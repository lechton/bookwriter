# Brief 005 — Closing the craft gap: from labeled lanes (4) to drawn scenes (8.5)

**Date:** 2026-07-19 · **Scope:** plan to close the innovation/professionalism gap between workflow-authored cards (rated 4) and the online Gemini originals (rated 8.5) · **Status:** plan approved for execution pending green light
**Builds on:** briefs 001–004; user calibration 260719 (workflow designs 4/10, originals 8.5/10)

## 1. Why 4 is the right score

The workflow fixed aim (pedagogy P1–P3 pass; confusions targeted, genres matched) but not drawing. Failure inventory, from the screenshots: metaphors carried by captions instead of shapes (The Wrecking Ball draws no ball; The Press Run draws no paper); zero environmental texture (the originals' dotted grids, hatching, blueprint tints); no object mimicry (their terminal IS a terminal); no typography play (rotation, watermarks, badges); every card the same bones — panel, chip, boxes, pills — interchangeable with any mid-tier tutorial diagram. Print discipline (9) and pedagogical aim (9) do not count on the innovation/professionalism axes the user scored.

## 2. Root cause

Rendering is still freehand invention per card. A model inventing CSS from scratch under print constraints converges to safe boxes and pills — every time, regardless of how good the concept is. The originals were produced in an unconstrained design-studio context where the model built a visual language once and reused it. We have no reusable visual language for scenes. Concept menus exist (brief 002); a render menu does not.

## 3. The solution: three layers

### Layer 1 — The render vocabulary (the big lever)

Build `assets/styles/metaphors.css`: the originals' craft moves extracted into print-safe, self-hosted, deterministic class sets, so scenes are assembled, not invented. First batch (~12 components):

- **Environments:** `.env-dots` (dotted grid), `.env-hatch` (diagonal stripes), `.env-blueprint` (blue tint grid) — the background participates in the metaphor, as the street's asphalt did.
- **Objects:** `.terminal` (chrome bar, traffic dots, log lines — extends the stub already in `diagrams.css`), `.paper` (newspaper sheet with fold rule and masthead rule), `.building` (the instance/demolition unit), `.tray` (the queue/inbox).
- **Devices:** `.stamp` (rotated bordered tag), `.badge` (numbered circles, as the Lifecycle Pipeline), `.watermark` (giant faded glyph behind content), `.ghost` (struck/dashed dead element — my one original device, promoted), `.wire` with `.wire-tag` (connector with inline label pill and drawn arrowhead), `.lane-label` (color-coded lane semantics).
- Rules: light backgrounds only, monochrome-legible, self-hosted fonts, must render identically in Chrome and Prince, 130mm-safe.

Paired with a **gallery**: `output/exp-004_gallery/` — one card per component, built and screenshotted, so the vocabulary is *visible*. A model that can see the menu assembles scenes; a model told the menu in words invents boxes. The gallery is the prompt.

### Layer 2 — Workflow v3 (small edits to `docs/design-workflow.md`)

1. RENDER must compose from `metaphors.css`; custom inline CSS only for gaps, and any gap used twice gets promoted into the library.
2. New step between CAST and RENDER — **STUDY**: pick two reference screenshots from `docs/_shots/` (the originals) and list two or three craft moves to borrow (texture? rotation? badges? watermark?). Brief 002's copying warning applies to metaphors; at render level, borrowing moves is the point.
3. Judging: D6 (scene is drawn, not labeled) now enforced with the library; add a paired score — each new card is rated 0–10 against its nearest original from the registry, recorded in the experiment log.

### Layer 3 — exp-005, the redraw gauntlet

Redraw the five 4-rated cards (Dead Wire vs Live Wire, The Live Feed, The Wrecking Ball, The Press Run, Waiting on the Wire) using the library, same text, same concepts — execution is the only variable. Side-by-side against the originals' screenshots; user rescores 0–10 on innovation and professionalism. **Target: 7.5+.** A card that does not pass D6 blind (reader guesses the concept name from the picture alone) does not ship.

## 4. The ceiling, honestly

Layers 1–3 should lift the floor to ~7.5. Consistent 8.5+ likely keeps the division of labor for flagship cards: the DIAGNOSE phase runs locally (pedagogy is the workflow's win), the scene is drafted in an online design session *given the library spec*, and local transcription into `metaphors.css` classes becomes near-mechanical — which is also exactly what makes the local model's independent output better. The library pays off in both modes.

## 5. Sequence and success metric

1. Build `metaphors.css` + gallery (exp-004) — biggest lever, do first.
2. Workflow v3 edits (STUDY step, compose-from-library rule, paired scoring).
3. exp-005 redraw gauntlet, user rescores against the originals.
4. Fresh-model validation (local Gemini, workflow + registry + gallery only).
5. Only then: production re-authoring (svelte-demo 01–03 first).

Success = user's rescore of the exp-005 set at 7.5+ on innovation and professionalism, with D6 passing blind.
