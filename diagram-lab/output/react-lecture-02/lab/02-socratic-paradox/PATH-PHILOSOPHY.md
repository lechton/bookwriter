# Path 02: The Socratic Paradox (The Dual Mirror)

## Philosophy
Challenge the reader's complacency by placing two nearly identical snippets side by side. Ask the hard question upfront. Make the reader think actively before revealing the engine mechanism.

## Pedagogical Invariants
1. **The Hook:** The Identical Twins. Two snippets that seem to accomplish the exact same DOM update.
2. **The Socratic Question:** Why does Snippet A scale linearly with defects ($O(N)$ failure surface), while Snippet B guarantees 100% synchronization?
3. **The Intellectual Duel:** Challenge the reader: "Did you think this was just cleaner syntax? It is actually a completely different computational paradigm."
4. **The Conceptual Breakthrough:** Contrast Imperative Step-by-Step Instructions ("How to mutate") with Declarative Intent ("What the UI should look like").
5. **The Senior Interview Insight:** Synthesize why senior interviewers test this question to differentiate junior script-writers from software architects.
