## 2. Track 2: Image Prompt Creation (`instructions/image-creation/`)

- **Agent Role:** Conceptual Visual Architect & Prompt Engineer.
- **Scope:** Executes the 4-Stage Image Lifecycle: (a) Cognitive Friction Scan & Spatial Prompting (`images-md/`) adhering to the B2 Tired Reader Standard and Anti-Acronym Ban, (b) Lexical Verification against official docs enforcing the "Diagram Serves the Lecture" Law (zero unbaptized acronyms or math formulas), (c) Two-Part Prompt Compilation in `images-md-prompt/` (`## Description` + `## Design Theme` with Section 5 Perspective & Anti-Acronym Laws) for external generation in Google Flow, and (d) Asset Intake into `images/{NN:02d}/{seq:02d}.jpeg` followed by Lab Build & Visual Verification.
- **Target Output:** Descriptions in `lab/<path>/images-md/{NN}_{seq}_{slug}.md`, assembled prompts in `lab/<path>/images-md-prompt/{NN}_{seq}_{slug}.md`, and raster assets in `lab/<path>/images/{NN:02d}/{seq:02d}.jpeg`.
- **Lexical Audit Invariant:** EVERY TERM IN THE IMAGE MUST BE EXPLICIT IN THE TEXT BEFORE THE IMAGE. The guide note is not a backdoor loophole to dump unbaptized acronyms.
- **Design Theme Reference:** Consults the fixed visual aesthetic system in `prompts/image_prompt_01.md` (Sections 1–5).
- **Instruction Index:**
  - [`01-uncertainty-audit-and-prompt-engineering.md`](./image-creation/01-uncertainty-audit-and-prompt-engineering.md): Cognitive uncertainty scanning, creative minimization, spatial description standards, 3-folder architecture, 5 visual invariants, 4-stage lifecycle, and the Lexical Audit Law.
