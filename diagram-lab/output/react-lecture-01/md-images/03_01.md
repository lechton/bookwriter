Accompanying Book Paragraph:
The most insidious bug in React is not one that throws a flashing red error in your console—it is the bug that fails in complete silence. If you define a component function and invoke it in lowercase as `<authorProfile />`, your build tools will not crash and your browser will not report a syntax error. Instead, your article appears with a mysterious blank gap where the author credit was supposed to render. Why does React insist that component names begin with a capital letter? The answer lies directly in the JSX compilation engine. Browsers cannot parse JSX syntax; a build step must compile every tag into a function call. During compilation, the first character of the tag name serves as a binary compiler switch: a lowercase initial letter instructs the compiler to emit a string literal (`React.createElement('authorProfile')`), which React sends directly to the browser DOM engine as a raw, unknown HTML element (`HTMLUnknownElement`). Because HTML permits arbitrary custom tags, the browser quietly creates a generic zero-pixel inline container, leaves it unstyled, and never calls your JavaScript function. Conversely, a capitalized initial letter instructs the compiler to emit a direct variable identifier (`React.createElement(AuthorProfile)`), prompting React to execute your component function, pass its props, and render the complete author card with live typography and avatars.

Description:
This visual aid dissolves one of the most frustrating stumbling blocks for new React engineers: why lowercase components fail silently without producing an error message. In standard HTML, tags are case-insensitive and custom tags are rendered as generic elements, leaving beginners baffled when their lowercase component function is completely ignored by the page. By organizing the component lifecycle into a compact, space-efficient vertical layout with large characters and surgical marker highlights, the student immediately visualizes the underlying mechanism: capitalization is not a stylistic preference or convention, but a functional compiler switch that determines whether React asks the browser for a raw DOM node or executes the developer's JavaScript logic.
