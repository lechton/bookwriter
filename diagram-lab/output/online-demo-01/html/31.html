Compiler Dependency Inference

State (Legacy)Compiler

Question. How does the Svelte compiler automatically infer dependencies for a legacy $: reactive statement?

Answer. In legacy Svelte (v3/v4), the compiler acts as a static analysis tool. When it encounters the $: label, it parses the trailing expression into an Abstract Syntax Tree (AST). It scans this tree to locate any top-level component variables that are read or evaluated within the statement. Svelte then automatically instruments the compiled JavaScript so that whenever any of those identified variables are reassigned, the reactive statement is queued to re-run.

Summary. The legacy Svelte compiler relies on strict lexical analysis. If a top-level variable is visibly read inside the $: statement, it becomes a dependency. Variables hidden inside external function calls are completely invisible to the dependency tracker.
