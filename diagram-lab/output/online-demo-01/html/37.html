$derived Rune

Svelte 5RunesReactivityOptimization

Answer. The $derived rune calculates derived state synchronously from other state variables. When any of the source $state signals it depends on change, the $derived value automatically re-evaluates.

Its primary optimization benefit is memoization. If the underlying state hasn't changed, Svelte returns the cached value instead of re-running the computation. This prevents expensive recalculations and unnecessary DOM updates. Additionally, $derived tracks its dependencies dynamically at runtime, avoiding stale closures.

Summary. Use $derived for computing values derived from $state. It offers automatic dependency tracking and memoization, recalculating only when necessary to optimize performance.
