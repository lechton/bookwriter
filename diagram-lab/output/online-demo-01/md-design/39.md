Design description: A top-down flow diagram demonstrating the `$inspect` rune stripping away Proxy wrappers for debugging, set on off-white paper. At the top, a secondary-accent cyan container labeled "Input" holds a complex nested block representing a `$state` object wrapped in multiple Proxy layers. A thick black arrow points downward into the primary-accent mustard-yellow element: a magnifying glass icon acting as a filter or lens, boldly labeled `$inspect()`. Below the magnifying glass, another thick black arrow points to a neutral white output container labeled "Console", which contains the raw, unwrapped data object with clean JSON-like syntax. Exactly four visual elements total: the reactive input container, the magnifying glass ($inspect), the console output container, and the arrows counted as one set. No arrows going backward, no legacy `console.log` comparisons — the diagram argues the unwrapping utility of `$inspect`.
