Design description: The graphic illustrates the Svelte compiler's static analysis process using a Neo-Brutalist aesthetic. The background is a dark blueprint grid (#1e1e24). On the left, a white "AST Parser" window displays the code `$: sum = a + b;`. The specific dependency variables (`a` and `b`) are highlighted with bright cyan boxes and drop-shadows to show the parser actively identifying them. A giant cyan arrow points to the right. On the right, a bright cyan "Internal Registry" block containing "Tracked Deps" displays `[ a, b ]` in a heavy, inverted terminal-style font block, visualizing the exact dependencies the compiler has memorized.
