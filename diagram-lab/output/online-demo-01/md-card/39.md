## Q39 — `$inspect` Rune

@tags Svelte 5, Runes, Debugging, State Management

**Answer.** The `$inspect` rune is a powerful built-in debugging utility that acts like a reactive `console.log`. Instead of manually logging state changes inside an `$effect`, you simply pass a reactive signal (like `$state` or `$derived`) to `$inspect()`. 

Whenever the tracked state changes, Svelte automatically logs the new value to the browser console. It strips away the Proxy overhead, allowing you to clearly see the raw underlying data structure without the noise of the reactivity system. It is strictly a development tool and is stripped out entirely during production builds.

```svelte title="Debug.svelte"
<script>
  let count = $state(0);
  let double = $derived(count * 2);

  // Automatically logs to the console whenever count or double changes
  $inspect(count, double);
</script>

<button onclick={() => count++}>Increment</button>
```

> **Summary.** Use the `$inspect` rune to cleanly log reactive state changes to the console. It automatically unwraps deep proxies for readability and is stripped out in production.
