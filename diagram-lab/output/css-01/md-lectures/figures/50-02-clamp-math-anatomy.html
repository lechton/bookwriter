Clamp Parameters Anatomy
Linear Slope Derivation (y = mx + b)
THREE ARGUMENTS CLAMP(MIN, VAL, MAX)
1. MIN (1.5rem / 24px) Lower safety floor: text never shrinks below this threshold on phones
2. PREFERRED (1rem + 2.5vw) Dynamic slope: viewport scale evaluated across normal reading widths
3. MAX (3.5rem / 56px) Upper ceiling cap: prevents oversized text explosion on ultra-wide screens
Safe Fluid Boundary: The browser clamps calculated size strictly between lower and upper bounds without overflow.
The clamp function evaluates the preferred rate of change while guaranteeing immutable safety boundaries.
RATE OF CHANGE SLOPE CALCULATION
1. SLOPE (m):
(56px - 24px) / (1600px - 320px)
= 32 / 1280 = 0.025 (2.5vw)
2. INTERCEPT (b):
24px - (0.025 * 320px) = 16px (1rem)
RESULT: 1rem + 2.5vw
Mathematical Precision: Combining rem with vw produces a line that hits exact design target sizes at 320px and 1600px.
Linear interpolation derives the exact viewport multiplier and root font offset required to connect target boundaries.
