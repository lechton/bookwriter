ARCHITECTURAL REFACTORING AND BLAST RADIUS SPECTRUM
COMPONENT-FIRST (BEM)
Location of Abstraction: External CSS stylesheet; HTML remains pure semantics.
Local Refactoring Blast Radius: Tied strictly to block file; zero risk of external leakage.
Global Design Token Updates: Requires editing every component rule or preprocessor variable.
Build Tool Dependency: Zero build tools required; runs natively in any web browser.
UTILITY-FIRST (TAILWIND)
Location of Abstraction: HTML template components (React, Vue, Svelte, partials).
Local Refactoring Blast Radius: Tied to template markup; editing classes never breaks other elements.
Global Design Token Updates: Centralized in config; updating `spacing[4]` updates entire site.
Build Tool Dependency: Requires Node.js compiler and PostCSS/JIT purging engine.
Architectural Complementarity: Separation of Concerns vs Separation of Files
BEM abstracts styling into stylesheets; utility-first abstracts styling into template components.
