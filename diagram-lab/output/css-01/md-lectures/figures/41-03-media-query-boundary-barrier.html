✓ Sass @Mixin: Crosses Media Boundaries
✕ Sass @Extend: Media Query Barrier
MEDIA QUERY COMPLIANCE ALLOWED
@mixin grid-layout {
  display: grid;
  gap: 16px;
}

@media (min-width: 768px) {
  .feed { @include grid-layout; }
}
✓ Sass clones declarations directly into the @media block.
@include grid-layout; inside @media block
Mixins safely cross media query boundaries by duplicating declarations into target scope.
MEDIA SCOPE RESTRICTION FORBIDDEN
%grid-layout {
  display: grid;
  gap: 16px;
}

@media (min-width: 768px) {
  .feed { @extend %grid-layout; }
}
✕ SASS ERROR: You may not @extend an outer selector from within @media.
@extend %grid-layout; inside @media triggers compile error
Sass strictly forbids extending outer selectors from within media queries.
