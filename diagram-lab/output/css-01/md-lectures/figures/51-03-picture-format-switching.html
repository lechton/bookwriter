Single Legacy Format (JPEG)
Format Switching via <picture>
LEGACY BASELINE UNIVERSAL JPEG
<img src="hero.jpg"> 240 KB
✕ Lowest common denominator: forces all clients to download heavy legacy files.
✕ High Network Cost: Modern browsers capable of decoding AVIF waste 80% more bandwidth downloading legacy JPEGs.
Using a single image format forces you to choose between breaking older browsers or punishing modern mobile users.
PROGRESSIVE NEGOTIATION <SOURCE TYPE="...">
<source type="image/avif"> 48 KB (-80%)
<source type="image/webp"> 72 KB (-70%)
<img src="hero.jpg"> 240 KB (FALLBACK)
✓ Next-Gen Delivery: The browser automatically loads the most advanced compression codec it supports, falling back cleanly.
The <picture> element provides content negotiation directly in HTML without complex server-side User-Agent sniffing.
