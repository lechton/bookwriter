1. SAME-DOCUMENT (SPA)
API:startViewTransition()
TRIGGER:JavaScript DOM update
SCOPE:Single memory context
Best For: React, Vue, Svelte applications managing dynamic client-side views.
Allows explicit async data fetching and state updates inside a single browser session.
2. CROSS-DOCUMENT (MPA)
CSS:@view-transition
RULE:navigation: auto
ORIGIN:Same-origin only
Best For: Multi-page static sites, Astro, Rails, and traditional HTML link clicks.
Zero JavaScript required; the browser orchestrates transitions between full page reloads.
3. MOTION ACCESSIBILITY
MEDIA:prefers-reduced-motion
TARGET:::view-transition-*
OVERRIDE:animation: none !important
Mandatory: Prevents vestibular disorientation and nausea for motion-sensitive users.
Converts animated morphs into instantaneous visual swaps when reduced motion is requested.
