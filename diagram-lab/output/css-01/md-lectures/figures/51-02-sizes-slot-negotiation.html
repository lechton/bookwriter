Missing Sizes: Preloader Guesswork
Declared Sizes: Exact Slot Selection
PRELOAD BLIND SPOT DEFAULT SIZES="100VW"
1. Preload Scanner: Scans HTML before CSS layout builds. Slot width unknown.
2. Default Fallback: Browser assumes slot = 100vw (e.g. 412px * 3x DPR = 1236px).
3. Download Choice: Downloads heavy 1600w asset for a tiny 200px sidebar thumbnail!
✕ Bandwidth Waste: Without sizes, mobile browsers assume full-width hero scale, defeating responsive image optimization.
The browser preloader cannot wait for CSS stylesheets to parse; omitting sizes causes massive over-fetching.
SLOT NEGOTIATION SIZES="(WIDTH < 768PX) 100VW, 33VW"
1. Media Condition: Matches 33vw slot on desktop (1200px * 0.33 = 400px slot).
2. Density Calculation: 400px slot * 2.0 DPR = 800px required density.
3. Exact Match: Picks 800w asset from srcset instantly during early HTML parse!
✓ Optimal Asset Match: The sizes attribute tells the preload scanner the true layout width before CSS downloads.
Declaring layout slot widths in sizes allows the preloader to fetch the exact right image file on the very first roundtrip.
