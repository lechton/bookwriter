1. SCROLL & PIN
CSS:overflow-x: auto
PIN:position: sticky
A11Y:tabindex="0"
Best For: Financial sheets, election data, multi-column metrics where comparing rows is essential.
Preserves 100% of native table semantics and column alignment with zero DOM mutation.
2. BLOCK REFLOW
CSS:display: block
LABELS:attr(data-label)
HEAD:visually-hidden
Best For: Customer directories, receipts, order histories where each row is an independent entity.
Transforms rows into comfortable vertical cards, completely eliminating horizontal scrolling.
3. COLUMN TOGGLE
PRIORITY:essential cols
SECONDARY:display: none
CONTROL:disclosure toggle
Best For: Analytics dashboards where secondary metrics hide until expanded by user request.
Reduces cognitive clutter by prioritizing core columns, disclosing secondary details on demand.
