CSS ARCHITECTURAL TRADEOFF MATRIX: BEM VS UTILITY VS SCOPED
BEM (Methodology)
Build Tool: None required; pure CSS
Specificity: Flat (0, 1, 0) throughout
HTML Ergonomics: Verbose class strings
DevTools View: Instant semantic clarity
Utility-First (Tailwind)
Build Tool: Compiler required (PostCSS)
Specificity: Flat (0, 1, 0) single utilities
HTML Ergonomics: Dense class chains in markup
DevTools View: Atomic styles; token lists
Scoped (CSS Modules / @scope)
Build Tool: Bundler or modern browser
Specificity: Automated hashes or scoping root
HTML Ergonomics: Clean concise class bindings
DevTools View: Generated class hashes (_x7k9)
BEM, Tailwind CSS, and CSS Modules / @scope;
BEM trades raw HTML brevity for zero build-tool dependencies, flat specificity, and human readability.
