✕ Sass @import: Global Hijacking
✓ Sass @use: Namespaced Isolation
GLOBAL SCOPE MUTATION UNPREDICTABLE
// grid.scss
$gutter: 24px;
↓ SIDEBAR.SCSS LOADED LATER (MUTATES GLOBAL SCOPE) ↓
// sidebar.scss
$gutter: 12px; // Silently overwrites global $gutter!

.article-content { margin-left: $gutter; } // Resolves to 12px
✕ Order-dependent: last imported partial silently wins everywhere.
@import flattens all files into one global scope
Variables mutate globally based on load order, causing silent layout bugs.
EXPLICIT NAMESPACES DETERMINISTIC
@use 'grid';
// grid.$gutter is isolated (24px)
↓ INDEPENDENT NAMESPACE ISOLATION ↓
@use 'sidebar';
.article-content {
  margin-left: grid.$gutter; // 24px
  padding-right: sidebar.$gutter; // 12px
}
✓ Total encapsulation: each module maintains its own immutable namespace.
@use 'module' binds members to explicit namespaces
Prevents variable collisions and makes origin immediately visible in source.
