BEM ENTITY TAXONOMY: BLOCK, ELEMENT, AND MODIFIER NOTATION
BLOCK
.story-card
Autonomous standalone component; defines parent namespace.
ELEMENT (__ )
.story-card__headline
Constituent part tied to block; separated by two underscores.
MODIFIER (-- )
.story-card--featured
Theme or state flag; separated by two consecutive hyphens.
BLOCK: .story-card MODIFIER: .story-card--featured
Election Night Live Coverage .story-card__headline
By Maya Lin, Senior Political Desk .story-card__byline
Interactive Live Results .story-card__action
.story-card, .story-card__headline, .story-card--featured;
Explicit delimiters (__ for elements, -- for modifiers) guarantee isolated, self-documenting tokens.
