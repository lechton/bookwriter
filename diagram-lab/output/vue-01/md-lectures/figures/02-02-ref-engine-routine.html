myRef
_value: 0 hidden slot
get value() calls track() read door
set value(n) calls trigger() write door
Read Path
1. Screen render reads value through the getter.
2. track() writes into the registry: this effect reads this ref.
EFFECT REGISTRY: render effect joins the list
Write Path
1. Click sets value through the setter.
2. New number lands in _value; trigger() wakes the list.
3. Render effect re-runs and reads the fresh number.
DOM RELABEL: counter shows 1 instead of 0
