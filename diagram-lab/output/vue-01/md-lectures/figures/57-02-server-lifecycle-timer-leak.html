The Lifecycle Asymmetry: Browser Teardown vs Node.js Timer Leak
Browser Client Environment (Single User) Complete Teardown
1. setup()
➔
2. onMounted() (Start Interval)
➔
3. onUnmounted() (Clear Interval)
Balanced execution: When the user navigates away, onUnmounted executes clearInterval(). Timers active: 0.
Node.js Server Environment (Shared Process, Thousands of Users) Zero Teardown
1. setup() (Interval Created!)
➔
2. onMounted() (Never Runs)
➔
3. onUnmounted() (Never Runs)
Fatal trap: Node runs setup() and immediately calls renderToString(). Unmount hooks never fire. Timers stay alive forever in libuv.
