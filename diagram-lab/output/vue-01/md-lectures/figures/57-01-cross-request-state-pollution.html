Node Process Global Scope (Shared)

A
Request 1 (Alice): Authenticates and writes state.user = 'Alice (Admin)'.
B
Request 2 (Bob): Guest visits. Reads state.user and sees Alice's session!
Cross-Request State Pollution: Data from Request 1 leaks into Request 2. Bob gains admin dashboard access.

App & Store Factory Pattern Isolated Per Request
Request Handler Factory Scope

A
Request 1 (Alice): Calls createApp(). Store #1 created exclusively for Alice.
B

Total Request Isolation: Each HTTP request owns a private sandbox. Memory garbage collected when response ends.
