# Decision Brief: Archetype 10 Architecture Audit Table Structural Invariant & Figure-Table Margin Neutralization (#2026_09_21_28_group_1)

**Date**: 2026-09-21
**Rule Tag**: `#2026_09_21_28_group_1`
**Components Affected**: `src/lecture.css`, `skills/figures/SKILL.md` (Section 14), `skills/verification/SKILL.md` (Section 15), `01-02-md-LECTURES/figures/templates/`

---

## 1. Problem Statement & Defect Analysis

During PDF verification of Lesson 01, the Stage E Architecture Audit Table (`figures/01-02-architecture-audit.html`) exhibited two severe layout defects:
1. **First Column Left Margin Clipping**: The entire first column (`Component Layer`) was pushed 260px to the left, completely off the page edge into the PDF margins.
2. **Obsolete Container Styling**: The table was styled with rounded borders, a dark solid header, and an outer card box rather than sitting directly on the editorial page substrate.

### Root Cause
1. **Duplicate Negative Margin Cascade**:
   - In `src/lecture.css`, `main figure.react-figure` applies `margin-left: -260px; width: calc(100% + 260px);` to bleed figures across the full printable page width.
   - However, `src/lecture.css` *also* had a blanket rule `main table { margin-left: -260px; width: calc(100% + 260px); }`.
   - Any `<table>` inside an embedded `<figure>` inherited this second negative margin, shifting it `-520px` relative to normal content, thereby pushing the first column off-screen.
2. **Missing Canonical Templates in React-05**:
   - `react-lecture-05` was created without the `figures/templates/` directory. Without `10-architecture-audit-vtable.html` on disk, an author was forced to author a table ad-hoc, failing to include the necessary `.audit-table { margin-left: 0 !important; }` reset.
3. **Instruction Under-Specification**:
   - `figures/SKILL.md` Section 14 stated semantic contents (eyebrow, title, 3 columns) but did not specify the physical layout invariants (editorial substrate, 3px rules, column percentage widths, and margin neutralization).

---

## 2. Changes Applied

### A. Root-Cause Stylesheet Neutralization (`src/lecture.css`)
Added a global reset rule for nested figure tables:
```css
/* Prevent nested figure tables from inheriting duplicate negative margin */
main figure table,
main .rce-figure table,
main .css-figure table {
	margin-left: 0 !important;
	width: 100% !important;
}
```

### B. Specification Upgrade in `skills/figures/SKILL.md` (Section 14)
- Mandated cloning directly from `templates/10-architecture-audit-vtable.html`.
- Enforced clean editorial substrate without outer card containers, drop shadows, or rounded corners, anchored by heavy 3px black rules (`border-top: 3px solid #0f172a; border-bottom: 3px solid #0f172a`).
- Mandated explicit nested table margin neutralization (`margin: 8px 0 0 0 !important; margin-left: 0 !important; width: 100% !important; table-layout: fixed !important; border: none !important;`).
- Standardized print budget column ratios: `Component Layer` (22%), `Naive Expectation` (39%), `What Happened` (39%).

### C. Quality Gate in `skills/verification/SKILL.md` (Section 15, Stage E)
- Added explicit inspection requirement verifying Archetype 10 editorial substrate, 3-column full visibility, and margin neutralization.

### D. Asset Restoration
- Copied the canonical `templates/` directory from `react-lecture-04` into `react-lecture-05/01-02-md-LECTURES/figures/templates/`.
