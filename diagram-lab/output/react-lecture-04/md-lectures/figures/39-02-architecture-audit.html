The Custom Hook Extraction Audit

Evaluating stateful logic reuse versus state sharing across component boundaries.

LAYER Component Architecture level NAIVE EXPECTATION Copy-Paste Logic Duplicated stateful blocks WHAT HAPPENED Custom Hook Extracted stateful recipe
<EditorialDesk /> Parent Container Workspace layout PROP-DRILLED
Lifts network state to the top-level parent and prop-drills `isOnline` down to all children. The parent manages window listeners and forces the entire view to re-render on every connection flicker. 		ISOLATED MOUNT
Passes zero network props to children. The parent remains completely decoupled and never re-renders when connection status toggles.
useOnlineStatus() Custom Hook Encapsulated logic SHARED SINGLETON
Assumes custom hooks behave like global singletons or shared stores, where calling the hook in multiple components binds them to a single shared state variable in memory. 		FIBER RECIPE
Encapsulates the stateful subscription recipe. Each component invocation allocates an independent hook cell on that component's fiber node, sharing logic with zero state sharing.
<Widgets /> Consumers Status bar & button COPY-PASTE DRIFT
Copy-pastes identical useState and useEffect blocks into every file. Bug fixes or cleanup improvements drift apart, creating silent production defects. 		SINGLE-LINE HOOK
Invokes `useOnlineStatus()` in a single line. Both components receive clean boolean values and re-render independently with zero boilerplate.
VERDICT

FRAGILE LOGIC DUPLICATION: Copy-pasting hook blocks creates maintenance drift and binds component files to low-level DOM event listeners.

BULLETPROOF LOGIC REUSE: Custom hooks encapsulate stateful recipes, allocating independent fiber state per component with zero shared state bugs.
