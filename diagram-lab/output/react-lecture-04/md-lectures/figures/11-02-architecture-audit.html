Layer 01
Array Transform
JSX iteration
 Imperative Loops

Using external for loops and pushing to a temporary array introduces mutable state outside the render expression.

 Array.map()

Calling array.map() inside JSX curly braces transforms data into an array of elements declaratively in a single expression.
Layer 02
Key Location
Element declaration
 Nested Key

Placing key inside the child component or on an inner tag fails: React cannot inspect keys buried inside children.

 Outermost Tag

The key prop must always be placed directly on the outermost JSX tag returned by the map() callback function.
Layer 03
Key Selection
Identity source
 Index as Key

Using array index (key={index}) ties identity to position; reordering, inserting, or filtering scrambles component state.

 Stable Data ID

Using permanent database IDs (key={item.id}) lets React track DOM nodes through reorders and preserve internal state.
Layer 04
Key Stability
Lifecycle persistence
 Dynamic Generation

Calling Math.random() generates fresh keys every render, forcing React to destroy and recreate the DOM on every pass.

 Persistent Identity

Keys must remain unchanged across renders, allowing React's reconciliation engine to reuse existing DOM nodes efficiently.
