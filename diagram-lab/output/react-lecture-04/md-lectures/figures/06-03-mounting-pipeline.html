The Two-Step React Mounting Pipeline
1
Physical DOM Container
<div id="root"></div>
Static HTML element located on disk in index.html; awaits mounting.
▼
2
Create Root Instance
const root = createRoot(domNode);
Acquires the container in memory, claims DOM ownership, and initializes concurrent scheduler.
▼
3
Render & Commit Component Tree
root.render(<NewsApp />);
Evaluates component hierarchy, builds virtual UI tree, wipes container, and commits live DOM nodes.
