Lessons from the Code
Event Handling & Propagation Architecture Audit

Evaluating predictable SyntheticEvent handling and bubbling control versus legacy inline listeners.

Component Layer Naive Expectation (Imperative Listeners) What Happened (React 19 Reality)
1. Parent Container (NewsDesk.jsx) Global Window Listeners Developers attach global listeners to window or mutate global selection state directly, bypassing React's declarative hierarchy and leaking listeners. Centralized Callback Props The parent defines pure callback handlers (handleSearch, handleSelectArticle) and passes them downward, keeping event logic centralized and predictable.
2. Search Child (ArticleSearch.jsx) Direct DOM Queries Developers query the input DOM element on submit using querySelector or expect onChange to fire only on blur, losing live keystroke control. SyntheticEvent Input Capture Reads e.target.value on every keystroke via onChange and detects Enter keypresses via onKeyDown, forwarding values upward cleanly.
3. Clickable Card (ArticleItem.jsx) Immediate Function Invocation Developers write onClick={onOpen(story.id)} with parentheses, executing the selection handler during render before any user click occurs. Deferred Arrow Function Wraps the callback in an inline arrow function (() => onOpen(story.id)), ensuring the handler executes strictly upon a physical user click.
4. Terminal Action (BookmarkButton.jsx) Accidental Event Bubbling Developers assume clicking a nested button only triggers that button, unintentionally firing the parent card's article selection handler as the click bubbles. Isolated Propagation Calls e.stopPropagation() on the SyntheticEvent to halt bubbling, allowing the bookmark action to execute without triggering the parent card click.
Verdict Fragile Coupling Untamed event bubbling triggers duplicate actions, parenthesis traps execute code during render, and direct DOM queries break component isolation. Bulletproof Modularity SyntheticEvent standardizes cross-browser details, deferred references protect render purity, and stopPropagation isolates nested interactive controls.
