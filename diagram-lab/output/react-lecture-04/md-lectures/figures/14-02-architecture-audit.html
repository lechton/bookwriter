Layer 01
Handler Binding
JSX event prop
 Function Call

Writing onClick={fn()} executes the function immediately during render, causing premature side effects and infinite loops.

 Function Reference

Writing onClick={fn} passes the function reference, allowing React to invoke it strictly when the user triggers the event.
Layer 02
Custom Arguments
Parameter passing
 Immediate Argument Call

Writing onClick={fn(id)} invokes the handler at render time and passes its return value to the event listener.

 Arrow Wrapper

Writing onClick={() => fn(id)} creates an inline callback that fires only on click, forwarding the argument safely.
Layer 03
Event Normalization
Browser consistency
 Browser Variance

Relying on raw DOM event objects exposes cross-browser inconsistencies in property names and bubbling behavior.

 SyntheticEvent

React passes a normalized SyntheticEvent object that behaves identically across all major browsers and platforms.
Layer 04
Event Propagation
Bubbling control
 Return False

Returning false from an event handler is ignored by React, allowing events to bubble to parent containers unintentionally.

 e.stopPropagation()

Explicitly invoking e.stopPropagation() halts event bubbling cleanly, preventing parent container clicks from firing.
