Layer 01
Nested Content
Component body
 Rigid Slots

Passing nested JSX trees via named props like content={...} creates clunky attributes and breaks natural HTML hierarchy.

 Children Prop

React automatically captures nested JSX onto props.children, allowing seamless visual containment and clean markup nesting.
Layer 02
Native Attributes
HTML element forwarding
 Manual Props

Explicitly declaring every native prop (id, tabIndex, aria-*) requires editing the wrapper for every new attribute.

 Rest + Spread

Destructuring known props and gathering ...rest allows spreading {...rest} onto the root element, forwarding all native attributes.
Layer 03
Optional Props
Fallback values
 Scattered Fallbacks

Using inline ternary or logical operators like props.variant || 'default' scatters fallback logic throughout render branches.

 Destructuring Defaults

Setting defaults in the signature ({ variant = 'default' }) guarantees clean, resilient values at the component boundary.
Layer 04
DOM Leakage
Attribute safety
 Blind Spreading

Spreading the entire uninspected props object onto a native tag passes non-standard props to the DOM, causing React console warnings.

 Filtered Spreading

Destructuring internal props first and spreading only ...rest guarantees that only legitimate DOM attributes reach the browser element.
