useRef: Silent Persistence vs State Re-renders

Evaluating render triggers, synchronous mutation, instance scoping, and the Golden Rule.

Storage Scope
Fiber attachment
 Using module-scoped globals (let timerId = null) outside components. Instance-scoped isolation. useRef binds mutable boxes strictly to the component Fiber, preventing shared collisions.
Render Trigger
silent mutation
 Storing timer IDs in state, triggering redundant re-renders on update. Zero render triggers. Mutating ref.current is synchronous and never schedules reconciliation passes.
Render Lifespan
local variables
 Declaring local let variables inside functions to store handles. Render resets locals. Every render re-runs the function, resetting local variables and losing active handles.
Render Purity
the Golden Rule
 Reading or mutating ref.current directly in JSX render output. Strict render purity. Read and write refs exclusively in effects or event handlers to avoid corrupt renders.
