Layer 01
Batching
Render scheduling
 Synchronous Re-render

Expecting each setter call to instantly re-execute the component, causing severe layout thrashing across multiple calls.

 Automatic Batching

React collects all setter calls in the event loop turn and processes them together, committing a single re-render.
Layer 02
Queue Action
Queued instruction
 Static Overwrite

Passing setCount(count + 1) evaluates against frozen snapshot 0, queuing a static "replace with 1" command.

 Calculation Function

Passing setCount(c => c + 1) queues a pure function that calculates next state from the pending state.
Layer 03
Repeated Calls
Consecutive updates
 Lost Updates

Three consecutive calls with snapshot expressions overwrite each other; the state only increases by 1.

 Chained Accumulation

Three consecutive updater functions execute in series (0 to 1, 1 to 2, 2 to 3), increasing the state by 3 accurately.
Layer 04
Function Purity
Execution contract
 Side Effect Danger

Mutating external variables or making network calls inside updater functions triggers duplicate bugs in StrictMode.

 Pure Reduction

Updater functions must be pure calculations with zero side effects, returning a new state value based solely on pending state.
