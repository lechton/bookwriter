The Distributed Reader State Challenge

Comparing manual DOM query bookkeeping against declarative React component projection.

HIERARCHY Component Layer LEGACY APPROACH Naive Expectation REACT 19 REALITY What Happened
<SiteHeader> Parent Container Scattered JavaScript files query element IDs across the page, risking silent null failures when templates change. Parent receives readerName once and distributes it through explicit child props, establishing a single source of truth.
<ReaderGreeting> Greeting Presenter Manual textContent assignment requiring defensive null guard clauses that mask broken selectors. Pure presenter projecting prop directly into JSX evaluation window with zero manual DOM lookups.
<SubscriberInfo> Subscriber Presenter Hardcoded element IDs break silently when moved into a drawer, leaving stale subscriber text on screen. Encapsulates markup and behavior cleanly, updating in lockstep with the greeting whenever props change.
