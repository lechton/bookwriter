Layer 01
Execution Frame
Current render scope
 Synchronous Mutation

Expecting state variables to mutate immediately on the next line of code, enabling instant read-after-write access.

 Immutable Constant

State is a fixed constant for the entire duration of the render execution frame; calling a setter cannot change current scope.
Layer 02
Setter Action
Next frame preparation
 Direct Overwrite

Assuming setVotes(1) directly modifies the existing variable address in memory during the handler run.

 Render Request

Calling setVotes(1) informs React to schedule a future render pass where votes will be initialized as 1.
Layer 03
Async Closures
Delayed callbacks
 Dynamic Reading

Assuming asynchronous timers or promises will read whatever state value the screen currently displays when they fire.

 Temporal Consistency

Callbacks close over the snapshot from the exact render in which they were created, preventing cross-render race conditions.

Immediate Access
Value propagation
 Read-After-Write

Reading the state variable immediately after calling the setter to pass into subsequent analytics or API functions.

 Local Calculation
