The Persistent Memory Architecture Audit

Evaluating ordinary local variables versus useState memory across component layers.

LAYER Component NAIVE EXPECTATION Local Variables Transient Stack Execution WHAT HAPPENED useState Memory React 19 Fiber Persistence
<HeadlineDesk /> Parent Container Ordinary Variable Mutation Assumed declaring let headline would store changes across renders and notify child views automatically. Centralized Reactive State Declares useState to retain the active headline in fiber memory, scheduling a re-render whenever the setter is invoked.
<HeadlineViewer /> Presenter Child Child State Duplication Assumed child could increment a local index or mutate parent variables directly to advance breaking headlines. Stateless Inverse Data Flow Child remains completely stateless, invoking onUpdateHeadline to request a state transition in the parent.
<StoryCounter /> Terminal Counter Silent Local Variable Loss Assumed let count = 0 would persist across clicks, only to find the screen never updates and resets on render. Isolated Instance Memory Allocates a private useState(0) cell in this fiber node, incrementing independently with zero parent re-renders.
VERDICT FRAGILE STATE LOSS Local variables vanish when the function exits, fail to trigger renders, and silently discard user actions. BULLETPROOF PERSISTENCE useState retains memory in the component fiber node and triggers scheduled re-renders on every setter call.
