Scope & Identity
component boundary
 Querying elements globally via document.getElementById or querySelector. Component-scoped refs. useRef anchors strictly to the component instance without cross-instance collisions.
Ref Passing
React 19 ref prop
 Wrapping custom components in awkward forwardRef higher-order functions. Direct ref prop. React 19 treats ref as a standard prop, making forwardRef obsolete.
Read Timing
commit phase
 Reading ref.current during render to calculate immediate style offsets. Post-commit availability. ref.current is null during render; read exclusively in effects or events.
Element Teardown
unmount cleanup
 Manually clearing DOM references to avoid detached node leaks. Automatic nullification. React automatically resets ref.current to null when the element unmounts.
