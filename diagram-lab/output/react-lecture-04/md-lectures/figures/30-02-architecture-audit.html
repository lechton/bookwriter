React Context: use() API vs Prop Drilling

Evaluating context teleportation, React 19 provider elements, and conditional hook reads.

Layer / Invariant
Architectural focus
Naive Conception
Common assumption
Engine Reality
React 19 implementation
Data Delivery
teleportation
 Threading courier props through 4-5 intermediate layout components. Context teleportation. Ancestor provides value; deep leaves read directly without touching middle nodes.
Provider Tag
React 19 syntax
 Mandating verbose legacy <Context.Provider value={...}> wrappers. Direct <Context> element. React 19 allows rendering <ThemeContext value={...}> directly as provider.
Consumption API
conditional reads
 Using useContext constrained unconditionally to the top level of functions. React 19 use() API. use(Context) can be invoked conditionally inside if statements, loops, or branches.
Scope Discipline
ambient boundaries
 Replacing all component props with context to eliminate all argument passing. Ambient data only. Restrict context to themes, auth, locale; keep localized data in explicit props.
