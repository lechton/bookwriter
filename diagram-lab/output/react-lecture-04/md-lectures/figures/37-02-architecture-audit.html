Render Phase
pure idempotence
 Assuming React has a bug when console.log prints twice in local dev. Intentional double render. Re-executes pure functions to expose side effects, mutations, and impure logic.
Effect Lifecycle
remount verification
 Running effect setup once and expecting teardown only on final unmount. Setup-cleanup-setup cycle. Simulates unmounting and remounting to verify clean listener and socket teardowns.
Production Build
zero runtime cost
 Fearing that double execution slows down production client performance. 100% stripped in production. StrictMode is completely inert in production builds with zero performance overhead.
Auditing Scope
sub-tree wrapping
 Believing StrictMode must wrap the entire root or be disabled completely. Flexible sub-tree placement. StrictMode can wrap specific branches, enabling gradual modernization of legacy code.
