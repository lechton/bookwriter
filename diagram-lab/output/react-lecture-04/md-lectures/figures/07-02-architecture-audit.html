LESSONS FROM THE CODE
ES Module Component Splitting & Import Architecture

Evaluating default exports, named exports, and the curly brace trap against naive monolithic expectations.

HIERARCHY Component Layer TRADITIONAL MISTAKE Naive Expectation REACT 19 STANDARD What Happened
NewsPortal.jsx Parent Container Piles all markup and sub-components into a thousand-line monolith, causing merge conflicts and tangled logic. Coordinates the page layout cleanly by importing specialized child components through explicit ES module contracts.
SiteHeader.jsx Default Export Child Imports default export using curly braces import { SiteHeader }, accidentally resolving to undefined and crashing React. Declares export default for the primary component; consumers import without curly braces under any convenient local name.
ArticleComponents.jsx Named Export Bundle Forces every tiny component into a separate file or exposes them on global window objects, risking name collisions. Exports multiple related micro-components (ArticleList, ArticleCard) using named exports with curly braces.
FINAL VERDICT MONOLITHIC MERGE CONFLICTS & RUNTIME UNDEFINED MODULAR ES MODULES & EXPLICIT BOUNDARIES
