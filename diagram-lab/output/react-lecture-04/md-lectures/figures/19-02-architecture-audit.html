Layer 01
Adding Items
Queue appending
 push() Mutation

Calling arr.push(item) modifies the array in place; Object.is bails out and skips re-rendering.

 Array Spread

Writing [...arr, item] creates a new array reference containing all prior items plus the new entry.
Layer 02
Removing Items
Item deletion
 splice() Mutation

Calling arr.splice(index, 1) cuts the element out of the existing array, keeping the same reference.

 filter() Method

Calling arr.filter(i => i.id !== id) returns a fresh array containing only the non-matching items.
Layer 03
Updating Items
Item transformation
 Direct Index Mutation

Setting arr[i].read = true mutates the object inside the array, altering past snapshots silently.

 map() with Spread

Calling arr.map(i => i.id === id ? { ...i, read: true } : i) produces both a new array and a new object.
Layer 04
Reordering Items
Sorting and reversing
 sort() / reverse()

Calling arr.sort() mutates indices in place, failing to trigger change detection or re-render.

 toSorted() Method

Calling arr.toSorted(...) generates a brand new sorted array without modifying the original array in state.
