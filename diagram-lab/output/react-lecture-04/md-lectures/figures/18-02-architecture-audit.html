Layer 01
Memory Reference
Heap allocation
 Same Address

Writing user.name = 'Alice' modifies existing properties at the same memory address on the heap.

 New Object

Writing { ...user, name: 'Alice' } creates a brand new object with a distinct memory address.
Layer 02
Change Detection
Re-render decision
 Render Bailout

React evaluates Object.is(prev, next) to true because pointers match; re-render is silently skipped.

 Render Trigger

React evaluates Object.is(prev, next) to false because pointers differ; re-render is scheduled immediately.
Layer 03
Field Updates
Property overrides
 Manual Duplication

Manually re-typing every property risks dropping fields or introducing typos whenever the schema expands.

 Spread Operator

Object spread copies all existing keys into the new object, allowing concise trailing overrides for target fields.
Layer 04
Nested Objects
Deep data structures
 Inner Mutation

Spreading outer object while mutating user.address.city leaves inner object mutated, risking desync.

 Multi-Level Spread

Spread at every level of nesting to ensure all ancestor objects receive fresh references and remain immutable.
