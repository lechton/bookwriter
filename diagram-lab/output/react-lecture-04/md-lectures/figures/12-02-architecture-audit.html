Layer 01
Determinism
Render calculation
 External State

Reading or writing variables declared outside the component makes JSX output dependent on execution counts and timing.

 Same Input = Same Output

Given identical props, a pure component always returns the exact same JSX without touching external variables.
Layer 02
Mutation Scope
Memory boundaries
 Prop Mutation

Mutating props or existing objects passes changes to parents and siblings without triggering proper React reconciliation.

 Local Mutation Only

Mutating objects created within the current render execution is completely safe and invisible to the outside world.
Layer 03
Development Audit
StrictMode tool
 Impurity Blindness

Without audit tools, subtle mutations work once on initial render but fail silently during subsequent user interactions.

 Double Rendering

React's StrictMode double-calls component functions in development to expose accidental mutations immediately.
Layer 04
Side Effects
Outside interaction
 Render Effects

Triggering network calls, timers, or DOM writes directly in the render body causes duplicate actions on every render pass.

 Quarantined Zones

Side effects are quarantined in event handlers or useEffect hooks, running strictly after rendering finishes.
