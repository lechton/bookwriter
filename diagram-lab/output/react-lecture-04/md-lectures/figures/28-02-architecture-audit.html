Evaluating fiber node lifecycle, state preservation rules, and the nested component trap.

Tree Position
fiber mapping
 Assuming state lives inside the component function and follows the function instance. Position-based retention. React stores state in Fiber nodes matched by component type and tree position.
Explicit Keys
identity override
 Assuming keys only serve to silence React compiler warnings on rendered lists. Forced state reset. Different keys force React to destroy the old Fiber node and mount a fresh instance.
Function Scope
nested definitions
 Declaring child component functions inside a parent component for convenience. State destruction bug. Creates a new component type on every render, resetting state and DOM focus.
View Toggling
conditional branches
 Assuming switching between conditional JSX branches automatically clears input state. State leaks across branches. Identical component types at the same tree slot reuse the existing Fiber.
