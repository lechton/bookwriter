Phase Timing
render vs commit
 Connecting to sockets or listeners directly inside the component body. Commit phase execution. useEffect executes after DOM paint, keeping pure render free of side effects.
Teardown Symmetry
cleanup pairing
 Omitting cleanup, allowing zombie connections to accumulate across renders. Symmetrical cleanup. Returned cleanup function disconnects the resource before next effect or unmount.
Dependency Sync
reactive values
 Passing [] while reading changing props, creating stale closure bugs. Full reactive alignment. List every read prop/state; effect cleans up old values and connects fresh ones.
StrictMode Audit
double-mount check
 Treating StrictMode double-execution as a framework bug to disable. Teardown stress test. Setup -> Cleanup -> Setup cycle verifies that cleanups completely reset state.
