Derived State
render calculation
 Declaring useState for filtered items and counts, manually syncing them in handlers. Compute during render. Calculate filtered items and counts on the fly; they can never drift out of sync.
Entity Selection
normalized reference
 Storing a full selected object in state, creating a stale duplicate when items update. Store selectedId only. Derive the active object with Array.find() during render to ensure fresh data.
Minimal Footprint
irreducible data
 Creating state for props, constants, or intermediate values across components. Apply the three tests. Only put data in state if it changes over time, cannot be props, and cannot be derived.
Status Modeling
impossible states
 Managing independent boolean flags (isLoading, isError, isSuccess) that can conflict. Use single status enum. Unify mutually exclusive states into 'idle' | 'loading' | 'success' | 'error'.
