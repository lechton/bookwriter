Layer 01
UI Paradigm
Control strategy
 DOM Mutation

Querying nodes via querySelector and toggling classes directly, causing desynchronization with React.

 State Projection

UI is a pure mathematical projection of state: JSX declares the view; React reconciles the DOM automatically.
Layer 02
State Modeling
Visual modes
 Boolean Explosion

Using independent boolean flags (isSubmitting, isSuccess) allows impossible simultaneous states.

 Status String

Modeling with a single status string ('typing' | 'submitting' | 'success') eliminates impossible states.
Layer 03
Transitions
Complexity scaling
 Exponential Combinations

Managing $2^n$ transitions manually leads to forgotten element resets and fragile edge-case bugs.

 Linear Declarations

Each visual state simply declares its own JSX markup; state transitions remain isolated and straightforward.
Layer 04
Derived Data
State minimalism
 Redundant State

Storing computable values (like isEmpty) in state creates multiple sources of truth that drift apart.

 Render Calculation

Calculate derived values dynamically during render: const isEmpty = text.length === 0 requires no state.
