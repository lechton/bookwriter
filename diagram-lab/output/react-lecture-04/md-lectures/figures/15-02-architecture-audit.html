Layer 01
Persistence
Across render calls
 Variable Reset

Variables declared with let or const re-initialize on every function call, forgetting user changes immediately.

 Fiber Node Storage

useState stores data in React's internal fiber node on the heap, retaining values across repeated render passes.
Layer 02
Render Trigger
UI synchronization
 Silent Mutation

Mutating a variable (likes++) alters memory silently; React receives no notification and never re-renders the screen.

 State Setter Call

Calling setLikes(next) explicitly alerts React to schedule a new render pass, keeping the DOM synchronized with state.
Layer 03
Call Order
Hook index alignment
 Conditional Call

Placing hooks inside if statements changes the call order between renders, corrupting state alignment in the fiber list.

 Top-Level Only

Calling hooks unconditionally at the top level guarantees React pairs each hook with the exact same memory slot every time.
Layer 04
State Location
Subtree coordination
 Isolated Child

Declaring state in a deep child prevents sibling components from displaying or reacting to changes in that value.

 Lifting State

Declaring state in the parent container allows passing current values down as props and passing setter callbacks to buttons.
