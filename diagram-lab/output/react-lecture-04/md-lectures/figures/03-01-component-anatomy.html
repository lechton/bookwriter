Compiler Architecture & Tag Resolution
JSX Compiler Casing Divergence: PascalCase vs Lowercase Tags
PascalCase Component Executes Function
1. JSX Authoring
<AuthorProfile author="Elena" />
2. Compiler Output
jsx(AuthorProfile, { author: "Elena" })
✓ Component Executed: Identifier variable references the function in memory. React invokes AuthorProfile() and renders the author card.
Lowercase Tag Ignores Function
1. JSX Authoring
<authorProfile author="Elena" />
2. Compiler Output
jsx('authorProfile', { author: "Elena" })
✕ Silent Failure: String literal instructs browser to create unknown HTML element <authorProfile>. Custom code never executes; screen stays empty.
