Layer 01

Source of truth
 DOM Internal

The DOM input node owns its own value; React state cannot see or validate keystrokes until submit.

 React State

React state exclusively determines the value; the input is a pure visual projection of component state.
Layer 02
Prop Pairing
Input synchronization
 Missing Handler

Supplying value without onChange freezes the input because React resets DOM on every keystroke.

 Two-Way Loop

Pairing value and onChange forms a complete loop: state pushes to DOM, events pull back to state.
Layer 03
Input Filtering
Keystroke control
 Unchecked Typing

Users can type any character; validation can only run after the user blurs or submits the form.

 Real-Time Masking

Keystrokes can be formatted, masked, or rejected in real time inside onChange before reaching the screen.
Layer 04
Form Reset
Programmatic clearing
 Manual DOM Query

Clearing an uncontrolled input requires imperatively querying the DOM node and mutating input.value = ''.

 Declarative Reset

Setting state to '' immediately clears the input across all instances through standard reconciliation.
