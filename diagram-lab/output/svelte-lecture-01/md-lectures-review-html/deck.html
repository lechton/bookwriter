Lecture 49 Review: Syncing Local Variables with Incoming Props

A quick-reference guide to the core concepts introduced in lecture 49. Review this table to solidify your understanding of Svelte 5's prop reactivity before moving on.

Scenario / Objective
Implementation Rules

How to sync a local variable with an incoming prop?

Keep a local variable continuously updated when the parent passes new data.

Correct: Use the $derived rune to maintain a continuous reactive connection.

let likes = $derived(post.likes);

Warning: Don't use $state, which only reads the prop once during creation and then ignores future updates.

let likes = $state(post.likes);

How to temporarily override a derived value?

Update the UI immediately before the server confirms the change (Optimistic UI).

Correct: Reassign the $derived variable directly. The override will be washed away when the parent updates the prop.

likes += 1;

Warning: Don't declare the derived variable with const if you intend to override it.

How to two-way bind a prop?

Allow a child component to push changes back up to the parent component.

Correct: Declare the prop as $bindable().

let { text = $bindable('') } = $props();

Warning: Don't mutate standard, one-way props directly.

How to write a multi-statement derivation?

Use an intermediate variable or loop to calculate a derived value.

Correct: Pass a callback function into $derived.by().

`let str = $derived.by(() => { return text.trim(); });`

Warning: Don't mutate other state inside the derivation. It must be side-effect-free.

How to destructure a prop?

Pull properties off the $props object without losing reactivity.

Correct: Read properties directly from the object in the template, or read through an intermediate prop object.

let p = $props();
<p>{p.title}</p>

Warning: Don't destructure into primitives, which severs the reactive connection.

let { title } = $props();

How to sync an editable local draft?

A form draft that the user can edit, but also syncs if the parent updates the source.

Correct: Carefully combine $state(prop.value) with an $effect() to push upstream changes into the local draft.

$effect(() => { draft = user.name; });

Warning: Default to $derived first; only reach for this when editability and continuous sync are both required.
