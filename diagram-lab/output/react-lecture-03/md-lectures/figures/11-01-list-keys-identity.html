key={article.id} ✓ STABLE DATABASE ID
id: 103 Global Energy Accord (New) Bookmark
id: 101 Tech Accord Signed Bookmarked
React tracks items by permanent entity ID.
When a new story is prepended, existing component state moves with its corresponding data.
key={index} ✕ INDEX STATE CORRUPTION
idx: 0 Global Energy Accord (New) Bookmarked
idx: 1 Tech Accord Signed Bookmark
React assumes index 0 is the same component and retains its previous state.
New item steals the old item's bookmark state, corrupting user interactions.
