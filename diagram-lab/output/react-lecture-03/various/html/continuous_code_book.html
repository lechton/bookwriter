Lecture 39: Managing Action State

Building a secure newsroom tip form requires carefully managing state across asynchronous transitions. Historically in React, achieving this required developers to manually wire up multiple independent state variables.

React 19 eliminates this manual coordination by introducing the useActionState hook. Notice how we start by importing the necessary hooks before establishing the default export function. 

import { useActionState } from "react";

export default function ConfidentialTipForm() {
  const [state, formAction, isPending] =
    useActionState(submitTipAction, {
      status: "idle",
      error: null,
      submissionCount: 0,
      receiptId: null
  });

By leveraging useActionState, the engine handles the pending states directly. This avoids manual boilerplate and immediately provides a resilient foundation.
