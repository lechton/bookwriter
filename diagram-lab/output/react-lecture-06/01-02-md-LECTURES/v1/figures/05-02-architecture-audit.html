JavaScript Expressions in JSX

Contrasting static markup literals against dynamic curly brace evaluation windows.

Dimension Grammar Mechanism Static Markup Literal Strings Bypasses JavaScript Scope Curly Braces Evaluation Window { } Dynamic JavaScript Execution
Text Content Projection Literal Characters
Writing <h2>headline</h2> renders the literal string "headline" on screen, ignoring variables in scope. 		Variable Evaluation
Writing <h2>{headline}</h2> evaluates the variable in memory and renders its live string value.
Attribute Value Binding Static Quote String
Writing src="avatarUrl" sets the HTML attribute to the literal string "avatarUrl", breaking image asset paths. 		Dynamic Attribute
Writing src={avatarUrl} evaluates the JavaScript variable and passes the resolved URL directly.
Grammar Eligibility Statements Forbidden
Placing statements like {if (admin) ...} crashes the compiler because statements produce no return value. 		Expressions Permitted
Accepts any valid expression: variables, arithmetic, ternary conditionals (isLead ? 'Lead' : 'Staff'), and function calls.
Inline Computations Manual Concatenation
Requires manual template string concatenation outside JSX before passing values into markup. 		Direct Math in JSX
Allows inline arithmetic directly inside markup: {readMinutes * 60} seconds.
