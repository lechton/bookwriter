REACT DOM MOUNTING ARCHITECTURE LEGACY SYNCHRONOUS VS CONCURRENT CREATEROOT
Legacy: ReactDOM.render() DEPRECATED
1. Package Import
import ReactDOM from 'react-dom';
Monolithic DOM package import.
2. Execution Model
ReactDOM.render(<App />, node);
One-shot synchronous blocking pass.
3. Event Boundary
document.addEventListener(...)
Events attached globally to document.
Synchronous mounting blocks main thread and emits deprecation warning.
Modern: createRoot() CONCURRENT
1. Package Import
import { createRoot } from 'react-dom/client';
Subpath import targeting client runtime.
2. Execution Model
const root = createRoot(node);
root.render(<App />);
Two-step concurrent root initialization.
3. Event Boundary
node.addEventListener(...)
Events isolated at root container boundary.
Concurrent root enables interruptible rendering and isolated events.
