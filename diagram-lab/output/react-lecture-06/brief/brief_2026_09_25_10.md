## Context & Motivation
1. **The Three Opening Anti-Patterns in Sequential Lecture Production**:
   Following updates to lecture openings, models authoring Lecture 4 oscillated between three distinct failure modes:
   - *Trap 1 (The Canned Retrospective Platitude)*: Blindly recycling conversational icebreakers ("Think back to how you render data in traditional browser scripts. In plain JavaScript, you declare...").
   - *Trap 2 (The Theatrical Domain Melodrama)*: Manufacturing atmospheric journalism novelizations ("In The National Times newsroom, articles and live dispatches arrive around the clock. When Hellen Jones files a breaking investigation into municipal transit..."). A user correctly diagnosed: "a person spent energy in a newspaper paradigm that could be generic for any website and few sentences long".
   - *Trap 3 (The Premature Detail Rain)*: Swinging to the opposite extreme by dumping raw code syntax, variable declarations, and micro-debugging steps directly into line 1 ("You assign Hellen Jones's breaking news title to a local variable: const headline = 'Transit Strike Paralyzes Downtown'. To display that title in the article header, you write <h2>headline</h2>. When the browser refreshes, the screen renders the literal seven letters 'headline'..."). The user called this out: "to start with details is even worse, it throws rain of details to the reader ! what you propose is not normal intro, can you not see it?".

2. **Root Cause Analysis & Golden Rule of De-Prescription**:
   - In `skills/v6.2/lecture-voice/SKILL.md`, positive guidance previously instructed authors to "connect with what the interface accomplishes for The National Times". Models interpreted this as an order to write narrative fiction in prose before addressing technical mechanics.
   - At the same time, `PROPER EXAMPLE B` opened with "Think back to the first script you wrote...", creating in-context few-shot leakage where the model copied the opening words directly into Lecture 4.
   - Rule 22 literally contained the string ("you declare the article headline in memory"), which the model stitched directly into its opening sentence.

3. **The Proper Solution: The Universal 3-Sentence Engineering Anchor & Paragraph 2 Keyboard Step**:
   - The opening of Section 1 must provide a concise, universal 2-to-3 sentence engineering anchor: (1) Sentence 1: Universal Web Reality (every website displays dynamic data from JavaScript variables). (2) Sentence 2: The Architectural Gap (static markup is hardcoded; manual synchronization is fragile). (3) Sentence 3: The React Mechanism (curly braces `{}` open an inline evaluation window).
   - Paragraph 2: Stepping to the keyboard. Only after the high-level conceptual umbrella is set does the text step to the editor, introducing *The National Times* component (`ArticleHeader.jsx`), the variable (`headline`), and the physical friction on screen.
   - Clarified the operational role of *The National Times*: it is strictly an authentic domain model for code artifacts (components, props, variable names, mock data), never a mandate for narrative novelizations or theatrical fiction in prose.
