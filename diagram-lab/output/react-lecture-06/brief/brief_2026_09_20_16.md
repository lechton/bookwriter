# Brief 2026-09-20-16: The Functional-Role Law and Duplicate Recap Elimination in Revisions

## 1. Context & Autopsy of the Defect

During review of Lesson 5 (`02-01-md-revised/05.md`), Step 3 (`PublishDate.jsx`) presented the following explanation:
```text
Notice how PublishDate executes JavaScript expressions directly inside markup:

1. Function call evaluation: It runs formatDate during render, passing timestamp and projecting the resulting formatted date string directly into the time element.
2. Method chain in attributes: It assigns the machine-readable dateTime attribute by converting timestamp into an ISO string on the fly.

Any valid JavaScript expression that returns a renderable value can execute between curly braces without manual DOM scripting.

To recap this step: any JavaScript expression that produces a value can be executed directly inside curly braces to compute dynamic markup on the fly.
```

The user flagged this passage as feeling hard and tiring to read: *"how can this structure could be more easy to read? more clear?"*

An autopsy identified four core friction points:
1. **Tour-Guide Throat-Clearing**: *"Notice how PublishDate executes..."* commands the reader to notice before showing them anything.
2. **Spec-Sheet Labels (Compiler Jargon)**: *"Function call evaluation"* and *"Method chain in attributes"* force the reader to decode abstract grammar categories rather than understanding who or what benefits from the code.
3. **The Back-to-Back Echo (Double Redundancy)**: The last two sentences state the exact same general rule almost verbatim back-to-back (*"Any valid JavaScript expression that returns a renderable value..."* followed immediately by *"To recap this step: any JavaScript expression that produces a value..."*).
4. **Missing Tactile Contrast**: `PublishDate` actually transforms the timestamp for two distinct audiences: human readers (visible formatted text) vs search engines and screen readers (`dateTime` ISO attribute).

## 2. Technical Decisions & Rules Added

We codified **Principle 05B: The Functional-Role Law (Banning Spec-Sheet Labels)** in `skills/lecture-revision/SKILL.md` (`#2026_09_20_16_group_1`):

1. **Banning Spec-Sheet Labels**:
   - Strictly ban abstract compiler or grammar labels (*"Function call evaluation"*, *"Method chain in attributes"*, *"Ternary operator branching"*).
   - Label roles by the real-world audience or operational destination:
     - **For human readers**
     - **For machines and assistive tech**
     - **For layout and styling**
     - **For component contracts**
2. **Tactile Historical Contrast**:
   - Contrast React's declarative expression evaluation against manual JavaScript DOM injection and helper scripts.
3. **The Single Takeaway Rule (Ban Duplicate Recaps)**:
   - Strictly ban following a general takeaway with a redundant *"To recap this step:"* sentence. If the takeaway is already stated, eliminate the echo.
4. **The Functional-Role Gate (Gate 5)**:
   - Added Gate 5 to the Readability Audit to ensure all multi-role breakdowns are audience-first and free of duplicate recaps.
