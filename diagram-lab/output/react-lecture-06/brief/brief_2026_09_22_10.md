# Decision Brief: Callout Code Display Block Separation & Uniform Inset Border Standard (#2026_09_22_10_group_1)

**Date**: 2026-09-22
**Rule Tag**: `#2026_09_22_10_group_1`
**Components Affected**: `skills/lecture-voice/SKILL.md`, `skills/code-blocks/SKILL.md`, `skills/verification/SKILL.md`, `src/build-lectures.mjs`, `src/lecture.css`, `skills/RULE-TAGS.md`

---

## 1. Problem Statement & Root Cause

In Lecture 09's `> [!WILD]` callout card, the compiler transformation example was written mid-sentence as inline monospace code:
`When you write nested JSX like <ArticleBox><Headline title="Breaking" /></ArticleBox>, the JSX compiler converts the nested tag directly into a prop named children. Under the modern JSX transform, this compiles to _jsx(ArticleBox, { children: _jsx(Headline, { title: "Breaking" }) }).`

In the compiled PDF layout:
1. **Container Overflow**: Inline code pills carry `white-space: nowrap` in `src/lecture.css` to prevent mid-token breaks. The 64-character compiled function call `_jsx(ArticleBox, { children: _jsx(Headline, { title: "Breaking" }) })` could not wrap, blowing straight through the card's right border and overflowing off the page into the margin.
2. **Double Left Border Conflict**: An initial test rendering code lines inside callouts inherited the default `.code-line-callout` styling with a bold 3.5px left accent border. Because the parent `.callout` panel already features a bold 4px left accent border, this created competing vertical left stripes (double bold borders).
3. **Justified Text Stretching**: Callout body paragraphs inherited `text-align: justify`, causing large, awkward word gaps around inline pills like `props.children`.

**Root Causes in Instructions & Build Pipeline**:
1. **The Over-Broad Ban Fallacy in Instructions**: `skills/lecture-voice/SKILL.md` Section 19 stated: `Keep code examples in adjacent code windows outside the callout; avoid embedding code fences inside alert boxes.` While intended to prevent full-sized macOS window editors inside alert cards, authors interpreted this as forbidding structured code lines altogether, forcing them to squeeze long AST transformations into inline running prose.
2. **Compiler Suppression**: In `src/build-lectures.mjs`, callout body rendering hardcoded `inline(b.text, false)` with `allowDisplayCode = false`, actively preventing the compiler from elevating long statements and JSX elements into dedicated `.code-line-callout` display blocks. Furthermore, the parser flattened all `> ` lines with `buf.join(' ')`, stripping intentional newlines and indentation.

---

## 2. Changes Applied

### A. Golden Rule De-Prescription in Skills
- **`skills/lecture-voice/SKILL.md` (Section 19)**:
  - De-prescribed the generic code ban inside callouts: full component implementations stay in adjacent editors, while concise syntax transforms and AST comparisons inside callouts are permitted and encouraged.
  - Mandated that code snippets in callouts are separated onto dedicated display lines with clean introductory lead-ins (e.g. `When nesting elements in JSX:`).
  - Required that structured JSX or transpiled calls are formatted across multiple indented lines for immediate visual hierarchy.
  - Required that inset code cards inside callouts maintain a uniform 1px perimeter without bold left accent stripes to prevent double-border conflict with the host panel.
  - Added a concrete PROPER EXAMPLE drawn directly from shipped Lecture 09.
- **`skills/code-blocks/SKILL.md` (Section 14)**:
  - Added Section 14: **Inset Display Code Blocks in Alert Cards**. Mandates dedicated backtick display lines for expressions ≥ 30 characters or complete JSX structures, clean 1px borders, and pure white card surfaces.
- **`skills/verification/SKILL.md` (Gate 21, item 18)**:
  - Added audit item 18 to the Pre-Flight Lecture Checklist: zero overflowing inline code pills in callouts, dedicated indented display lines, and uniform 1px perimeter without competing bold left borders.

### B. Build Engine Hardening (`src/build-lectures.mjs`)
- Hardened blockquote parsing to accept empty `>` lines (`line.startsWith('> ') || line === '>'`) and joined lines with `\n` to preserve multiline indentation.
- Enabled `allowDisplayCode = true` in callouts (`inline(b.text, true)`), allowing expressions ≥ 30 characters or full JSX elements to render as display code blocks.
- Added automatic paragraph grouping for callout bodies with double-newline separation (`paras.map(p => <p>${inline(p, true)}</p>)`).

### C. Design System & CSS Polish (`src/lecture.css`)
- Styled `.callout .code-line-callout` as a crisp, pure-white inset card (`background: #ffffff`, `border: 1px solid #cbd5e1`, `box-shadow: 0 1px 3px rgba(15, 23, 42, 0.05)`, `border-radius: 4px;`).
- Stripped heavy left accent borders from nested code cards to prevent double-border collision with the parent callout panel.
- Set `text-align: left;` on `.callout .callout-body p` to permanently eliminate wide justification gaps around inline code pills.

### D. Production Lecture Correction (`01-02-md-LECTURES/09.md`)
- Restructured Lecture 09's `> [!WILD]` card with clean lead-ins and multi-line indented AST formatting for both the JSX input and the `_jsx` transpiled output.
