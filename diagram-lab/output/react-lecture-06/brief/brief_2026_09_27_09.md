# Architectural Decision Brief — 2026-09-27-09: Harmonization of Principle Card Line Widths with the Standard 80-Character Boundary

## Executive Summary
This batch updates `src/build-lectures.mjs`, `skills/v6.3/principled-theory/SKILL.md`, and `skills/v6.3/RULE-TAGS.md` under tag `#2026_09_27_09_group_1`. It applies the **Golden Rule of De-Prescription** to abolish the legacy 40-character line width ceiling (`MAX_CASE_LINE_LEN = 40`) in principle callout cards, aligning principle card snippets with the curriculum-wide **80-character boundary** (`skills/v6.3/code-blocks/SKILL.md` Section 03). This eliminates artificial multi-line statement splitting for basic ES module imports and exports and prevents the comment extraction parser from sandwiching upward-pointing speech bubble clouds (`.cmt-bubble`) between split lines of a single statement.

## 1. Root Cause Analysis

### 1.1 The Legacy Two-Column Card Ceiling Trap
Under tag `#2026_09_26_01_group_1`, a 40-character line budget was established because principle cards were originally arranged side by side in a narrow two-column layout (~320px width per card). When cards were modernized under `#2026_09_27_06_group_1` into full-width breakout containers (`code-plus` with `width: calc(100% + 260px)` spanning ~680px), the 40-character ceiling became an outdated, over-prescribed constraint.

### 1.2 The Speech-Bubble Sandwich Glitch
In real JavaScript and React code, standard import statements naturally require 42 to 55 characters:
- `import ArticleCard from './ArticleCard.jsx';` (44 characters)
- `import ArticleCard from './components/ArticleCard.jsx';` (55 characters)

Because `build-lectures.mjs` issued a hard warning for any code line $> 40$ characters, authors were forced to split single statements across two lines:
```markdown
> `import ArticleCard // Default export syntax`
> `  from './ArticleCard.jsx';`
```
Because the compiler extracts inline comments and injects the speech bubble (`.cmt-bubble`) directly beneath the line containing the comment, the speech bubble was inserted between `import ArticleCard` and `from './ArticleCard.jsx'`, completely breaking the visual continuity of the statement.

## 2. Resolution

### 2.1 Compiler Limit Harmonization (`src/build-lectures.mjs`)
- Changed `MAX_CASE_LINE_LEN` from `40` to `80` in both table-based and default `code-plus` principle snippet parsers (lines 1170 and 1228).
- Principle card lines now share the exact same 80-character boundary that governs all narrative code blocks in the curriculum (`skills/v6.3/code-blocks/SKILL.md` Section 03).

### 2.2 Skill Alignment (`skills/v6.3/principled-theory/SKILL.md`)
- Updated Rule 128:
  - Replaced the rigid 40-character rule with the standard 80-character boundary.
  - Allowed statements like `import ArticleCard from './ArticleCard.jsx';` to sit on a single line, allowing speech bubbles to anchor naturally beneath the complete statement.
