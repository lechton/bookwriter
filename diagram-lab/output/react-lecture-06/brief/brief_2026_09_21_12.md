## Context & Defect Analysis
In Lecture 03, Step 2 (`ArticleHeader.jsx`), the explanation of parameter destructuring was authored as:
> "Instead of accessing `props.headline` throughout the body, we use JavaScript object destructuring directly inside the parameter list."

This phrasing introduced significant pedagogical friction:
1. **Unintroduced Baseline**: The student had never been shown `function ArticleHeader(props)` or `props.headline` anywhere in the course yet. Referring to `props.headline` as something being avoided assumed prior knowledge without establishing the baseline.
2. **Abstract Jargon**: Phrases like "throughout the body" and "JavaScript object destructuring directly inside the parameter list" rely on specification terminology rather than clear, visual engineering mechanics.
3. **Missed Opportunity at a Technical Crossroad**: When code arrives at a fork where developers have two concrete ways to write something (such as the explicit `props` object vs parameter destructuring), authors must not handwave with text. They must grasp the opportunity to teach the fundamental mechanics by displaying both options with separate, integrated code snippets.

## The Solution: The Pedagogical Crossroads Skill
1. **Dedicated Skill**: Created `skills/pedagogical-crossroads/SKILL.md` to govern technical forks across the curriculum.
2. **Two-Option Visual Code Staging**: Authors must present competing choices as separate code blocks:
   - **Option A (Foundational / Baseline Pattern)**: Reveals the underlying engine reality (e.g. `function ArticleHeader(props)` showing that React passes a single data object).
   - **Option B (Modern Idiomatic Standard)**: Shows the clean standard (e.g. `function ArticleHeader({ headline })` showing parameter unpacking).
3. **Exemplars as Inspiration, Not Constraints**: Four canonical crossroads (props receiving, prop passing quotes vs curlies, multi-line return ASI traps, component decomposition) are codified as inspiration, while the rule applies broadly to all similar technical crossroads.
4. **Integration**: Linked from `skills/lecture-structure/SKILL.md` and `skills/lecture-voice/SKILL.md`, and registered in `skills/README.md`.
