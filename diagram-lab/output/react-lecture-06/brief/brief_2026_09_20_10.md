# Brief 2026-09-20-10: Component Code Role-Mode 4-Field Syntax & Tree Integrity Law

## 1. Context & Autopsy of the Failure
When inspecting Lecture 01 (`01-02-md-LECTURES/01.md`, line 170), the `component-code` panel failed to render the serif role card and omitted all child components in the generated PDF. The block was written as:
```markdown
```component-code title="national-times - Component Architecture"
SiteHeader.jsx | [role: parent container receiving readerName and projecting it to child boundaries]
ReaderGreeting.jsx | [role: child greeting presenter projecting readerName into DOM text node]
SubscriberInfo.jsx | [role: child subscriber presenter displaying plan metadata alongside readerName]
```
```

This failed for two distinct reasons:
1. **The 2-Field vs. 4-Field Trap**:
   `component-code-explorer.mjs` parses fields as `file | props | kind | renders`. The serif callout (`.surface-ui-role`) only triggers when `[role: ...]` is parsed in Field 4 (`renders`). By writing only two fields, `[role: ...]` was parsed into Field 2 (`props`), rendering an unreadable grey props pill next to the filename instead of a serif role card.
2. **Zero-Indentation Tree Truncation**:
   The child components had zero indentation. In `component-code`, nested children must have 2 spaces of indentation (`  ReaderGreeting.jsx`). With zero indentation, the parser treated all lines as root nodes, and `parseComponentTree` silently executed `return roots[0]`, discarding all child components from the output without raising any error.

## 2. Technical Decisions & Fixes
1. **Compiler Hardening (`src/component-code-explorer.mjs`)**:
   - Throws a descriptive error if `[role: ...]` appears in Field 2 or 3.
   - Throws a descriptive error if `roots.length > 1`, eliminating the silent truncation of unindented children.
2. **Build Validation (`src/build-lectures.mjs`)**:
   - Validates that every 5-stage practical example carries ````component-code title="Summary: The Logic of Nested Components"```` in Stage D.
3. **Instruction Update (`skills/ui-panels/SKILL.md`)**:
   - Codified the 4-Field Syntax Law and 2-Space Indentation Law with a canonical multi-component example.
4. **Verification Gate (`skills/verification/SKILL.md`)**:
   - Enhanced Structure Gate 18 to audit 4 fields per line and 2-space indentation.
5. **Content Realignment**:
   - Fixed `01-02-md-LECTURES/01.md` and `01-02-md-LECTURES/04.md` (and their pre-lectures) to use proper 4-field, 2-space indented syntax with the title `Summary: The Logic of Nested Components`.
   - Re-skinned `01-01-code-assembly-pipeline.html` and `04-01-code-assembly-pipeline.html` to the canonical Template 09 pastel palette.
