## 1. Problem Statement & Root Cause

Previously, the instructions established *The National Times* newsroom as the running world but did not provide a standardized whitelist of character names. Consequently, authoring agents and models introduced arbitrary, ad-hoc names across different lectures and figures (e.g., `Elena Rostova`, `Marcus Vance`, `Sarah Lin`), creating narrative inconsistency and cognitive friction for the reader.

---

## 2. Changes Applied

### A. Skill Invariant (`skills/lecture-voice/SKILL.md`)
- Codified the approved character whitelist:
  - `John Miller`
  - `Leo Smith`
  - `James Cooper`
  - `Ann Brooks`
  - `Clara Foster`
  - `Hellen Jones`
  - `Julian`
- Mandated that all future lectures, code examples, prop values, alt attributes, and UI figures draw strictly from this whitelist.
- Strictly banned arbitrary or ad-hoc character names.

### B. Audit & Refactoring of Existing Files
- Standardized all character references across `01-02-md-LECTURES/*.md` and `figures/*.html`:
  - `Elena Rostova` / `Elena` / `Elena Vance` ➔ `Clara Foster`
  - `Marcus Vance` / `Marcus` ➔ `Leo Smith`
  - `Sarah Lin` ➔ `Ann Brooks`
