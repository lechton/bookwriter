# Decision Brief: Enhanced Theme Multi-Theme Deck Generation and Shared Code Appearance Preservation (#2026_09_22_01_group_1)

## 1. Problem Statement & Context

In `react-lecture-05`, lectures and course readers are published across multi-theme decks (Teal, Black, Old). A new theme ("Enhanced") was requested based on the design colors, typography, and layout from `various/html/lecture_view_01.html`, while strictly preserving the shared, standard theme of the code appearance across all editors and code blocks.

---

## 2. Changes Applied

### A. Compiler Updates (`src/build-lectures.mjs`)
- Integrated Google Fonts preconnect and stylesheet links (`Inter`, `JetBrains Mono`, `Merriweather`, `Montserrat`) into the HTML `<head>` page template.
- Expanded the multi-theme publishing arrays to include `{ id: 'enhanced', label: 'Enhanced' }`:
  - `01-03-md-lectures-HTML/React v5.2 Q{first}-Q{last}-enhanced.html`
  - `01-04-md-lectures-PDF/React v5.2 Q{first}-Q{last}-enhanced.pdf`
  - Revision multi-theme variants under `02-02-md-revised-html/` and `02-03-md-revised-pdf/`.

### B. Stylesheet Architecture (`src/lecture.css`)
- Added `@import url("https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700&family=JetBrains+Mono:wght@400;600&family=Merriweather:ital,wght@1,400;1,700&family=Montserrat:wght@700;800;900&display=swap");` at the top of `src/lecture.css`.
- Defined `:root` / `body.theme-enhanced` variables:
  - `--text: #1a1a1a`
  - `--muted: #64748b`
  - `--rule: #e2e8f0`
  - `--accent: #147b96`
  - `--title-color: #147b96`
  - `--marginalia-color: #147b96`
  - `--bold-color: #0d5669`
  - `--bullet-color: #147b96`
  - Standard shared code pill values preserved (`--code-pill-color: #0e7490`, `--code-pill-bg: #eef7f9`, `--code-pill-border: rgba(14, 116, 144, 0.25)`).
- Added explicit `THEME: ENHANCED` overrides for Prince compatibility:
  - Inter body typography (`font-family: 'Inter', ...`).
  - Montserrat headings (`h1` weight 900 `#147b96`, `h2` weight 800 `#1a1a1a`, `main h3` and `main h4` weight 800 `#147b96`).
  - Merriweather serif italic interview question text (`font-family: 'Merriweather', ...`).
  - Dark teal narrative bold (`p strong, p b { color: #0d5669 !important; }`).
  - Callout boxes and scenario boxes with `#f8f9fa` background and `#147b96` left accent border.
  - Preserved standard shared code block and editor appearance without theme divergence.
