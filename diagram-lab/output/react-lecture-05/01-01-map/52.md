# Q52: Escaping Overflow and Stacking with createPortal
* **Topic Tag**: `#create_portal` | `❱❱ MORE`
* **Interview Question**: *How do you render a modal that escapes its parent's overflow and stacking context?*
* **Core Truth**: `createPortal` renders JSX elements into a different physical DOM node outside the parent component's DOM hierarchy while preserving standard React event bubbling and context propagation.
* **The Friction**: An article sidebar has `overflow: hidden` and `z-index: 10`. When an editor opens an "Editorial Fact-Check" modal inside the sidebar, the modal is visually clipped by the parent container's boundaries and hidden behind higher z-index headers on the page.
* **The Mechanism**: React Portals (`createPortal(children, domNode)`). Render `<Modal>` JSX directly into `document.body` or a dedicated modal root element (`#modal-root`), bypassing parent CSS constraints.
* **Under the Hood**: Virtual hierarchy vs physical DOM hierarchy: even though the portal's physical DOM nodes sit at `document.body`, the portal remains a child in the React Virtual DOM / Fiber tree; events fired inside the portal bubble up the React tree to ancestor components.
* **The Code Experiment**:
  * *Naive*: Nesting a modal inside an `overflow: hidden` container and attempting extreme `z-index: 999999` CSS hacks that still get clipped by stacking contexts.
  * *React*: An `EditorialModal` using `createPortal(modalJSX, document.body)` that displays unobstructed over the entire page while bubbling click events cleanly to the parent component.
* **Scope Boundary**: Focus on `createPortal`, overcoming CSS overflow/stacking issues, and event bubbling through portals. Do not cover server-side HTML streaming details (Q101+).
