# Q77: Reconciliation Internals: Type and Key Diffing
* **Topic Tag**: `#reconciliation_internals` | `❱❱❱ ADVANCED`
* **Interview Question**: *When React re-renders, how does the reconciliation algorithm decide which DOM nodes to update?*
* **Core Truth**: React's heuristic $O(n)$ reconciliation algorithm relies on two fundamental assumptions: two elements of different types produce completely different trees, and elements with matching stable keys represent the same underlying entity across renders.
* **The Friction**: An engineer changes a wrapper element from `<div><Article /></div>` to `<section><Article /></section>`. Even though `Article` did not change, React completely unmounts and destroys the entire `Article` subtree, losing all reader inputs, because the parent element type changed from `'div'` to `'section'`.
* **The Mechanism**: The Reconciliation Diffing Rules: (1) If `element.type` changes, tear down the entire old subtree and mount a fresh one from scratch; (2) If `element.type` matches, retain the underlying DOM node and update only changed attributes; (3) For child lists, match fibers by `key` to determine moves, insertions, and deletions.
* **Under the Hood**: Solving the $O(n^3)$ tree diff problem: a general tree diffing algorithm is $O(n^3)$, which would require 1 billion operations for 1,000 nodes; React's heuristic diffing achieves $O(n)$ linear time by assuming web UIs rarely move subtrees across different tag types without intentional restructuring.
* **The Code Experiment**:
  * *Naive*: Toggling a parent container tag type (`isUrgent ? <div ...> : <section ...>`) and wondering why all child state resets on every toggle.
  * *React*: Keeping the container tag type stable (`<article className={isUrgent ? 'urgent' : ''}>`) so React reconciles attributes without destroying child fibers and state.
* **Scope Boundary**: Focus on the heuristic diffing algorithm, element type equality, key matching, and why $O(n)$ diffing requires these constraints. Do not delve into the internal Fiber workLoop pointers (Q78).
