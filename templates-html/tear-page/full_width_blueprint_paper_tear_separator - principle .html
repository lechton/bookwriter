Batching and Updater Functions

You call the setter with score + 1 three times in one click, and the score rises by one. Where did the other two points go?

INTERVIEW QUESTION  ·  ❱ CORE

How does React queue multiple state updates, and when do you need an updater function?

OVERVIEW

State Setter setScore with score + 1 vs. Updater Function with s => s + 1 : the plain value replaces, the updater continues

The Four Ideas This Lesson Stands On

KEY DEFINITION

State and its twin setter. REVIEW In vanilla JavaScript, you just write score = 3, and the job is done. Not in React. A value that must survive between renders lives in state, and state always comes as a pair: the state variable and its twin setter. You declare both together in one line: const [score, setScore] = useState(0). Every single time. React holds these values for your component between renders, and you never change them directly: no score += 1 here. Each time, you call the matching setter setScore(score + 1).
