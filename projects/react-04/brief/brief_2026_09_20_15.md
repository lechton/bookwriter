# Batch 2026_09_20_15: The Name Every Actor Law and Concrete Specificity in Revisions

## Context and Failure Mode
During the revision of Lesson 5 (`md-lectures-revised/05.md`), an initial attempt to remove line-number directives (`Look at lines 6, 7, and 8...`) and inline syntax smuggling (`{headline}`, `author={author}`, `timestamp={timestamp}`) produced the following prose:

> The curly braces evaluate in-scope variables and pass them as props to the children. The parent component does not concatenate strings or touch the DOM. It declares the values it wants in markup, and React evaluates each expression during the render pass.

While this eliminated syntax smuggling and imperative directives, it suffered from severe **abstract hand-waving**:
1. It stripped out all concrete names, leaving the reader to guess which variables were in scope, what data they held, and which children received them.
2. It failed to deconstruct the dual role of curly braces in the snippet: text interpolation (`{headline}`) versus prop passing (`author={author}`, `timestamp={timestamp}`).
3. It reduced sharp, actionable technical instruction to vague textbook jargon.

## The Solution
We codified **Core Principle 05: Concrete Specificity Without Vague Abstractions (The "Name Every Actor" Law)** in `skills/lecture-revision/SKILL.md`:
- **Name Every Actor:** Always explicitly name the exact variable (`headline`), the exact prop (`author`), and the destination component (`AuthorBadge`, `PublishDate`) using clean single-token backticks.
- **Deconstruct Multi-Role Syntax:** When a syntax feature (such as curly braces) serves multiple purposes in the same snippet, enumerate the roles (e.g. text interpolation vs prop assignment).
- **Tactile Contrast:** Contrast React's declarative expression evaluation against what the developer suffered through in vanilla JavaScript (string concatenation, manual DOM surgery).
- **The Actor Gate:** Added Gate 3 to the Readability Audit to ensure no revision hides actors behind vague abstractions.

## Target Example from Lesson 5
```markdown
Notice how `StoryBanner` uses curly braces in two distinct ways:

1. **Text interpolation:** It drops `headline` directly between the heading tags to display the title on screen.
2. **Prop assignment:** It uses curly braces inside JSX attributes to hand live data downward—passing the `author` object to `AuthorBadge`, and the `timestamp` number to `PublishDate`.

In traditional JavaScript, you would concatenate strings or manually set element properties. Here, the parent component does zero string surgery and never touches the DOM. It simply declares the variables it needs, and React evaluates each expression during the render pass.

To recap this step: curly braces act as a bridge into JavaScript, allowing the parent to display dynamic text and pass rich data structures directly to child components.
```
