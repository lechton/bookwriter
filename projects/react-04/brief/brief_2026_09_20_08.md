# Brief 2026-09-20-08: Archetype 09 Color Fidelity and Template Cloning Law

## 1. Context & Trigger
During review of Lecture 39, the introductory code assembly pipeline figure (`md-lectures/figures/39-01-code-assembly-pipeline.html`) was found visually degraded compared to Lecture 40 (`md-lectures/figures/40-01-code-assembly-pipeline.html`):
- In Lecture 39, the card content boxes were bleached stark off-white/gray (`#f8fafc`), edge bars used harsh saturated primary colors (`#2563eb`, `#0d9488`, `#d97706`, `#16a34a`), and the markup was riddled with ad-hoc inline styles (`style="background: #2563eb;"`, `style="background: #eff6ff;"`, `style="background: #f8fafc;"`).
- In Lecture 40, the cards followed the canonical design system established in `templates/09-progressive-assembly-step-cards.html`: pure CSS classes (`.step-card.step-1`, `.step-card.step-2`), muted and cohesive edge tones (`#7495be`, `#66a49b`, `#e09f67`, `#74ad68`), and a unified, soft pastel background across the entire `.card-main` container (`#d4e1f1`, `#d0e6e1`, `#f9e0c5`, `#d2ebc9`).

## 2. Why the Failure Occurred
1. **Instruction Contamination in `skills/figures/SKILL.md` (Line 276)**:
   The definition for Template 09 in `skills/figures/SKILL.md` was accidentally copied from Template 08:
   > *"Use template 09 (09-progressive-assembly-step-cards.html) as the alternative visual roadmap for multi-step progressive architecture: an ice-slate panel (#f4f6f9) with dark slate header bar (#344154)..."*
   Template 09 has no dark slate header bar and no ice-slate panel. Because the skill documentation described the wrong template, authors had no explicit written specification of Archetype 09's true color system.
2. **Absence of a Verification Gate**:
   `skills/verification/SKILL.md` contained 25 gates auditing pedagogy, structure, and mechanics, but zero gates checked figure color fidelity or template cloning. Regressions in figure HTML and styling slipped past the build without warning.
3. **Ad-Hoc Hand-Crafting ("Frankensteining")**:
   Instead of cloning `templates/09-progressive-assembly-step-cards.html` 1:1 and changing only the text and component tags, the author hand-crafted the markup with inline styles and bleached `#f8fafc` backgrounds.

## 3. The Invariants of Archetype 09
Under `#2026_09_20_08_group_1`:
1. **Canonical 4-Tone Pastel Palette**:
   - Step 1 (Blue): edge `#7495be`, main `#d4e1f1`, divider `#b0c4dd`
   - Step 2 (Teal): edge `#66a49b`, main `#d0e6e1`, divider `#aed1cb`
   - Step 3 (Amber): edge `#e09f67`, main `#f9e0c5`, divider `#eac4a1`
   - Step 4 (Green): edge `#74ad68`, main `#d2ebc9`, divider `#b2d5a5`
2. **Surface Continuity**:
   The pastel background belongs on `.card-main`. Both `.step-badge` and `.card-content` sit on this shared tinted surface. Setting `background: #f8fafc` or `background: #ffffff` on `.card-content` is strictly forbidden.
3. **Strict Ban on Inline Styles**:
   All colors must flow through the scoped `.step-1`, `.step-2`, `.step-3`, `.step-4` CSS classes. `style="background:..."` is permanently banned.
