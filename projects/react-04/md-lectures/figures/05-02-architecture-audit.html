LESSONS FROM THE CODE
JSX Expressions & Dynamic Data Architecture

Evaluating dynamic expressions, object binding, and text interpolation against legacy static HTML string expectations.

HIERARCHY Component Layer TRADITIONAL MISTAKE Naive Expectation REACT 19 STANDARD Component Reality
StoryBanner.jsx Parent Container Concatenates strings with plus operators ('<h1>' + title + '</h1>') or template strings, risking injection attacks and manual string bugs. Unquoted curly braces {headline} open a safe evaluation portal into JavaScript, escaping dangerous characters and projecting data cleanly.
AuthorBadge.jsx Child Component Wraps curly braces inside quotes (src="{author.avatarUrl}"), passing raw string characters literally to the browser and breaking image resolution. Unquoted attribute binding src={author.avatarUrl} evaluates the object property directly in JavaScript memory, delivering the valid URL.
PublishDate.jsx Child Component Pre-computes dates imperatively in external scripts and pushes strings into DOM nodes by querying element IDs by hand. Function call expression {formatDate(timestamp)} executes inline during render, deriving localized time text without manual DOM querying.
