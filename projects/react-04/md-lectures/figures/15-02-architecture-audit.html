Lessons from the Code
Callback Props & Inverse Data Flow Audit

An architectural comparison evaluating how child components notify parent containers without violating one-way data flow.

Component Layer Naive Expectation (Direct Mutation / Two-Way Binding) What Happened (Unidirectional Callback Props)
1. The Origin (Parent Page: NewsPage.jsx) Split State Ownership Children manage local filters or mutate parent variables directly. The parent loses control over which component triggers updates, causing state drift across views. Single Source of Truth The parent owns activeFilter state and passes an updater callback onSelectFilter downward, keeping the filter coordinated across all sibling views.
2. The Boundary (Nav Bar: CategoryNav.jsx) Tangled State Plumbing Intermediate containers duplicate filter state or intercept DOM events manually, coupling navigation layout directly to filtering logic. Pure Forwarding Conduit The navigation bar owns zero state. It receives the callback from the parent, wraps it with the category argument, and forwards it cleanly to each child button.
3. Terminal Control (Button: FilterButton.jsx) Direct Prop Reassignment The button reassigns its prop or attempts to write to the parent's memory, which violates component purity and fails to trigger re-renders. Inverse Data Flow Trigger The button holds only a telephone line (onSelect). Clicking fires native onClick, invoking the callback and executing the parent's setter safely in parent scope.
4. Sibling Consumer (Feed: ArticleFeed.jsx) Cross-Sibling Coupling The article feed must query sibling button DOM nodes or subscribe to custom window events to know which category was clicked. Pure Downward Consumer The feed receives category as a read-only prop. It owns zero callbacks and re-renders automatically when parent state updates, completing the circuit.
Final Verdict Fragile Coupling Direct prop mutation and two-way binding create untraceable state bugs and tightly coupled, brittle components. Bulletproof Modularity Props flow down, user actions flow up via callbacks, keeping components pure, decoupled, and completely predictable.
