Architecture Audit: Effect Lifecycle and Dependency Synchronization

Evaluating component lifecycle assumptions against React 19 effect synchronization guarantees.

HIERARCHY Component Layer ASSUMPTION Naive Expectation (COMPONENT LIFECYCLE) GUARANTEE What Happened (REACT 19 REALITY)
Parent Workspace
<ChatWorkspace.jsx>
 Expected to manage socket connection directly or unmount entire workspace when channel switches. Owns roomId state cleanly; stays mounted and coordinates child views without touching websockets.
Selection Control
<ChannelSelector.jsx>
 Expected to notify socket service directly or manage channel teardown inside click event handlers. Pure interactive control; delegates state update upward via onSelect, completely decoupled from socket logic.
Reactive Effect Boundary
<ChatRoom.jsx>
 Assumed effect only cleans up when component unmounts; expected changing roomId to update socket in place. React executes cleanup callback from previous render to disconnect old room, then runs new setup to connect new room.
FINAL VERDICT ZOMBIE ACCUMULATION ISOLATED RE-SYNCHRONIZATION
