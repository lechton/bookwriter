# md-pre-lectures — Pre-Lecture / Prelecture Blueprints

This directory stores the **pre-lectures** (or **prelectures**) for the `react-lecture-04` course.

A pre-lecture / prelecture is the **first iteration of the material** before creating the full lecture in `md-lectures/{nn}.md`. It directly mirrors the final lecture headings (`#`, `##`, `###`), mapping every upcoming element into an atomic pre-element bullet (`[p]`, `[code]`, `[components]`, `[figure]`, `[callout]`, `[table]`) with in-situ pedagogical qualifications attached via `◼`. It locks in the technical vocabulary to prevent jargon pollution and ensures complete causal flow across the lecture.

- **Authoring Guide**: See [`../old-instructions/PRE-LECTURE-INSTRUCTIONS.md`](file:///Users/techton/lechton/research-code/bookwriter/diagram-lab/output/react-lecture-04/old-instructions/PRE-LECTURE-INSTRUCTIONS.md) for full rules, skeleton, pre-element taxonomy, and quality gates (legacy; pending rewrite into the new instruction system).
- **Naming Convention**: `{nn}.md` (e.g. `01.md`, `02.md`, ... `100.md`, ... `180.md`), matching question numbers.
