THE THREE TREES OF REACT STRUCTURAL ARCHITECTURE IN DEPTH
1. Module Tree Bundler
Nodes & Edges
Nodes are JavaScript files on disk. Edges are static import statements.
App.jsx → NewsLayout.jsx
Primary Role
Analyzed at build time by Vite/Rollup for bundle splitting and dead-code elimination.
2. Component Tree Structure
Nodes & Edges
Nodes are component definitions. Edges represent parent-child JSX nesting.
<NewsLayout><HeaderBar/></NewsLayout>
Primary Role
Defines structural hierarchy, top-down prop paths, and component boundaries.
3. Render Tree Runtime
Nodes & Edges
Nodes are live React elements and host DOM tags for the currently rendered frame.
div.layout → header → h1
Primary Role
Governs reconciliation, top-down re-renders, and automatic subtree unmounting.
