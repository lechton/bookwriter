ES MODULE EXPORT ARCHITECTURE DEFAULT VS NAMED EXPORTS IN REACT
Default Export PRIMARY COMPONENT
1. Declaration Syntax
export default function ArticleCard()
Flags single primary component of file.
2. Namespace Binding
moduleNamespace.default
Binds internally to the .default key.
3. Import Syntax
import ArticleCard from './Card.jsx'
Imported directly without curly braces.
Clean, canonical import representing the entire component file.
Named Export COMPANION HELPERS
1. Declaration Syntax
export function formatRole(role)
Flags specific utility or sub-component.
2. Namespace Binding
moduleNamespace.formatRole
Binds to exact property identifier.
3. Import Syntax
import { formatRole } from './Card.jsx'
Imported strictly with matching curly braces.
Allows multiple utility functions to share the module file cleanly.
