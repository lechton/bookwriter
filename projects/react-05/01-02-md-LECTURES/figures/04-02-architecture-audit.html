JSX Grammar & React Fragments

Contrasting permissive HTML markup against strict JSX compiler syntax invariants.

Dimension Syntax Invariant Permissive HTML Plain HTML Markup Fails in JSX Compiler Strict JSX & Fragment React JSX <>...</> Compiler Compliant
Root Return Grammar Adjacent Siblings
Returning <h2> and <p> directly crashes the build because JavaScript functions cannot return two values. 		Single Expression
Wrapping in <>...</> compiles to a single function call: _jsx(Fragment, { children: [...] }).
DOM Node Pollution Unwanted Wrapper <div>
Adding a physical wrapper div satisfies the single-return rule but inserts an unnecessary node into the browser DOM. 		Zero DOM Overhead
React Fragment renders zero wrapper elements in the browser DOM, mounting children directly into the parent.
CSS Layout Hierarchy Breaks Flex / Grid
Wrapper divs turn flex children into grandchildren, breaking gap, row alignment, and column spans. 		Preserves Direct Flow
Children remain direct items of the parent Flexbox or Grid container, preserving layout alignment perfectly.
Tag Closing & Attributes Unclosed & class
Unclosed <img> tags cause fatal parser errors. The class attribute collides with JavaScript reserved words. 		Self-Closing & className
Explicit self-closing <img /> and camelCase className map cleanly to DOM properties.
