Architecture Audit
Splitting Components Across Files with ES Modules

Contrasting monolithic file clutter against modular ES module architecture.

Dimension Module Boundary Monolithic Model Single File Bloat Merge Conflicts & Ambiguity Modular Model ES Module Splitting Isolated Responsibilities
File Architecture 1,200-Line Monolith
Bundles five components in one file; editing a single badge forces git conflicts across multiple developers. 		Dedicated Files
Extracts each component into a dedicated module file in src/components/, isolating concerns.
Primary Export Ambiguous Identifiers
Uses multiple named exports without designating a primary component, forcing consumers to guess module roles. 		export default
Designates the single primary component of the file with export default, imported cleanly without curlies.
Utility Helpers Scattered Utilities
Places tiny formatters in distant global utility folders, disconnecting them from the components that use them. 		Co-located Named Exports
Exports companion helpers like formatRole as named exports alongside their companion component.
Import Safety Curly Brace Mismatch
Writing import { Card } on a default export assigns undefined and crashes React during render. 		Explicit Syntax
Imports default components bare (import Card) and named helpers in braces ({ helper }).
