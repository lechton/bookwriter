## 1. Context & Motivation
Previously, the lecture compiler (`src/build-lectures.mjs`) generated multi-theme reader decks using the prefix `React R5 ${rangeSlug}` for all pipelines, resulting in file names like `React R5 Q01-Q06*.pdf` in standard lectures and `React R5 Q01-Q02*.pdf` in revised lectures. Furthermore, when compiling a single targeted lecture (e.g., `node src/build-lectures.mjs 02`), the compiler skipped deck compilation entirely (`if (!isSingle)`), leaving the multi-theme decks in `02-03-md-revised-pdf/` un-updated during iterative revision workflows.

To align output filenames with curriculum versioning and guarantee up-to-date revised decks:
1. Standard lecture decks must be prefixed with `React v5.1 ${rangeSlug}` (e.g. `React v5.1 Q01-Q06*.pdf`).
2. Revised lecture decks must be prefixed with `React v5.1-rev ${rangeSlug}` (e.g. `React v5.1-rev Q01-Q02*.pdf` or `React v5.1-rev Q01-Q06*.pdf`).
3. All four colour theme decks (default alias, `-teal`, `-black`, `-old`) must be compiled in the revision pipeline each time the build runs, even when targeting a single lecture.
4. Stale legacy files (`React R5 ...`) must be automatically purged upon recompilation.

## 2. Changes Applied
1. **Build Compiler Hardening (`src/build-lectures.mjs`)**:
   - Added `isRevised` detection to `buildDirectory`: sets `defaultPrefix` to `'React v5.1-rev'` when building `dirs.mdLecturesRevised`, and `'React v5.1'` for standard lectures.
   - Added `alwaysBuildDeck = false` parameter to `buildDirectory`, passing `true` for `dirs.mdLecturesRevised`.
   - Conditioned deck generation on `shouldBuildDeck = (!isSingle || alwaysBuildDeck)`.
   - In `buildDirectory`, when `isSingle && alwaysBuildDeck`, reads all available source markdown files in `inputDir` to construct a complete `readerBody` containing every revised lecture, ensuring comprehensive deck generation.
   - Updated stale deck file cleanup regexes in both HTML and PDF passes to `/^React\s*(?:(?:R5|v5\.1(?:-rev)?|19)\s*)?Q\d+-Q\d+.*` so that obsolete `React R5 ...` files are automatically unlinked while keeping the current `React v5.1...` decks.
