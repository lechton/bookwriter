# Brief 2026-09-20-11: Assembly Pipeline Compiler Color Linting & Class Integrity Law

## 1. Context & Autopsy of the Failure in Lectures 05 and 06
When reviewing Lectures 05 and 06 (`05-01-code-assembly-pipeline.html` and `06-01-code-assembly-pipeline.html`), both figures still displayed stark, bleached white cards (`#f8fafc`) with harsh edge strips (`#3b82f6`, `#0d9488`, etc.) and isolated badge coloring.

### Why This Persisted:
1. **Early Legacy Artifacts**: Lectures 05 and 06 were authored prior to the Template 09 pastel standard (`#2026_09_20_08_group_1`).
2. **Mutated Class Names**: Instead of `.step-1..4`, the figures used `.card-1..4`. The card wrapper was styled with `background-color: #f8fafc;` while `.card-main` had zero styling, inheriting the bleached background.
3. **Compiler Blind Spot**: The build pipeline (`src/build-lectures.mjs`) previously only checked whether a figure tag was present in markdown (`/code-assembly-pipeline/`), but never opened or inspected the figure file itself. Because Prince compiles HTML without errors regardless of CSS colors, broken and bleached figures passed builds with 0 warnings.

## 2. Technical Decisions & Fixes
1. **Mechanical Build-Time Figure Linting (`src/build-lectures.mjs`)**:
   - The build script now resolves and reads the HTML figure from disk.
   - Mechanically detects and warns if `#f8fafc` or `#ffffff` is used on card containers.
   - Mechanically verifies the presence of all 4 canonical pastel colors:
     - `#d4e1f1` (Step 1 blue)
     - `#d0e6e1` (Step 2 teal)
     - `#f9e0c5` (Step 3 amber)
     - `#d2ebc9` (Step 4 green)
   - Mechanically detects and warns against mutated `.card-[1-4]` class names, requiring `.step-1..4`.
2. **Instruction Codification (`skills/figures/SKILL.md`)**:
   - Enhanced Section 26B with the Class-Name Integrity Law, Anti-Bleaching Law, and compiler enforcement notice.
3. **Verification Gate (`skills/verification/SKILL.md`)**:
   - Updated Gate 17 to include the mechanical compiler audit.
4. **Lecture 05 & 06 Remediations**:
   - Re-skinned `05-01-code-assembly-pipeline.html` and `06-01-code-assembly-pipeline.html` to 1:1 Template 09 pastel standard.
   - Cleaned Unicode characters from `05-02` and `06-02` to ensure zero Prince font warnings.
