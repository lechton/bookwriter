## 1. Context & Motivation
In `react-lecture-05`, combined reader PDFs and multi-theme deck artifacts were previously generated with the legacy `React 19 Q{first}-Q{last}*.pdf` naming convention. Under Group 1, the `R5` curriculum identifier was added, yielding `React R5 19 Q{first}-Q{last}*.pdf`. Under Group 2, the legacy `19` version marker is completely and algorithmically removed via regex, standardizing all deck outputs cleanly on `React R5 Q{first}-Q{last}*.pdf` (e.g. `React R5 Q01-Q06-old.pdf`, `React R5 Q01-Q06-black.pdf`, `React R5 Q01-Q06-teal.pdf`, and `React R5 Q01-Q06.pdf`).

## 2. Changes Applied
1. **Algorithmic Deck Naming & Legacy Stripping (`#2026_09_21_21_group_2`)** (`src/build-lectures.mjs`):
   - Used regex `/^React\s*(?:R5\s*)?(?:19\s*)?Q/i` to algorithmically identify deck arguments requiring automatic range slugs.
   - Set canonical format to `React R5 ${rangeSlug}` (e.g. `React R5 Q01-Q06`).
   - For custom deck titles or filenames, applied algorithmic regex stripping: `.replace(/\b19\s+/g, '').replace(/\s+/g, ' ').trim()`.
   - Updated stale file cleanup regexes in both HTML and PDF compilation routines to `/^React\s*(?:R5\s*)?(?:19\s*)?Q\d+-Q\d+.*\.html$/i` and `/^React\s*(?:R5\s*)?(?:19\s*)?Q\d+-Q\d+.*\.pdf$/i`.
   - Any prior deck files (including `React 19 Q...` and `React R5 19 Q...`) that do not match `resolvedDeckFileName` are automatically unlinked on build.
