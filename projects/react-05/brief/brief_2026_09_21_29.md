# Decision Brief: React v5.2 Standard and React v5.2-rev Multi-Theme Deck Generation Law (#2026_09_21_29_group_1)

**Date**: 2026-09-21
**Rule Tag**: `#2026_09_21_29_group_1`
**Components Affected**: `src/build-lectures.mjs`, `skills/build/SKILL.md` (Section 03), `skills/lecture-revision/SKILL.md` (Section 08), `skills/RULE-TAGS.md`

---

## 1. Problem Statement & Context

The course deck version in `react-lecture-05` was previously set to `React v5.1` / `React v5.1-rev`. To reflect the latest course curriculum and design refinements, the version standard for multi-theme course reader decks is advanced to **`React v5.2`** for standard production lectures and **`React v5.2-rev`** for junior-friendly revised lectures.

---

## 2. Changes Applied

### A. Compiler Deck Generation (`src/build-lectures.mjs`)
- Updated `defaultPrefix` in `buildDirectory`:
  ```javascript
  const defaultPrefix = isRevised ? 'React v5.2-rev' : 'React v5.2';
  ```
- Updated deck filename and title resolution regexes:
  ```javascript
  /^React\s*(?:(?:R5|v5\.[12](?:-rev)?|19)\s*)?Q/i
  ```
- Updated stale deck unlinking regexes in both HTML and PDF passes:
  ```javascript
  /^React\s*(?:(?:R5|v5\.[12](?:-rev)?|19)\s*)?Q\d+-Q\d+.*\.html$/i
  /^React\s*(?:(?:R5|v5\.[12](?:-rev)?|19)\s*)?Q\d+-Q\d+.*\.pdf$/i
  ```
  This automatically cleans up any leftover `React v5.1...` artifacts on build.

### B. Skill Updates
- `skills/build/SKILL.md` (Section 03): Updated deck naming to `React v5.2 Q{first}-Q{last}*.pdf` across all three themes (`-teal`, `-black`, `-old`, and default untagged).
- `skills/lecture-revision/SKILL.md` (Section 08): Updated revision multi-theme deck references to `React v5.2-rev Q{first}-Q{last}*.pdf`.
