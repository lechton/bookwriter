## Context & Defect Analysis
In Lecture 03, Step 2 (`ArticleHeader.jsx`), the pedagogical crossroad opened with:
> "To read that data, you have two clear options:"
followed immediately by a bare code block titled `Baseline Option: The Explicit Props Object`. This was followed by prose stating:
> "In this baseline pattern, the function receives the complete props object. To read the title, you must write props.headline. This works, but typing props. across larger components creates unnecessary clutter. In modern React, we choose the unpacked pattern using JavaScript parameter destructuring:"
followed by a second code block titled `Modern Unpacked Option`.

This presentation suffered from two severe pedagogical defects:
1. **The Vague Presentation Trap**: The options were announced vaguely with a single handwaving transition. The reader had no visual roadmap of what the two choices were before seeing the first code snippet. Dropping directly into code without declaring the options upfront reads like an accidental discovery rather than a structured comparison.
2. **Shifting Artistic Vocabulary**: The author constantly shifted vocabulary across sentences and headings, describing technical choices like an artist ("Baseline Option: The Explicit Props Object", "baseline pattern", "unpacked pattern", "Modern Unpacked Option"). A master educator maintains steady, grounded vocabulary throughout the lesson.

## The Solution: Visual-First Declaration & Anti-Shifting Vocabulary Law
1. **Visual-First Numbered List Protocol**: Before presenting comparative code snippets, the author must declare both options explicitly in a visual numbered list in the text, declaring what each option is and previewing the concrete syntax tokens (e.g. Option 1: The foundational way `props.headline` vs Option 2: The modern idiomatic way `{ headline }`).
2. **Anti-Shifting Vocabulary Law (The Wise Educator Standard)**: Ban decorative, shifting labels and artistic descriptions. Maintain strict lexical consistency across the introductory numbered list, code block titles, prose explanations, and margin comments.
3. **Explicit Counter-Example Codified**: The vague presentation pattern is explicitly recorded in `skills/pedagogical-crossroads/SKILL.md` as a negative counter-example to prevent regressions.
