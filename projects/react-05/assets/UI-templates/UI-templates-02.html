1. Flat Design Principles & Structural Directness SERIES 02 STANDARD

Design Philosophy & Core Primitives:
  1. Directness & Visual Elegance: Replaces heavy multi-layered inspector badges with pure, self-evident flat-design UI elements. A button looks like a button, an input looks like an input, and a badge looks like a capsule badge.
  2. Unambiguous Element Descriptors: Clean monospace descriptors (e.g. [blockquote], [button], [input: text], [figure.media]) sit subtly atop flat controls via .flat-elem[data-elem], ensuring zero confusion between component roles and rendered HTML elements.
  3. Solid Colored Tabs & Dashed Boundaries: Components declare their scope with vibrant, colored dashed perimeters and flush top-left solid tabs (#334155 Shell, #7c3aed Header, #0284c7 Profile, #d97706 Badge, #2563eb Card, #0891b2 Form).
  4. Rounded Capsule Badges (.surface-ui-badge): Rendered with soft pastel backgrounds (#e0f2fe), subtle borders (#bae6fd), and dark contrast text (#0369a1) for reader greetings, status tags, and counts.
  5. Solid Flat Buttons (.surface-ui-btn): Saturated, high-contrast flat buttons (#0891b2 teal, #7c3aed purple) with bold typography that convey immediate interactivity.
  6. Preserved Textbook Proportions: Outer window, macOS dots, title bar, blue-slate stage, and max-width 560px canvas remain 100% compliant with the canonical textbook design.
