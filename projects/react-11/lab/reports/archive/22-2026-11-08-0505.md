## Fixes in the lecture

1. Principle 5, the pointer coordinates.
   - Old: "When the user moves the pointer across the page, the browser gives the event object two numbers: `e.clientX`, how far across the page the pointer is from the left edge, and `e.clientY`, how far down the page the pointer is from the top edge."
   - New: "When the user moves the pointer across the page, the browser gives the event object two numbers. `e.clientX` is how far the pointer is from the left edge of the browser window, and `e.clientY` is how far it is from the top edge."
2. Follow-up question 2, when the Effect runs, and a quote that could not be checked.
   - Old: "Because an **Effect** runs **after** React has already rendered and painted the screen." and "React's docs call this pattern "both unnecessary and inefficient.""
   - New: "Because an **Effect** runs **after** React has already rendered the component and put the result on the page." and "React's docs say this is more complicated than necessary, and inefficient too."
3. Every browser preview of the team page.
   - Old: `card: Team`, which the build draws as an empty card, so the `Team` heading from `<h1>Team</h1>` was missing from all ten previews.
   - New: `heading: Team`, which draws the heading the real page shows.
