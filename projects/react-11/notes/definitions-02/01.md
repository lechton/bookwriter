

What is a component? The components are the building blocks of the web application. For example, when a blog has a header on top and articles in the middle, and footer in the bottom, these are three components, they represent 3 parts of the web application. What is cool with components is you can reuse them. For example if you want a button you can create one component <Button> and reuse it every time you want to create a new button. Something that can be tricky is that components are nested. This means one component is inside another. This nesting can be many levels in, for example a button <Component> can be placed inside a component named <Card> which can be inside a component named <Sidebar> which rests in the left side of the website. And then in turn the <Sidebar> can be nested inside a <Main> component which has all the elements of the website. If you noticed so far all components in React start with capital leter, you are allowed to write <Article> but not <article>, why? Because small letter components can be confused with normal html. There is an existing <article> tag in html and if React allowed small letter components it could create confusion. 


Code snippet: 
> [name, setName] = useState("John")

What is a setter? In any programming language we need to be able to create variables and change variables. In Javascript you  create a variable  "name" and define it as "John". Then you can change the variable. The change is also called mutation. At any point, you can change name into "Peter", "Steven", or "Mary". You get the picture. You can do this with any programming language relatively simple. You cannot do this in React, at least not for the variables that matter. The most important variables, those that become part of the State of the component, which is the persitent memory of the component,  you cannot just define a new variable and then change it. You need a variable "name"? You need to put it inside a special function named `useState`. To define name as "John" you write useState("John"). To define name as "Peter" you write useState("Peter"). To define name as "Mary" you write useState("Mary"). But every time you do this, React gives you back also another function, the setter, which you need to use when you want to change the variable. So to mutate the variable name you need to say setName("John"). If you want to change it into "Mary" you need to write setName("Mary") etc. So to summarize, when you define new variable you write useState("John"). But when you change the existing variable you write the new value with a setter, e.g. setName("John").
