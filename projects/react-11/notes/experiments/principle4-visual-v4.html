Principle 4

Write One Handler for Multiple <input> Boxes [e.target.name]

1
The Goal

Updating two properties of the same object

Suppose we have a person object in state and two <input> boxes on the screen. We type "John" in the first box, then "Robinson" in the second.

On the screenperson in state
NameSurname
 { name: "", surname: "" }
NameJohnSurname
 { name: "John", surname: "" }
NameJohnSurnameRobinson
 { name: "John", surname: "Robinson" }
2
The Problem

Look at the two setPerson lines we end up writing

If we write a separate function for each <input> box, we write:

setPerson({ ...person, name: e.target.value })
setPerson({ ...person, surname: e.target.value })

Everything in those two lines is identical except for one word: name versus surname.

3
The Solution

Replace both lines with [e.target.name]

Instead of writing name: in one function and surname: in another, we write one single function:

setPerson({ ...person, name: e.target.value })
setPerson({ ...person, surname: e.target.value })
↓
setPerson({ ...person, [e.target.name]: e.target.value })

Then we label the first <input> box with name="name" and the second with name="surname", so [e.target.name] knows which property to change:

The <input> boxWe typeBecomes
<input name="name" />Johnname: "John"
<input name="surname" />Robinsonsurname: "Robinson"

One single function gives us { name: "John", surname: "Robinson" }

4
In Code

One function for both boxes

✓ DO THISOne function for both <input> boxes
function handleChange(e) {
  setPerson({ ...person, [e.target.name]: e.target.value });
}

<label>Name <input name="name" onChange={handleChange} /></label>
<label>Surname <input name="surname" onChange={handleChange} /></label>
✗ DO NOT DO THISA separate function for each <input> box
function handleNameChange(e) {
  setPerson({ ...person, name: e.target.value });
}

function handleSurnameChange(e) {
  setPerson({ ...person, surname: e.target.value });
}

<label>Name <input onChange={handleNameChange} /></label>
<label>Surname <input onChange={handleSurnameChange} /></label>
