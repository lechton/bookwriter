PRINCIPLE 4

Write One Handler for Multiple <input> Boxes

The tool that makes it work: [e.target.name]
1
The Goal

Updating two properties of the same object

A person object in state, and two <input> boxes on the screen.

At the start
{ name: "", surname: "" }
Type in the first boxJohn
{ name: "John", surname: "" }
Type in the second boxRobinson
{ name: "John", surname: "Robinson" }
2
The Problem

Look at the two setPerson lines we end up writing

With a separate function for each <input> box:

First <input> box
setPerson({ ...person, name: e.target.value })
Second <input> box
setPerson({ ...person, surname: e.target.value })
Everything in those two lines is identical except for one word: name versus surname.
3
The Solution

Replace both lines with [e.target.name]

Instead of name: in one function and surname: in another, we write one single function:

setPerson({ ...person, name: e.target.value })
setPerson({ ...person, surname: e.target.value })
↓
setPerson({ ...person, [e.target.name]: e.target.value })

Then we label each box with name="...", so [e.target.name] knows which property to change:

<input name="name" />
type "John"
name: "John"
<input name="surname" />
type "Robinson"
surname: "Robinson"
One function, both boxes:{ name: "John", surname: "Robinson" }
4
In Code

One function, or one function per box

✓ DO THIS One function for both boxes
function handleChange(e) {
  setPerson({ ...person, [e.target.name]: e.target.value });
}

<label>Name <input name="name" onChange={handleChange} /></label>
<label>Surname <input name="surname" onChange={handleChange} /></label>
✗ DO NOT DO THIS A separate function for each box
function handleNameChange(e) {
  setPerson({ ...person, name: e.target.value });
}

function handleSurnameChange(e) {
  setPerson({ ...person, surname: e.target.value });
}

<label>Name <input onChange={handleNameChange} /></label>
<label>Surname <input onChange={handleSurnameChange} /></label>
