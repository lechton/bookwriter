# Archive of the skills

These are old versions of the skill files, kept as a copy before every edit. Never read or follow them as current rules. The current skills are in the newest `skills/vX.Y/` folder.

The folders here have the same shape as the skills: `v11.3/intro/` holds the old files of `skills/v11.3/intro/`. Each name ends with the date and a number, such as `SKILL_2026_11_15_001.md`. The brief with the same date tells why the file was changed.
