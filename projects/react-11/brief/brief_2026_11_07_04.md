# Brief 2026-11-07 04: What the reader learns stays learned across the lecture

## Why this batch exists

When Lecture 20 was rewritten under `brief_2026_11_07_03`, the writer pasted the owner's Clear button opening, which teaches `name`, `setName`, `onChange`, and `value`, and then in Principle 1 explained `name`, `setName`, and `onChange` all over again from scratch. Across the rest of the chapter, almost every code block was preceded by boilerplate definitions such as "Here the state is `message`, and the function that changes it is `setMessage`" and "puts `e.target.value` into `name` with `setName`".

Five lines in `skills/v10.4/` had pushed the writer to treat the reader as if their memory reset every few paragraphs:
- `writing` Section 1 said "a code line they saw three paragraphs ago is a memory, not something in front of them", without saying that what the lecture has already taught stays learned.
- `writing` Section 2 said "When an explanation starts from one of them [words from an earlier lesson], say what it does on this page before you build on it", which the writer applied inside every principle instead of once in the chapter opening.
- `writing` Section 3 said "The reader may have forgotten the picture above, so give them everything again".
- `writing` Section 7 asked for four full names the first time any passage needed them, including "what our code does in reply", and did not warn that translating code lines into prose ("puts `delivery` into `topic` with `setTopic`") is still reciting the code block.
- `check` Step B listed "a handler explained before the reader is reminded which state it changes" under *Something missing*, which directly triggered a second pass that injected state-and-setter reminders before every handler in Lecture 20.

Following Fix before you add, this batch prunes those five triggers and adds a living PROPER and COUNTER-EXAMPLE pair to `writing` Section 1 showing how Principle 1 builds on the opening without re-teaching it.

- PROPER and COUNTER-EXAMPLE in `writing` Section 1: the Lecture 20 Principle 1 passage right after the owner's opening.
