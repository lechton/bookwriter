# Brief 2026-11-14 03: teach how to think, not a simpler copy of the docs

## Why
While auditing Lecture 32, the owner found that the text simplified the React docs instead of teaching how to think. The example was the dependency array: the docs say "you can't choose your dependencies", but the developer does choose, one step earlier, by deciding what the Effect stays in sync with and writing its code to read those values. The owner then wrote a new section in the intro skill, a new warning section in method-writing.md, and saved the discussion as method-example-01.md, and asked for the issues in them to be fixed with "ppp".
