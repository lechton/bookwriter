## What was edited so the paths and links agree

- Skills, maps, and the prompt: every folder path `.../v2/` became `.../v1/`, `skills/v9.4/` became `skills/v10.1/`, `projects/react-09` became `projects/react-10`, skill names such as `verification-v2` became `verification-v1`, and "River Version (`v2`)" became "River Version (`v1`)". Lines that warned against the Original Version `v1` now name it as the Original Version of `projects/react-09`, so they no longer ban this project's own folders. No rule changed.
- Maps keep their provenance: a line such as "Skills Loaded" now names `projects/react-09/skills/v9.1/v2/...`, the skills the map was really written with.
- Lectures and drafts had no version paths and are unchanged.
- `src/build-river.mjs` reads and writes the `v1` folders through one `VERSION` constant, imports `./editor.mjs`, and labels the old theme "River Version (v1)".
- `archive_lecture.py` archives maps, drafts, pre-lectures, lectures, HTML, and PDF of one lesson; the react-09 revision folders, which this project does not have, are gone from its list.
- `skills/v10.1/README.md` and `skills/v10.1/RULE-TAGS.md` are new: one River skill set, the pipeline, and the ten River rule groups carried over so every tag in the skills resolves.
- `questions/README.md` names its new home and points to the react-09 briefs of the Versions table.
- HTML and PDF were rebuilt with `node src/build-river.mjs`, so the old theme carries the `v1` label.
