# Brief 2026-11-12 01: React 11 begins, with skills v11.1 as its first skill set

Tag: #2026_11_12_01_group_1

## Decision

The owner asked for a new project, `projects/react-11`, made as an exact copy of `projects/react-10`, with skills `v11.1` as its first skill set and the default. React-10 stays as it is, as history. When a React request names no project, the active project is now react-11.

## What was copied

Everything in `projects/react-10` was copied unchanged into `projects/react-11`: the syllabus cards, the maps, the drafts, the pre-lecture, the lectures with their `archive/` folders, the HTML and the PDF, the question bank, the briefs, the audits, the notes, the lab with its cases and reports, the build scripts, `archive_lecture.py`, and `ARCHIVE-LOG.md`. The lessons keep their folder names, such as `01-02-md-LECTURES/v1/`, and their text is unchanged.

## What changed so the names and links agree

1. `skills/v11.1/` is a copy of `projects/react-10/skills/v10.7/`. The older sets `v10.1` to `v10.7` are not carried over; they stay in `projects/react-10/skills/`.
2. `skills/v11.1/README.md`: the title, the first lines, the link to the prompt, and the line on which skills to load now name `v11.1` and `projects/react-11`. The older lines on `v10.7` and `v10.6` are kept, and one line says where the earlier sets live.
3. `skills/v11.1/RULE-TAGS.md`: the title names `v11.1`, one new line says the older rows were made in react-10, the link to the `v10.4` registry points to `projects/react-10`, and one row records this copy. The older rows keep their paths, because they name where each edit was made.
4. In `check`, `lecture`, `editing-skills`, `map`, `figures`, and `examples`, every `projects/react-10`, `skills/v10.7/`, "react-10", and "React 10" that names the live project or skill set now names react-11 and `v11.1`. Lines that tell history, such as "written under `v10.3`", are unchanged.
5. `notes/prompt_v11.1.md` is a copy of `notes/prompt_v10.7.md` with `SV = v11.1` and `projects/react-11`. The older prompts `prompt_v10.1.md` to `prompt_v10.7.md` stay in `projects/react-10/notes/`.
6. `archive_lecture.py`, `lab/README.md`, `lab/package.json`, and `lab/package-lock.json` name react-11.
7. `questions/README.md` names its new home and says the bank was copied unchanged from react-10.
8. The maps of Lessons 21 to 26 linked to the `v10.5` and `v10.6` Opening Essence they were written with. Those links now point to `projects/react-10/skills/`, so they keep their provenance.
9. `AGENTS.md`: react-11 is in the project registry and is the default React project; react-10 is marked as continued in react-11; the mirror list names `projects/react-11/skills/v11.1/`.

No rule, example, or checklist changed.
