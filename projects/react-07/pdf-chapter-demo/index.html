LECTURE 17

Batching &
Updater Functions

INTERVIEW QUESTION  |  > CORE

How does React queue multiple state updates, and when do you need an updater function?

01
EVENT
HANDLERS (Lecture 13)

You respond to user actions by attaching a function to an element, such as:

<button onClick={handleClick}>

You pass the function without calling it. React runs that event handler every time user clicks.

02
STATE & SETTERS (Lecture 14)

Any value that changes on screen must live in state.

const [tickets, setTickets]
  = useState(0)

1. tickets is the state variable (starts at 0).

2. setTickets is the setter (only way to request, a new value).

04
FIXED SNAPSHOTS (Lecture 16)

During a render and its handlers, the value of never change is tickets changes. It remains locked as a fixed number called a snapshot.

05
RENDER PURITY (Lecture 16)

Any code that runs during a render be pure, inputs, it return the same output. It must never alter external variables or trigger popups.
