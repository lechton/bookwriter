LESSONS FROM THE CODE
Event Wiring, Inverse Data Flow & Propagation Boundaries

Contrasting naive execution mistakes and bubbling traps with declarative callback architecture

Component Layer File & Scope Naive Antipattern Broken Event Wiring Premature Calls & Collisions Idiomatic Architecture Declarative Callbacks Controlled Inverse Flow
App.jsx Application Shell ×Premature execution & direct mutation: Invokes handlers inside JSX braces (onClick={handleSelect()}) firing during render, or assumes child can mutate parent state directly. ✓Declarative callback handlers: Defines action handlers at the owner level and passes uncalled function references down as props (onSelect={handleSelect}).
ArticleCard.jsx List Item Boundary ×Unwired custom props: Places onClick on custom component tags expecting automatic DOM binding, leaving clicks ignored and silently dropped. ✓Forwarded callbacks & arrow arguments: Wires callback props to native button elements and wraps argument calls in inline arrow functions (() => onSelect(article.id)).
ActionButton.jsx Terminal Control ×Non-semantic tags & unstopped bubbling: Uses clickable div tags that trap keyboard users, and allows clicks to bubble up, triggering parent selection unexpectedly. ✓Semantic buttons & propagation control: Uses native button elements for full keyboard accessibility and calls e.stopPropagation() to isolate nested button actions.
Verdict Broken & Inaccessible: Executing handlers during render breaks click response, unstopped propagation creates conflicting actions, and non-semantic click targets exclude keyboard users. Predictable & Accessible: Passing function references, using callback props for inverse flow, stopping propagation when actions nest, and using native buttons creates robust interfaces.
