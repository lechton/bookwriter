Architecture Audit: Container Composition and Attribute Forwarding

Contrasting monolithic layout flags against composable slot containers and clean prop spreading.

Component Layer Naive Pattern Monolithic Mega-Card Layout Prop Explosion React Contract Composable Container Slot Composition
<EditorialGrid /> Caller Component ✕ Passes twenty boolean flags (hasBadge, hasImage, showAuthor) to configure rigid internal card layouts. ✓ Nests custom markup directly inside <CardContainer> tags, composing badges, headlines, and summaries freely through open slots.
<CardContainer /> Slot Container ✕ Omits {children} causing content to drop silently, or treats children as an array and crashes on single child elements with children.map. ✓ Mounts {children} where content belongs; treats children as an opaque descriptor tree without calling fragile array methods.
{ ...rest } Attribute Forwarding ✕ Spreads full props onto <div {...props}>, triggering unknown-prop warnings (isFeatured) and leaking attributes to the DOM. ✓ Destructures consumed props (color, children) and forwards only ...rest to the DOM node, preserving accessibility attributes cleanly.
className = '' Precedence & Defaults ✕ Places static className="card" before spread, allowing caller classes to overwrite base styles or producing "card undefined". ✓ Destructures className = '' with an ES fallback and merges classes explicitly (`card card-${color} ${className}`.trim()).
Architectural Verdict
Rigid Fragility: Parameter explosions require editing shared files for every design change; attribute leakage triggers console warnings and crashes.
Composable Resilience: Inversion of control decouples outer framing from inner content; clean rest forwarding and explicit class merging protect styling invariants.
