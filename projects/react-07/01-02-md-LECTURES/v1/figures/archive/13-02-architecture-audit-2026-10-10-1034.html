Event Handling & Callback Architecture
The Architecture of Event Handling

Contrasting premature invocation, custom prop silence, and inaccessible targets with declarative function references and callback wiring

Dimension Event Mechanism Anti-Pattern Fragile / Naive Practice Premature Calls & Ignored Props React Reality Declarative Architecture Controlled Callback Contracts
Handler Binding Function Reference ✕ Immediate Invocation in JSX
Writing onClick={handlePublish()} invokes the function during render on page load, logging actions prematurely and failing to respond to clicks. 		✓ Passing Function as Value
Writing onClick={handlePublish} passes the uncalled function reference, allowing React to execute it only when the user clicks the element.
Supplying Arguments Parameterized Calls ✕ Inline Function Execution
Calling onClick={openArticle(id)} evaluates immediately during JSX evaluation, triggering calls for every list item during rendering. 		✓ Inline Arrow Function Wrapper
Writing onClick={() => openArticle(id)} passes an anonymous arrow function that delays invocation until the click event occurs.
Component Boundary Custom Component Props ✕ Assuming Native DOM Propagation
Passing onClick to <ArticleCard onClick={...} /> assumes custom components automatically receive browser events without explicit wiring. 		✓ Explicit on Prop Delegation
Custom components accept semantic callback props (like onSelect) and wire them internally to built-in DOM elements like <button>.
Target Semantics Accessibility (a11y) ✕ Generic Clickable Containers
Placing onClick on <div onClick={...}> creates controls that cannot be focused with Tab or triggered with Enter or Space keys. 		✓ Native Interactive Elements
Using <button type="button" onClick={...}> guarantees keyboard navigation, focus indicators, and screen reader announcements for free.
Data Communication Child-to-Parent Flow ✕ Direct Parent State Mutation
Children attempting to directly mutate parent variables or reassign outside state breaks unidirectional data flow. 		✓ Inverse Data Callback Notification
Parent passes callback function down, child invokes callback with arguments on user interaction, parent retains update authority.
Verdict Premature Execution & Inaccessible Controls
Invoking handlers during render and using generic <div> tags causes phantom actions, broken listeners, and excludes keyboard users. 		Predictable Actions & Accessible Interfaces
Passing function references to native buttons and wiring callback props guarantees clean, accessible, and deterministic user interactions.
