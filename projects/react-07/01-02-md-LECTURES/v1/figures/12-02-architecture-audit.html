LESSONS FROM THE CODE
Component Purity, Render Isolation & StrictMode Resilience

Contrasting naive mutable state and DOM writes with idiomatic pure functional rendering

Component Layer File & Scope Impure Antipattern Naive Mutable Execution Corrupted State & Drift Pure Architecture Deterministic Formula Resilient on Every Render
App.jsx Application Shell ×Module-level counter: Increments an external variable during the mapping loop. StrictMode double-rendering doubles the output numbers (#2, #4, #6), and later renders cause numbers to climb without bound. ✓Index-derived numbering: Calculates position purely from array mapping (position={index + 1}) and passes it downward as an explicit prop. Output is 100% deterministic across any number of renders.
ArticleCard.jsx List Item Boundary ×External array mutation: Calls array.push() on module variables or props during render. Duplicate items accumulate on every render pass, triggering key collision errors and memory leaks. ✓Local mutation isolation: Creates brand-new local arrays or copies with spread syntax inside the function body. Modifying local arrays before returning JSX remains completely safe and invisible to other components.
ReadingStatus.jsx Presentation Leaf ×Imperative DOM mutation: Queries elements via document.getElementById() to set className directly during render. Throws fatal TypeError crashes on initial render because DOM nodes do not exist yet. ✓Declarative JSX calculation: Evaluates inline ternary conditional expressions directly inside returned JSX. React safely reconciles class names and attributes during the commit phase with zero manual DOM queries.
Verdict Fragile & Unstable: Impure components break under StrictMode, produce conflicting state during concurrent rendering, and fail silently or crash when called multiple times. Pure & Resilient: Treating components as pure formulas (UI = f(props)) guarantees identical markup for identical inputs, enabling seamless caching, server rendering, and safe concurrent restarts.
