Component Anatomy & Capitalization Architecture Audit

An architectural comparison evaluating how React compiles custom components, enforces PascalCase, and executes declarative trees.

Contract Dimension Naive JavaScript Reflex (Anti-Pattern or Crash) React Platform Reality (Compiler & Runtime Contract)
1. Capitalization (AST Branching) Lowercase Function Tags Transpiler compiles <articleCard /> to string literal _jsx("articlecard"), creating an empty unknown HTML element that fails silently. PascalCase Identifiers Transpiler compiles <ArticleCard /> to unquoted identifier _jsx(ArticleCard), instructing React to invoke the component function.
2. Return Model (DOM Manipulation) Imperative DOM Append Calling document.body.append() during render mutates the browser before reconciliation, leaking nodes and duplicating UI elements. Declarative UI Descriptors Components return lightweight JSX objects describing target markup, allowing React to diff in memory and perform surgical DOM updates in the commit phase.
3. Invocation Mode (Tree Attachment) Direct Function Calls Calling {ArticleCard()} executes synchronously as raw JavaScript, inlining markup directly without registering an independent fiber in the React tree. Declarative JSX Tags Writing <ArticleCard /> creates an independent fiber node with dedicated lifecycle tracking, isolated reconciliation, and future hook support.
4. Return Grammar (Expression Shape) Adjacent Root Elements Returning multiple sibling tags without an enclosing wrapper violates JavaScript return grammar: return _jsx() _jsx() is an illegal syntax error. Single Root Container Enclosing siblings in a single parent tag or React Fragment (<>...</>) evaluates into a single function call expression that returns legally.
5. Render Purity (Idempotence) Mutating Global State Altering outside variables during render breaks during StrictMode double-invocation, producing desynchronized counts and race conditions. Pure Mathematical Calculation Component acts as a pure function: UI = f(data), returning identical UI descriptors for the same inputs with zero observable side effects.
Architectural Verdict Silent Failure & Drift Treating components like normal JavaScript functions ignores compiler AST contracts and corrupts the virtual DOM render tree. Reliable Component Contracts PascalCase functions returning declarative UI descriptors guarantee predictable execution, safe reconciliation, and robust tree management.
