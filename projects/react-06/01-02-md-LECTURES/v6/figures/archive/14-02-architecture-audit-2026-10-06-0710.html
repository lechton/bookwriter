Memory Isolation and State Lifecycle in React 19

Contrasting ephemeral function variables against React's durable per-instance Hook memory

Dimension Memory Mechanism Anti-Pattern Local Variable Model Ephemeral Scope & Silent Mutation React Reality Declarative State Hook External Storage & Render Queues
Variable Scope Function Lifecycle ✕ Ephemeral Call Execution
Declaring let likes = 0 resets to zero every time React executes the component function from top to bottom. 		✓ External Fiber Memory
Calling useState(0) retains data in React's external memory slots across multiple render cycles.
Screen Notification Re-render Triggers ✕ Silent Memory Mutation
Assigning likes = likes + 1 changes memory React does not watch, leaving the user interface permanently stuck. 		✓ Setter Render Scheduling
Calling setLikes(likes + 1) stores the next value and queues an immediate component re-render.
Hook Alignment Call Order Tracking ✕ Conditional Hook Invocations
Wrapping useState inside if blocks corrupts the sequential index pointer, causing Hook order mismatch errors. 		✓ Stable Top-Level Sequencing
Calling Hooks unconditionally at the top level guarantees React pairs state slots predictably on every render pass.
Instance Boundary Component Identity ✕ Shared Module Leakage
Moving let likes = 0 outside the component creates global shared state across all cards without triggering renders. 		✓ Private Instance Isolation
Each mounted <StoryCard /> maintains completely independent state; clicking one never touches sibling counts.
Start Values Initializer Performance ✕ Repeated Argument Evaluation
Passing useState(computeInitial()) executes heavy calculation on every render even though React ignores the result. 		✓ Function Reference Initializer
Passing useState(computeInitial) tells React to call the initializer function once during component setup only.
Verdict Silent Failure & Data Loss
Local variables cannot communicate with React or persist across renders, creating unresponsive buttons and lost data. 		Durable Memory & Declarative UI
useState provides durable per-instance memory and setter-driven re-renders, keeping the interface synchronized.
