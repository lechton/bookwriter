REACT PROPS ARCHITECTURE MUTATION TRAP VS IMMUTABLE SNAPSHOT
Direct Prop Mutation ILLEGAL
1. Incoming Props
function Card(props) { ... }
Props passed downward from parent.
2. Child Mutation
props.title = 'Updated';
Child attempts to overwrite parent data.
3. React Runtime Check
Object.isFrozen(props) === true
Throws TypeError in development mode.
Fatal crash: Cannot assign to read only property 'title'.
Unidirectional Data Flow IMMUTABLE
1. Incoming Props
function Card({ title }) { ... }
Unpacked cleanly via destructuring.
2. Derived Variable
const upper = title.toUpperCase();
Computes local value without mutation.
3. React Runtime Check
Pure Component Execution
Parent retains single source of truth.
Deterministic rendering: parent controls data, child renders inputs.
