Event Object, Propagation & Browser Defaults
Responding to Events: Propagation and Browser Defaults

Contrasting unstopped bubbling, reading wrong target attributes, and page-reloading form submits with localized stopPropagation, currentTarget, and preventDefault

Dimension Event Mechanism Anti-Pattern Fragile / Naive Practice Unstopped Cascades & Reloads React Reality Controlled Event Architecture Precise Targets & Containment
Side Effects Location Render vs Handlers ✕ Side Effects in Component Body
Placing network calls, storage writes, or logging in the function body executes them on every render, firing before user interaction. 		✓ Side Effects in Event Handlers
Placing side effects inside event handler functions guarantees they run only when the user clicks, types, or submits.
Target Resolution target vs currentTarget ✕ Reading e.target Attributes
Reading dataset properties from e.target returns undefined when the user clicks a nested icon or text tag inside the container. 		✓ Reading e.currentTarget Attributes
Reading e.currentTarget consistently references the element holding the listener, regardless of which nested child element was clicked.
Text Input Timing onChange vs DOM change ✕ Expecting Event on Blur
Assuming onChange waits for the field to lose focus causes keystroke-by-keystroke logic to fire unexpectedly on every typed character. 		✓ Immediate Keystroke Dispatch
React's onChange normalizes the browser input event, capturing e.target.value immediately on every character typed or deleted.
Event Bubbling Container vs Child Actions ✕ Unstopped Upward Bubbling
Clicking a nested button inside a clickable card allows the click to bubble up to the card, triggering card navigation unintentionally. 		✓ Explicit Local Containment
Calling e.stopPropagation() inside the button's handler halts bubbling, keeping child actions local and calling parent callbacks explicitly.
Browser Defaults Page Reloads & Navigation ✕ Default Form Navigation
Submitting a search form without interception triggers a full-page browser reload, clearing client memory and resetting what was typed. 		✓ Canceling Native Default Action
Calling e.preventDefault() halts browser reload behavior while allowing React event handling to process the search query smoothly.
Verdict Accidental Cascades & Erased Client State
Unstopped bubbling, reading nested targets, and unprevented form reloads trigger unwanted parent actions and wipe application memory. 		Deterministic Containment & Robust Event Flow
Stopping propagation on child actions, reading currentTarget, and canceling form reloads ensures predictable, stable event handling.
