CONTAINER ARCHITECTURE: COMPONENT COMPOSITION REACT 19 COMPONENT TREE
RIGID MULTI-PROPS PROHIBITED
1. Container Signature
ArticleBox({ headline, quote, audio, body, ... })
Container must anticipate every possible child type via separate props.
2. Caller Invocation
<ArticleBox headline="Alert" quote="..." audio="..." />
Consumers cannot customize layout or nest custom widgets without modifying container.
3. Architectural Outcome
Prop Explosion: 10+ props, tight coupling, impossible to support varied editorial desks.
COMPOSABLE CHILDREN SLOT RECOMMENDED
1. Container Signature
ArticleBox({ children, tier = 'standard', ...rest })
Container acts as an open frame; projects arbitrary JSX via {children}.
2. Caller Invocation
<ArticleBox><PullQuote /></ArticleBox>
Parent freely composes any combination of components between tags.
3. Architectural Outcome
Zero Prop Drilling: Decoupled containers, natural JSX nesting, native attribute spreading.
