JSX COMPILER AST ROUTING TAG CAPITALIZATION RULE
Lowercase: <articleCard /> WRONG
1. JSX Syntax Input
<articleCard />
Starts with lowercase letter 'a'.
2. Compiler AST Output
_jsx("articlecard", {})
Emits a static string literal.
3. Browser DOM Action
document.createElement("articlecard")
Creates unknown native HTML tag.
Function ignored: browser renders an empty, unstyled tag.
Capitalized: <ArticleCard /> RIGHT
1. JSX Syntax Input
<ArticleCard />
Starts with uppercase letter 'A'.
2. Compiler AST Output
_jsx(ArticleCard, {})
Emits direct function reference.
3. React Runtime Action
ArticleCard() -> <article>...</article>
Executes function and mounts JSX.
Function runs: browser renders complete editorial card.
