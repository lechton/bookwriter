CONTROL FLOW: CONDITIONAL RENDERING REACT 19 DECLARATIVE BRANCHING
IMPERATIVE & ZERO TRAP VULNERABLE
1. Imperative Mutation
el.classList.toggle('hidden')
Bypasses React reconciliation; causes state desynchronization and layout flicker.
2. The Falsy Zero Trap
{count && <Badge />} (count = 0)
JavaScript evaluates 0 && JSX to 0; React prints a literal "0" text node into DOM.
3. Architectural Outcome
Leaked Text & DOM Drift: Stray zeroes appear on screen; DOM contradicts React state.
DECLARATIVE CONTROL FLOW RECOMMENDED
1. Early Return Guard
if (!story) return null;
Exits before main return; protects subsequent destructuring from null errors.
2. Boolean-Safe Logical AND
{count > 0 && <Badge />}
Evaluates to boolean false; React ignores false and cleanly renders nothing.
3. Architectural Outcome
Zero DOM Leaks: Clean declarative branching via standard JavaScript expressions.
