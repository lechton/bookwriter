# Architectural Decision Brief: 2026-10-03-01: Principle Top-Row Flex Container Standard, 68-Character Card Boundary, and Code Wrap Safety

## Executive Summary
This batch updates `src/build-lectures.mjs`, `src/lecture.css`, `skills/v6.4/principled-theory/SKILL.md`, `skills/v6.4/code-blocks/SKILL.md`, and `skills/v6.4/RULE-TAGS.md`. It eliminates visual overlap defects between the marginalia glossary and breakout principle cards by wrapping the glossary and definition card in a dedicated flex container (`.principle-top-row`), replacing fragile negative-margin CSS floats with an aligned two-column layout. It also calibrates the principle card single-line ceiling to 68 characters, adds `white-space: pre-wrap` and `word-break: break-word` safety nets, reserves 48px padding for watermark badges, and aligns Lecture 13 markup.

## 1. Root Cause Analysis

### 1.1 Spatial Overlap Between Left Marginalia and Breakout Code Cards
Previously, `.principle-marginalia-glossary` floated left inside `.principle-body` (`float: left; margin-left: -280px; width: 245px;`). When a principle contained multiple glossary terms, the left column stretched vertically (~180px) while a concise definition card took only ~100px. Because `.principle-cases-grid` broke out to the full width (`margin-left: -260px; width: calc(100% + 260px);`), and `clear: both` on negative-margin flex containers failed in print engines, the green breakout card rendered immediately beneath the shorter definition card, physically painting across and slicing through the bottom half of the glossary text.

### 1.2 Monospace Code Clipping Against Card Boundaries
In batch #2026_09_27_09_group_1, principle card line limits were raised to 80 characters. However, on US Letter print with 20mm margins, the printable width is ~498pt. At `0.84rem` (`9.24pt`) JetBrains Mono with card padding and a 44px top-right watermark badge, the physical hard limit before clipping is ~72-74 characters. A 79-character single-line JSX snippet (`<button type="button" className="action-btn" onClick={handleSave}>Save</button>`) exceeded this limit, causing `Save</butt` to be clipped because `.case-code-line` had `white-space: pre` and `.principle-case` had `overflow: hidden`.

## 2. Resolution

### 2.1 Principle Top-Row Flex Container (`src/build-lectures.mjs` & `src/lecture.css`)
- In `src/build-lectures.mjs`, wrapped glossary entries and the definition card inside `<div class="${topRowClass}">` (`.principle-top-row`, or `.principle-top-row.no-glossary` when no glossary entries exist).
- In `src/lecture.css`, converted the top row to an aligned flex container:
  - `.callout-principle .principle-top-row`: `display: flex; align-items: flex-start; margin-left: -260px; width: calc(100% + 260px); gap: 16px; margin-bottom: 0.6rem;`.
  - `.callout-principle .principle-marginalia-glossary`: `width: 244px; min-width: 244px; flex-shrink: 0; padding-right: 12px; margin: 0; float: none; clear: none;`.
  - `.callout-principle .principle-definition-card`: `flex: 1; min-width: 0; margin-bottom: 0;`.
- Because `.principle-top-row` is a flex container, its height automatically matches whichever column is taller, guaranteeing that `.principle-cases-grid` always starts strictly below both elements with zero possibility of text overlap.

### 2.2 Physical 68-Character Ceiling & Wrap Safety (`src/build-lectures.mjs` & `src/lecture.css`)
- Set `MAX_CASE_LINE_LEN = 68` in `src/build-lectures.mjs` across both compact and breakout validation branches to flag oversized lines at compile time.
- Updated `.callout-principle .case-code`:
  - Calibrated font size to `0.80rem` for a crisp, proportional fit.
  - Added `padding-right: 48px;` to reserve space for the 44px `.case-watermark-bg` icon.
- Updated `.callout-principle .case-code-line`:
  - Added `white-space: pre-wrap; word-break: break-word;` so that edge-case long lines wrap cleanly instead of clipping characters.

### 2.3 Skills Documentation (`skills/v6.4/`)
- Updated `skills/v6.4/principled-theory/SKILL.md` to mandate the **Principle Top-Row Flex Container Standard** and document the 68-character single-line limit.
- Updated `skills/v6.4/code-blocks/SKILL.md` to add the **Principle Card 68-Character Ceiling** gate.
- Re-formatted Principle 3 in `01-02-md-LECTURES/v6/13.md` and `01-01-md-PRE-lectures/v6/13.md` into symmetric multi-line JSX snippets.
