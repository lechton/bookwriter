# Decision Brief — 2026-09-25-06: Curriculum Map Syllabus Consultation and Strict Scope Boundary Enforcement Law

## Context & Motivation
1. **The Concept Bleeding Pathology & Knowledge Gaps**:
   In previous authoring cycles, agents and authors frequently drafted pre-lecture blueprints and lectures by relying on general React intuition or ad-hoc topic interpretation. This led to severe "forward concept bleeding"—introducing downstream language constructs, props passing, curly-brace expressions (`{headline}`), parameter destructuring, and multi-file component trees into early foundational lessons where those mechanics had not yet been formally established.
   This concept bleeding created acute knowledge gaps: concepts were used in practical examples or principles before their foundational theory had been introduced, confusing students progressing through the curriculum.

2. **The 180-Question Curriculum Syllabus (`01-01-map/`) as the Absolute Foundation**:
   The `01-01-map/` directory contains the master architectural syllabus for all 180 lectures in the bank. Each mapping file (`01-01-map/{nn}.md`) defines six authoritative dimensions:
   - **Topic Tag & Typology**: (e.g. `#component_anatomy` | `❱ CORE`).
   - **Interview Question**: The exact canonical question being answered.
   - **Core Truth**: The foundational mental model and architectural fact.
   - **The Friction**: The real-world senior debugging dilemma or junior mistake.
   - **The Mechanism**: The exact language or runtime feature resolving the dilemma.
   - **Under the Hood**: The browser engine, JSX compiler AST, or React reconciler implementation details.
   - **The Code Experiment**: The specific naive vs. idiomatic code contrast.
   - **Scope Boundary**: The explicit pedagogical ceiling defining what must NOT be introduced in that question (e.g. Q02 commands: *"Focus strictly on the single component function, its capitalization, its pure return contract, and declarative invocation (<Card /> vs Card()). Do not introduce props, curly brace expressions, or multi-file trees."*).

3. **User Directive**:
   The user explicitly highlighted the curriculum map ("the 01-01-map is taken into consideration ? nnn") and commanded: "do not edit 02, only instructions ppp". This mandates locking `01-01-map/{nn}.md` into the instruction system as Mandatory Step 0 and stopping before touching or authoring any lecture file.
