# Decision Brief — 2026-09-25-09: React 05 Statement Display Block Elevation Harmonization and Multiline Single-Backtick-Block Invariant

## Context & Motivation
1. **The Trapped Inline Statement Defect**:
   In React 05, code statements like `const headline = "Transit Accord Reached"` embedded after a colon in prose were automatically elevated to a dedicated `.code-line-callout` card on a new line. In React 06, an unvetted `isStandalone` check was added to `inline(s, allowDisplayCode)` in `src/build-lectures.mjs`, requiring `lineBefore` and `lineAfter` to be completely empty. Because authors follow the single continuous line convention for prose paragraphs, this suppressed `isDisp` and trapped important statements inline as plain monospace text pills.

2. **The Shredded Multiline Backticks Visual Disaster**:
   In `01-02-md-LECTURES/v3/04.md`, a multiline JSX snippet was authored with individual backticks on every line (`return (`, `<article className="...">`, etc.). This caused the compiler to treat each line as an independent callout block, producing 4 stacked, disconnected boxes followed by two orphaned closing pills (`</article>` `);`). In contrast, canonical lectures like `03.md` enclose the entire multiline block within a single pair of opening and closing backticks, producing one coherent card.

## Changes Implemented
- `src/build-lectures.mjs`:
  - Pruned the `isStandalone` constraint from `inline(s, allowDisplayCode)`.
  - Harmonized with React 05: any expression matching `isDisplayCode(c)` in a paragraph or callout (`allowDisplayCode = true`) is automatically elevated to a `.code-line-callout` block on its own line.
- `skills/v6.2/code-blocks/SKILL.md`:
  - Added Section 14B: **Single-Block Multiline Backtick Invariant**.
  - Mandated that multiline snippets in prose or callouts must use a single pair of opening and closing backticks around the entire block.
  - Formally banned shredding multiline code into line-by-line backticks.
- `skills/v6.2/RULE-TAGS.md`:
  - Registered batch `#2026_09_25_09_group_1`.

## Verification & Integrity
- All modifications adhere to single continuous line formatting, question-based standards (`- [ ] Does ...? / - [ ] Is ...?`), and zero em-dashes.
- Verified that compiling `04.md` and reader decks renders clean display blocks and zero shredded multi-box artifacts.
