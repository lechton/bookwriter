# Decision Brief: Pruning "Wire" Jargon, Native Image Component, and Anti-Gratuitous-Icon Standard (#2026_09_22_03_group_1)

**Date**: 2026-09-22
**Rule Tag**: `#2026_09_22_03_group_1`
**Components Affected**: `skills/lecture-voice/SKILL.md` (Section 25), `skills/ui-panels/SKILL.md` (Section 02), `src/component-explorer.mjs`, `src/lecture.css`, `assets/icons/`, `01-02-md-LECTURES/04.md`, `skills/RULE-TAGS.md`

---

## 1. Problem Statement & Root Cause

1. **Newspaper Slang ("wire")**:
   - In `04.md`, the author used 20th-century newsroom telegraph slang ("wire", "wire copy", "wire icon").
   - To a web development learner, "wire" sounds like electrical hardware or network jargon. Under the Two-Tier Convention Protocol, "wire" was missing from the Tier 1 pruning list.

2. **Asset Representation Vacuum**:
   - In `skills/ui-panels/SKILL.md`, Field 4 previously had no specification for images (`<img>`) or icons (`<svg>`).
   - Lacking an image or icon renderer, the author dumped `[elem:img.wire-icon: [badge: Wire Icon]]`—a text badge literally reading "Wire Icon".
   - Using text badges to simulate icons or dumping gratuitous icons into demo UI panels creates kitsch and confusion.

---

## 2. Changes Applied

### A. Two-Tier Convention Protocol (`skills/lecture-voice/SKILL.md`)
- Added `"wire"` / `"wire copy"` to the Tier 1 prune-and-replace list, replacing it with plain terms like `"breaking alert"` or `"news feed"`.

### B. UI Panels Skill (`skills/ui-panels/SKILL.md`)
- Added the **Native Image & Icon Components** rule:
  - When representing an image (`<img>`), use the native `[img: caption]` or `[elem:img.class: caption]`.
  - Avoid gratuitous icons in UI panels; keep the focus on authentic UI content (headings, paragraphs, inputs, buttons, status tags).
  - Strictly banned text-badge cop-outs (e.g. `[badge: Wire Icon]`) and platform emojis.
  - Supported `[icon: name]` with clean SVG icons when strictly required.

### C. Component Explorer & Styles (`src/component-explorer.mjs` & `src/lecture.css`)
- Added native SVG icons (`image`, `alert-bell`, `newspaper`, `search`, `user`, `clock`, `radio`, `check`) and saved SVG files in `assets/icons/`.
- Implemented `renderUiImage(caption)` rendering `.surface-ui-image` with a minimal SVG photo vector and caption.
- Styled `.surface-ui-image` with neutral slate background (`#f8fafc`), subtle border (`#cbd5e1`), and clean typography.

### D. Lecture 04 Updates (`01-02-md-LECTURES/04.md`)
- Replaced `[elem:img.wire-icon: [badge: Wire Icon]]` with `[elem:img.story-photo: [img: Breaking Story Photo]]`.
- Replaced `className="wire-icon"` with `className="story-photo"`.

## 3. Verification & Results

- The UI canvas in Lecture 04 renders an authentic image element with a clean vector photo glyph and caption.
