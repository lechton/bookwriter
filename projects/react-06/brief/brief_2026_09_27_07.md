# Architectural Decision Brief — 2026-09-27-07: The Kindergarten Noun Standard, Basic Variable Vocabulary Law, and Subculture Jargon Ban

## Executive Summary
This batch updates `skills/v6.3/lecture-voice/SKILL.md`, `skills/v6.3/RULE-TAGS.md`, and lecture files (`07.md`, `05.md`, `04.md`, and figures) under tag `#2026_09_27_07_group_1`. It establishes **The Kindergarten Noun Standard (The Basic Variable Law)**: all props, variables, parameters, and identifiers in examples and explanations MUST use basic, everyday nouns that an ordinary human being understands without technical translation (`name`, `title`, `job`, `author`, `date`, `count`, `label`, `text`, `color`). It permanently bans specialized design-system and corporate subculture jargon (`tone`, `variant`, `intent`, `elevation`, `surface`, `payload`, `orchestrator`, `telemetry`, `manifest`) and niche publishing terms (`masthead`).

## 1. Root Cause Analysis

### 1.1 The Corporate Design-System Jargon Reflex
AI models trained on enterprise GitHub repositories and design systems (Shopify Polaris, Braid, Atlassian, Adobe Spectrum) unconsciously reach for specialized subculture abstractions—such as naming a card styling prop `tone="urgent"` or `surface="raised"`. To an everyday learner studying basic React props and container composition, "tone" sounds bizarre or musical, obscuring the simple lesson that props are ordinary variables.

### 1.2 Domain Over-Specialization (The "Masthead" Trap)
In teaching layout components, prose and code repeatedly referred to `NewsHeader` as "owning masthead branding" or the "masthead header". A masthead is niche newspaper/publishing terminology that means nothing to the average person. In web fundamentals, it is simply a `site header`, `top bar`, or `title banner`.

## 2. Resolution

### 2.1 The Kindergarten Noun Standard (`skills/v6.3/lecture-voice/SKILL.md`)
- Added **Section 26: The Kindergarten Noun Standard (Basic Variables & Zero Subculture Jargon)**:
  - Universal Rule: All props, variables, parameters, and attribute identifiers must use elementary nouns (`name`, `title`, `job`, `author`, `date`, `count`, `label`, `text`, `color`).
  - Banned Jargon List: Explicitly bans `tone`, `variant`, `intent`, `elevation`, `surface`, `payload`, `orchestrator`, `manifest`, `telemetry`, and `masthead`.
  - The 8-Year-Old Reality Test: If an ordinary person outside of tech would not immediately know what the noun means in daily life, it is rejected in favor of an elementary equivalent.

### 2.2 Lesson & Figure Code Updates
- In `07.md` and `figures/07-02-architecture-audit.html`:
  - Replaced all instances of `tone="urgent"` / `tone="neutral"` with elementary `color="red"` / `color="gray"`.
  - Updated all surrounding prose, callouts, and table cells to explain `color` and `title` without jargon.
- In `05.md`, `04.md`, and figures:
  - Replaced all instances of `masthead` with `site header`, `title banner`, or `header container`.
