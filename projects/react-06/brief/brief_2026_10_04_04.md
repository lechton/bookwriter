## Philosophy & Architecture: The Two-Run Production Air-Gap

### 1. Root Cause of the Authoring-Audit Contamination

Previously, the lecture production workflow suffered from boundary contamination:
- `code-blocks/SKILL.md` contained instructions and exemplar snippets featuring tildes (`~token~`), speech bubble offset rules, and secondary audit references.
- When an author agent drafted an initial lecture (Run 1), it loaded `code-blocks/SKILL.md` and became burdened by token wrapping syntax (`~token~`), pointer calculations, and character-width budgets instead of dedicating 100% of its cognitive focus to pedagogical clarity, B2 English narrative pacing, and clean, runnable code.
- Furthermore, because build instructions mentioned `diagnose-lecture.mjs` directly in the authoring cycle, models felt compelled to write code blocks pre-targeted with tildes on the initial pass.

### 2. The Pure Code Authoring Standard (Run 1)

During initial lecture drafting (Run 1):
- Authors write plain, idiomatic, runnable React code.
- Comments are written as natural trailing explanations (`code // comment`, `<Component /> {/* comment */}`).
- There are **ZERO tildes** in drafted code.
- All tildes and secondary audit rules were pruned from `code-blocks/SKILL.md` and its exemplar snippets.
- Authors focus entirely on storytelling, B2 English, Stage C step-by-step assembly, and deep architectural explanations.

### 3. The On-Demand Audit Protocol (Run 2)

The code comment audit is **never destroyed or deleted**:
- **100% of the audit intelligence is preserved**: The complete 15-row Token Targeting Anatomy table, the 10 Golden Comment Exemplars, the column 36/30 geometry benchmarks, the dotted underline styling, and all 9 deterministic code block invariants remain fully intact inside `code-comment-audit/SKILL.md`.
- **Guaranteed Execution On Demand**: The audit is executed as a dedicated second pass (either via explicit command or prior to PDF compilation). The auditing agent loads `code-comment-audit/SKILL.md`, reads the anatomy table, wraps focal tokens in tildes (`~token~`), calibrates line widths, and runs `node src/diagnose-lecture.mjs {NN}`.
- **The Mechanical Gate**: `node src/diagnose-lecture.mjs {NN}` remains the hard automated gatekeeper. It strictly verifies that all 9 invariants pass with 0 errors before a lecture can be compiled into a final certified PDF.
