# Architectural Decision Brief — 2026-09-27-11: Documentation-Only Fact Checks in Principle Maps

## Executive Summary
This batch revises one checkbox in `skills/v6.3/map-principles/SKILL.md` Section 04 under tag `#2026_09_26_21_group_1 revised by #2026_09_27_11_group_1`. The checkbox used to ask whether every quoted compiler message, console warning, or error text was "checked against React 19 with Vite". Authors read that as an order to build a real React and Vite app, install packages, drive a headless browser, and reproduce each behavior before writing a map. The revised checkbox keeps the goal (no outdated error text) and changes the evidence: quotes come from the local react.dev corpus, and a result react.dev does not quote is described by its behavior instead of as exact text.

## 1. Root Cause Analysis
- **The prescription**: "checked against React 19 with Vite" named a toolchain instead of a source, so the only way to satisfy it literally was to run that toolchain.
- **The consequence**: sessions writing maps Q12 to Q17 each built a temporary app in the system temp folder, installed `react`, `react-dom`, `vite`, `@vitejs/plugin-react`, and a browser driver, and ran scripted clicks in headless Chrome. The maps then carried "Runtime check" lines in `Sources Read`, which the Output Contract never asked for.
- **Why it is the wrong cost**: the project's authority for React facts is already the local react.dev corpus (Section 01), and the map is a contract for authors, not a test report. Setting up and running an app adds time, installs software, and leaves processes and folders behind, while the facts a lesson needs are in the documentation.

## 2. Resolution
- The Section 04 checkbox now reads: "Is every compiler message, console warning, or error text quoted in a proof taken from the local react.dev corpus (including the React 19 upgrade guide) rather than recalled from an older toolchain, and is a result react.dev does not quote described by its behavior instead of as exact text, so the map rests on the documentation alone?"
- No new rule was added; the existing rule was de-prescribed by replacing the toolchain with the documentation as the evidence.
