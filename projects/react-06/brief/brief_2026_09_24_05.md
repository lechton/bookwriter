# Brief 2026_09_24_05: Versioned Directory Architecture and Latest-Version Default Law

## Origin & Context
The user partitioned the lecture files into versioned directories, placing all source markdown files into `01-02-md-LECTURES/v1/` and mirroring this structure across `01-01-md-PRE-lectures/v1/`, `01-03-md-lectures-HTML/v1/`, `01-04-md-lectures-PDF/v1/`, and standalone figures under `01-02-md-LECTURES/v1/figures/`. The user requested to hardcode this versioning convention across all internal operations, scripts, diagnostic tools, orchestrators, skills, and agent rules so that by default, all operations (including compiling, diagnosing, viewing, and commands like "create two next lectures") automatically resolve and target the latest version without requiring manual notification or path specifications.

## Rules & Standards Introduced

### 1. Build Pipeline Auto-Resolution & Relative Asset Depth (`src/build-lectures.mjs`)
- **Dynamic Latest-Version Detection**: Implemented `findLatestVersionTag(baseDir)` which inspects directories matching `/^v(\d+)$/i`, sorting them numerically in descending order to auto-select the highest version (e.g. `v1`, `v2`, etc.). Falls back to the root directory if no version subdirectories exist.
- **Explicit CLI Version Override**: Added support for `--version <ver>`, `-v <ver>`, and `--version=<ver>` flags so developers can compile a specific older version when needed.
- **Dynamic CSS Relative Path Calculation**: Because HTML outputs are nested inside version subdirectories (`01-03-md-lectures-HTML/v1/*.html`), the hardcoded `../src/lecture.css` previously caused Prince XML to throw `warning: can't open input file: ../src/lecture.css`. The compiler now dynamically computes `relative(htmlDir, join(ROOT, 'src/lecture.css'))`, yielding `../../src/lecture.css` automatically and eliminating the Prince warning.
- **Figure Path Resolution Fallback**: Updated `formatMD` and pipeline AST figure checks to check both `join(dirs.mdLectures, b.attrs.src)` and `join(dirs.mdLecturesBase, b.attrs.src)` to transparently locate figures in `01-02-md-LECTURES/<version>/figures/`.

### 2. Diagnostic Tool Auto-Resolution (`src/diagnose-lecture.mjs`)
- Integrated `findLatestVersionTag` and `--version` CLI parsing so `node src/diagnose-lecture.mjs <num>` automatically points `LECTURES_DIR` to the latest version subdirectory (`01-02-md-LECTURES/v1/`), resolving files accurately during audits.

### 3. Production Orchestrator Auto-Resolution (`produce_lectures.py`)
- Added `resolve_version_dir` and `set_active_version`, auto-detecting the latest version for `LEC_DIR`, `PRE_DIR`, and `PDF_DIR`.
- Added `--version` CLI option.
- Updated `build_prompt` to inject active versioned paths (`{PRE_REL}/{bn(n)}.md`, `{LEC_REL}/{bn(n)}.md`, `{PDF_REL}/{bn(n)}.pdf`, `{LEC_REL}/figures/`).
- Updated `answered_questions()` to inspect `LEC_DIR` (`01-02-md-LECTURES/v1/`), correctly recognizing existing lectures Q01 through Q13 as completed and targeting Q14 as the next unanswered question.
