## Authorized Scope
Lesson 04 teaches curly braces in JSX. It works inside one component, `ArticleCard`, that uses only local variables. Curly braces open a window to JavaScript in two places. One is the content between tags. The other is an attribute value, right after the `=`. Everything outside the braces is literal text. The braces hold one expression, never a statement. That expression runs while React renders the component. Its result takes the place of the braces. Strings and numbers print. Booleans, `null`, and `undefined` print nothing. Objects stop the render. The lesson builds on Q02, one component function that returns JSX. It also builds on Q03, the JSX grammar and its compilation to `_jsx` calls.

## Principles

### Principle 1: Curly braces open JavaScript in two places, and everything else is text
- **Handle**: `braces-window`
- **Kind**: Decision
- **Placement**: braces around each variable in content (`<h2>{headline}</h2>`) or after `=`; never around a tag name; comments in content as `{/* */}`
- **Mechanism**: the JSX compiler reads markup outside braces as fixed text and compiles the inside of braces as JavaScript
- **Tempting Belief**: a variable name in markup is read as the variable; a habit from code, where `headline` always means the variable
- **Defect**: `<h2>headline</h2>` shows the word "headline"; `// check the read time later` in content shows on screen; `<{tag}>` fails the build
- **Importance**: the card's Friction; the first bug every newcomer ships
- **Review Point**: Do
- **Required Lesson Proof**: `ArticleCard` renders `<h2>headline</h2>` beside `<h2>{headline}</h2>`; the screen shows "headline" and then "Night Trains Return to Europe"; a `// check the read time later` line in the content appears on screen, while the same note in `{/* */}` does not.

### Principle 2: An attribute takes a quoted string or one braced expression
- **Handle**: `quotes-or-braces`
- **Kind**: Decision
- **Placement**: `src={avatarUrl}` with no quotes; a URL built from parts goes in one pair of braces (`` src={`/img/${photoId}-${size}.jpg`} ``)
- **Mechanism**: a quoted attribute compiles to a string literal, so braces inside the quotes stay characters; `{a}{b}` after `=` fails the build
- **Tempting Belief**: every attribute value goes in quotes; a habit from HTML, and from Vue and Angular templates, which fill in values inside quoted attributes
- **Defect**: `src="avatarUrl"` and `src="{avatarUrl}"` put those exact strings in the DOM, and the image breaks; `disabled="false"` leaves the button disabled and logs "Received the string `false` for the boolean attribute `disabled`."
- **Importance**: the broken image in the card's Friction; reviewers flag a quoted variable on sight
- **Review Point**: Do
- **Required Lesson Proof**: three `<img>` tags in `ArticleCard` with `src="avatarUrl"`, `src="{avatarUrl}"`, and `src={avatarUrl}`; DevTools shows `avatarUrl`, `{avatarUrl}`, and `/img/anna.jpg`; then `src="/img/{photoId}-{size}.jpg"` against the template literal, which yields `/img/anna-s.jpg`.

### Principle 3: Braces hold one expression, and statements go above the return
- **Handle**: `expression-only`
- **Kind**: Decision
- **Placement**: a choice inside braces as a ternary (`{readTime > 10 ? 'Long read' : 'Quick read'}`); an `if` above the `return`, with its result in a variable
- **Mechanism**: the braces become an argument of a `_jsx` call (`_jsx("p", { children: ... })`), and a function argument must be an expression
- **Tempting Belief**: braces run any JavaScript, as a `<script>` tag or a PHP block does
- **Defect**: `<p>{if (readTime > 10) 'Long read'}</p>` fails the build; esbuild reports `Unexpected "if"`, Babel reports "Unexpected token"
- **Importance**: the card's Under the Hood; interviewers ask for the difference between an expression and a statement
- **Review Point**: Do not
- **Required Lesson Proof**: `ArticleCard` with `readTime = 4` first tries `{if (readTime > 10) 'Long read'}` and the build fails; the ternary then prints "Quick read", and so does an `if` above the `return` that sets `label`.

### Principle 4: The code in braces runs each time React renders the component
- **Handle**: `runs-during-render`
- **Kind**: Model
- **Placement**: values are ready before the JSX line that uses them; nothing after it changes the output
- **Mechanism**: JSX is a function call; its arguments are evaluated once, when the line runs, and the result is plain data
- **Tempting Belief**: braces bind to the variable and update when it changes; a habit from Vue and Angular templates, and from spreadsheet cells
- **Defect**: `headline` reassigned after `const title = <h2>{headline}</h2>` leaves the old headline on screen
- **Importance**: without it, the reader cannot understand why Q14 needs state, or why Q12 asks render code to stay pure
- **Prediction**: a `console.log` inside `formatReadTime`, called as `{formatReadTime(readTime)}`, prints once per render, and twice under `StrictMode`; reassigning `headline` after the JSX line changes nothing on screen.
- **Required Lesson Proof**: `ArticleCard` calls `{formatReadTime(readTime)}`; the console shows "formatReadTime ran" once without `StrictMode` and twice with it; a version that stores `<h2>{headline}</h2>` in `title`, then reassigns `headline`, still shows "Night Trains Return to Europe".

### Principle 5: Predict what content braces print from the value's type
- **Handle**: `values-on-screen`
- **Kind**: Model
- **Placement**: a boolean meant as a word becomes text first (`String(isFeatured)` or a ternary)
- **Mechanism**: React DOM writes strings and numbers into text nodes and skips booleans, `null`, and `undefined`, so they can mark "nothing here"
- **Tempting Belief**: braces print a value the way a template literal does, where `${false}` gives "false" and `${undefined}` gives "undefined"
- **Defect**: `{isFeatured}` shows nothing where "true" was expected; `{article.titel}` leaves an empty heading with no error
- **Importance**: the card's render matrix; blank booleans and silent typos are common shipped bugs
- **Prediction**: in `ArticleCard`, `{readTime}` prints `4`, `{0}` prints `0`, `{isFeatured}` and `{null}` print nothing, `{['Rail', 'Travel']}` prints `RailTravel`, and a lone `{NaN}` prints `NaN` with the warning "Received NaN for the `children` attribute."
- **Required Lesson Proof**: a list in `ArticleCard` with one `<li>` per value; the screen and DevTools show which items are empty.

### Principle 6: Content needs a string or a number, so read the field, call the function, or format the date
- **Handle**: `printable-content`
- **Kind**: Decision
- **Placement**: `{publishedAt.toLocaleDateString('en-GB')}`, not `{publishedAt}`; `{formatReadTime(readTime)}`, not `{formatReadTime}`
- **Mechanism**: React accepts strings, numbers, elements, arrays, and holes as content; it throws on a plain object or a `Date`, and skips a function with an error
- **Tempting Belief**: any value can be shown; a habit from `console.log`, which prints every object, and from template literals, which turn a `Date` into readable text
- **Defect**: `{publishedAt}` stops the render with "Objects are not valid as a React child (found: [object Date])"; `{formatReadTime}` renders an empty `<p>` and logs "Functions are not valid as a React child."
- **Importance**: one object in content takes down the whole render; the react.dev Challenge "Fix the mistake"
- **Review Point**: Do not
- **Required Lesson Proof**: `ArticleCard` adds a fixed `publishedAt = new Date(2026, 9, 6)`; `{publishedAt}` stops the render, `{publishedAt.toLocaleDateString('en-GB')}` prints `06/10/2026`; `{formatReadTime}` prints nothing and logs the error, `{formatReadTime(readTime)}` prints "4 min read".

### Principle 7: Double curlies are an object inside the braces
- **Handle**: `double-curlies-object`
- **Kind**: Model
- **Placement**: an inline object (`style={{ color: 'pink' }}`) or a variable that holds one (`style={theme}`)
- **Mechanism**: JavaScript writes objects with braces, so an object inside the JSX window shows two pairs; JSX adds no meaning of its own
- **Tempting Belief**: `{{ }}` is special syntax for printing a value; a habit from Handlebars, Mustache, Vue, and Angular, which print values with double braces
- **Defect**: `<h2>{{headline}}</h2>` stops the render with "Objects are not valid as a React child (found: object with keys {headline})"
- **Importance**: a react.dev Recap bullet; interviewers ask what `{{` means
- **Prediction**: `style={{ color: 'pink', fontSize: 20 }}` and `style={theme}`, with `const theme = { color: 'pink', fontSize: 20 }`, produce the same DOM, `style="color: pink; font-size: 20px;"`.
- **Required Lesson Proof**: `ArticleCard` renders its headline twice, once with the inline object and once with `theme`; DevTools shows the same `style` on both; then `<h2>{{headline}}</h2>` stops the render with the object error.

### Principle 8: A line break between text and braces removes the space
- **Handle**: `line-break-space`
- **Kind**: Decision
- **Placement**: `{readTime} min read` on one line, or `{readTime}{' '}` at the end of the line when a line break must stay
- **Mechanism**: JSX trims whitespace that contains a line break at the start and end of each text line; spaces inside a line stay
- **Tempting Belief**: whitespace in markup always collapses to one space; a habit from HTML, where the browser does that
- **Defect**: `{readTime}` and `min read` on separate lines render `4min read`
- **Importance**: ships as joined words; formatters insert `{' '}` and reviewers ask why it is there
- **Review Point**: Do
- **Required Lesson Proof**: `ArticleCard` prints `{readTime} min read` on one line (`4 min read`), then split over two lines (`4min read`), then with `{' '}` (`4 min read`).

## Senior Answer
Curly braces open a window from JSX to JavaScript. They work in two places: between tags, and right after an attribute's `=`. Everything outside them is plain text. So `src="avatarUrl"` passes the word, and `src={avatarUrl}` passes the value. Inside the braces goes one expression, something that produces a value. A statement like `if` fails the build, because the braces become an argument of a function call. So I use a ternary inside, or put the `if` above the `return`. The expression runs each time React renders the component. Its result replaces the braces, and the output keeps that value. Strings and numbers print. `true`, `false`, `null`, and `undefined` print nothing, which is handy for empty slots. A plain object or a `Date` stops the render, so I pass a field or formatted text instead. Double curlies are just an object inside the braces, as in `style={{ color: 'pink' }}`. Last, a line break between text and braces drops the space. So I keep them on one line, or add `{' '}`.
