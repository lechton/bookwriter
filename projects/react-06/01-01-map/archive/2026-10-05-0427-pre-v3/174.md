# Q174: React Compiler Interaction with Server Rendering
* **Topic Tag**: #react_compiler | ❱❱❱ ADVANCED (Server)
* **Interview Question**: *How does the React Compiler interact with server rendering and libraries?*
* **Core Truth**: The React Compiler optimizes both Server and Client Components by automatically memoizing JSX allocations and computation blocks at build time, eliminating unnecessary object reallocations during server renders and stabilizing client reference props passed across the server/client boundary.
* **The Friction**: A data-heavy financial table at The National Times re-renders slowly on the server during streaming SSR because nested helper functions recreate thousands of child element objects per request; manual `useMemo` is invalid in Server Components, leaving developers uncertain how to optimize server execution until they compile the server bundle.
* **The Mechanism**: Build-time SSA optimization: the React Compiler analyzes JavaScript ASTs using Static Single Assignment (SSA) form and inserts reactive memoization scopes (`_c` cache arrays) into both client and server component code; for Server Components, this memoizes expensive calculations across renders in long-lived server processes and prevents redundant JSX tree allocations during streaming passes.
* **Under the Hood**: Cross-boundary prop stabilization: when a Server Component passes an object or callback prop to a Client Component, uncompiled code allocates a new object reference on every server render pass; the compiler wraps the prop in a memoization slot, ensuring stable object identities that prevent the client component from triggering unnecessary client re-renders upon receiving updated Flight payloads.
* **The Code Experiment**:
  * *Naive*: Trying to use `useMemo` or `useCallback` inside an async Server Component to prevent downstream client re-renders, causing a build-time crash because hooks are strictly banned on the server.
  * *React*: Running the React Compiler over server and client source files, allowing the compiler to automatically insert caching scopes that stabilize object references across the server/client boundary without manual hooks.
* **Scope Boundary**: Do not cover general React Compiler rules or client-only memoization benefits (covered in Q70/Q90); focus strictly on how the compiler processes Server Components, optimizes server render throughput, stabilizes cross-boundary props in Flight payloads, and handles third-party component libraries.
