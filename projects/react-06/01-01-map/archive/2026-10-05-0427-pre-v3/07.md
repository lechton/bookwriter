# Q07: Container Composition with Children and Prop Spreading
* **Topic Tag**: `#children` | `❱ CORE`
* **Interview Question**: *How do the children prop, spread attributes, and default values work?*
* **Core Truth**: The `children` prop enables component slot composition by capturing whatever JSX is placed between opening and closing tags, decoupling container layout from inner content.
* **The Friction**: A team builds a `Modal` or `Card` component with twenty specialized props (`title`, `hasImage`, `buttonText`, `badgeContent`), creating an unmaintainable, rigid API that breaks every time designers want a different inner layout.
* **The Mechanism**: Nesting markup inside component tags (`<Card><EditorialContent /></Card>`), accessing `children` as an ordinary prop, and using JSX spread syntax (`{...restProps}`) to forward arbitrary attributes cleanly.
* **Under the Hood**: How JSX transforms nested children into the `children` key of the props object (`_jsx(Card, { children: ... })`), treating children as an opaque element descriptor tree.
* **The Code Experiment**:
  * *Naive*: A rigid `NewsCard` accepting ten boolean and string props for layout variations.
  * *React*: A flexible `CardContainer` accepting `children`, allowing callers to nest arbitrary headlines, badges, or bylines freely.
* **Scope Boundary**: Focus on slot composition via `children`, attribute spreading, and default prop fallbacks. Do not introduce render props or context.
