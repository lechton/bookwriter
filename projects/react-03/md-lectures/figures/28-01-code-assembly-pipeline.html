REDUCER + CONTEXT ARCHITECTURE — 5-STAGE PIPELINE
Step 1: Isolating Business Rules in Pure Reducer
cartReducer(cart, action) // Pure state transitions
First, author the pure cart reducer to handle adding, removing, and clearing items with mathematical immutability.
Step 2: Nesting Split Providers for Re-render Isolation
<CartStateContext> <CartDispatchContext>
Next, nest the state and dispatch providers inside CartProvider to separate dynamic data from stable callbacks.
Step 3: Authoring Guarded Custom Consumer Hooks
useCart() & useCartDispatch() // React 19 use() API
Then, author dedicated consumer hooks with fail-fast assertions to prevent orphaned consumption outside providers.
Step 4: Connecting Decoupled Consumers to Context
CartSummary & AddToCartButton
Connect leaf components to their respective channels: state listeners re-render on data changes while action buttons stay dormant.
Step 5: Mounting the Parent Cart Component
SubscriptionCartApp.jsx // <CartProvider> wrapping tree
Finally, mount the CartProvider wrapper in the parent component App to establish ambient state distribution without prop drilling.
