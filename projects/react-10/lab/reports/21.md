## Fixes

1. Principle 4, the computed true or false name. The React docs show it in a hotel feedback form, not a contact form, and the build flagged the code in the sentence.
   - Old: "The React docs show this in a contact form: `const isSending = status === 'sending';`."
   - New: "The React docs show this in a hotel feedback form:", then a `js` block with `const ~isSending~ = status === 'sending'; // True only while status is 'sending'`.
2. Principle 5, the `dom` block of the picture. React 19 writes `src` after `alt`.
   - Old: `+ <img class="picture picture--active" src="/park.jpg" alt="The new park">`
   - New: `+ <img class="picture picture--active" alt="The new park" src="/park.jpg">`
3. Principle 1, the Subscribe note block. With `note` found on line 3, the click listener starts on line 5.
   - Old: `startLine="4"`

4. Principle 4, the booleans mistake. With the handler on lines 10 to 19 and the success check after it, the input sits on line 28.
   - Old: `startLine="25"`
   - New: `startLine="28"`
