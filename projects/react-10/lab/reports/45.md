## Fixes in the lecture

1. Principle 4, "`form.reset()` empties the boxes too early". Old: "If the answer is `Username john is taken.`, the user has already watched the form clear as if the account was created, and then reads that it was not." New: "If the answer is `Username john is taken.`, the user has already watched the form clear as if the account was created. One second later, the refusal appears, and the boxes fill again with the default values from the new state."
2. Principle 2, the Create account `src/App.jsx`: the highlight on `action={formAction}` had no comment. New line: `<form ~action={formAction}~> {/* React resets the form after signUp returns */}`.
3. Principle 3, `src/App.jsx` from line 16: the two `defaultValue` highlights had no comment. New lines end with `{/* The reset puts back john after a refusal */}` and `{/* The reset puts back john@mail.com after a refusal */}`.
