# Lab report: Lecture 33, Fetching Data in an Effect, with Loading, Errors, and Race Conditions

Checked on 2026-11-09 against React 19.3.1, React DOM 19.3.1, Vite 8.3.6, and `@vitejs/plugin-react` 6.2.1. Runs use the dev server with `StrictMode` on, the way the lecture's `main.jsx` mounts `App`, unless a line says `--prod`. Every case is in `lab/cases/33/`, and each was run from `projects/react-10` with `node lab/check.mjs <case>`.

The lab has no real server. Each `steps.mjs` uses the shared `lab/cases/33/server.mjs`, which turns on Puppeteer request interception and answers `/api/bio/{name}` with the React docs' strings: `{ "bio": "This is {name}’s bio." }`, Bob after 2000 ms and everyone else after 200 ms, or status 500 with `{ "message": "Server error" }` for the names a case lists. The helper then reloads the page, so the first load, before the helper exists, reaches Vite instead; its `Screen after load` and the `SyntaxError: Unexpected token '<', "<!doctype "... is not valid JSON` lines above the `--- reload with the lab server ---` marker belong to that first load and are not part of any claim. The helper also prints every bio request with its time, and whether it finished or failed.
