# Lab report: Lecture 32, Connecting a Component to an External System with useEffect

Checked on 2026-11-08 against React 19.3.1, React DOM 19.3.1, Vite 8.3.6, and `@vitejs/plugin-react` 6.2.1. Runs use the dev server with `StrictMode` on, the way the lecture's `main.jsx` mounts `App`, unless a line says `--prod`. Every case is in `lab/cases/32/`. Each `steps.mjs` uses the shared `lab/cases/32/helper.mjs`. The helper clicks buttons by position and reads the `<h1>` once a second. It also prints every Console line with its time since the click and its file and line. For `Counter.jsx`, it maps the line through the inline source map Vite serves, so the number matches the one Chrome DevTools shows. Each case was run from `projects/react-10` with `node lab/check.mjs <case>`. `SECONDS=<n>` sets how many one-second samples a run takes.
