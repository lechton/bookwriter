## Fixes

1. Principle 4, *The pending flag by hand and isPending*. The hand-written version keeps the email in the box, so the two screens are not the same.
   - Old: "Yes, it is the exact same thing on the screen! For one submit, both buttons read "Signing up..." for one second, then "Sign up" again. The difference is in the code."
   - New: "Yes, on the button it is the exact same thing! For one submit, both buttons read "Signing up..." for one second, then "Sign up" again. Only the email box differs. With the hand-written version, the email stays in the box. React resets the form only after a form action, and this form has an `onSubmit` handler instead (as seen in Lesson 41). The difference that matters is in the code."
2. Principle 2, the build listed a parenthesis violation in a code block title.
   - Old: `title="With signup(formData) and with signup(previousState, formData)"`
   - New: `title="With formData alone and with previousState first"`
