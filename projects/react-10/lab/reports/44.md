4. Principle 2, the steps after the click. React logs the error when the set function runs, before the red render, not after the white heart comes back. Old: "1. `onClick` runs first, as a plain event handler. The heart reads `❤️ Liked` for a moment." then "3. The Console logs an error." and "4. The form's action starts the save."
