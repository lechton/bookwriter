# Brief 2026-11-06 02: Skills `v10.3`, four plain skills replace eight

## Why this batch exists

The owner found that the Lecture 20 opening was hard to understand. It showed three name boxes and their code, then said "they are NOT the same thing" three times. It never said what `value`, `defaultValue`, `onChange`, or `e.target.value` do. It never showed the steps that make box B refuse a letter. The draft already had these gaps, and the simplify pass kept them.

The lecture did not break the `v10.2` rules. It followed them. The rules asked for the phrases "the exact same thing" and "NOT the same thing", but never asked for the steps behind them. They asked for everyday pictures for English terms, but did not say that code words like `onChange` need explaining too. The rule against "info bombs" was defined by two Lecture 09 cases, so it did not catch a new one. The simplify pass only made text shorter, so it never added a missing step. The new rule from earlier the same day, browser before code, puts the result first, and no rule said the cause must follow.

The deeper problem was size and style. Eight writing skills held about 135,000 characters, written in the same dense style they asked writers to avoid. The owner noted that a one-paragraph prompt used to work better: write in B2 English for a reader with a headache and a short attention span, and be comprehensive. A writer copies the style of what it reads.

So `v10.3` is a rewrite, not a patch. It keeps what the skills taught, says each thing once in plain words, and puts one plain instruction first. The four `v1` files total about 38,000 characters. `v10.2` stays unchanged as history.
