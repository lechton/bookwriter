# Brief 2026-11-06 01: Skills `v10.2`, browser previews a reader recognizes

## Why this batch exists

The owner asked for Lecture 20 to open with its simple example, three name boxes starting with John, shown in a browser before the code. The first correction exposed three gaps. The skills never described how a form control is drawn, so the preview showed six plain lines that only implied inputs, a value from state that no real page shows, and a thin strip instead of a Console. The renderer had no styling for form fields at all. Every browser was full width, so a three-line preview sat in an almost empty frame starting left of the sentence that introduced it. The owner also set the rule that corrections after a lecture is finished touch only the final lecture and are re-rendered.

The fixes were made first in the lecture and the build, then written into a new skill version, `v10.2`, which becomes the default. `v10.1` is kept unchanged as history.

### #2026_11_06_01_group_2: Browser previews show the real controls
- `code-and-figures/SKILL.md` Section 2.3 item 1 lists what a `page` preview draws, grouped by what the reader sees: page text, cards, forms (`field:`, `textarea:`, `select:`, `check:`, `button:`, `submit:`), the Console (`console:`, `log: message | File.jsx:19`), and the good and bad marks on the control itself.
- The fidelity rule adds that each control looks like the real control, the frame shows only what the real page shows, and the Console shows every message React prints, including a first-render warning.
- A PROPER example from the corrected Lecture 20 opening and an invented COUNTER-EXAMPLE modelled on the first correction.

### #2026_11_06_01_group_3: Each browser chooses its width
- `code-and-figures/SKILL.md` Section 2.3 item 7: `width=text` for small single-column previews, full width for comparisons, grids, sidebars, and long Console output, one width for every state of the same page, and `size=mini` described as a separate choice.
- Covered by verification check B3.
- Renderer support: `width=text` on `page`, `shop`, `mail`, `dom`, `console`, `devconsole`, and `overlay`; an unknown value stops the build; under 720px the figure falls back to full width as the text does.
