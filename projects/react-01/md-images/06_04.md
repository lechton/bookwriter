# Visual Aid Specification — Lecture 06: JavaScript in JSX with Curly Braces

Where:
Place this visual aid in `md-lectures/06.md` inside the section `### The Raw Object Pitfall`, positioned immediately after the paragraph explaining why React refuses to render raw objects ("React refuses to render raw objects because it cannot guess how you want multiple fields formatted on screen. Accompanying Book Paragraph:
To understand why passing an object directly into JSX halts your application, visualize how React handles dynamic children. When curly braces evaluate a primitive string or number, React effortlessly creates a standard DOM text node and mounts it to the screen. But when you write `<h4>{reporter}</h4>`, curly braces evaluate to a multi-property JavaScript object. Because React cannot assume whether you want JSON, comma-separated keys, or localized labels, it halts execution immediately with its iconic fatal error: "Objects are not valid as a React child (found: object with keys {name, role})." As shown in the comparison below, curly braces grant you access to JavaScript expressions, but JSX child slots demand renderable leaf values. To display your data without crashing, always drill past the container into a specific primitive property like `{reporter.name}`.

Description:
This visual aid dissolves one of the most persistent mental traps for developers learning JSX: assuming that because curly braces evaluate JavaScript, any valid JavaScript variable can be placed inside a tag. Developers write `<h4>{reporter}</h4>` expecting React to serialize or display the object, only to be stopped by React's famous "Objects are not valid as a React child" fatal error. By organizing the lifecycle into a compact, space-efficient vertical layout with large characters and surgical marker highlights, the student's eye instantly tracks the causal chain: from the multi-line object definition in the source card, to the yellow-highlighted syntax in the component return, directly to the contrasting browser screen outcomes. In one glance, the student internalizes the core rule: curly braces evaluate JavaScript, but JSX child nodes require primitives.
