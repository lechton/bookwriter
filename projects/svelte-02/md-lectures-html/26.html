Lecture 26: Context

Interview Question

CORE

How do you pass data deep into the tree without prop-drilling?

Imagine this scenario:

  1. You are building an e-commerce site with a main layout, a product grid, individual product cards, and action rows inside each card.
  2. The user's VIP status is determined at the top level, but it is needed by the AddToCartButton deep inside the card to apply a discount.
  3. How do you pass this data down?
  4. If you use a prop, you must hand it through the layout, into the grid, into the card, and finally to the button — a chain of components that don't care about the VIP status themselves.
  5. This creates a brittle chain where changing the middle layers breaks the data flow.
  6. The solution is to drop the data into an invisible bucket at the top, and let the deep component reach in and grab it directly.

The Invisible Bucket

This invisible bucket is a decision about the architecture of our app. We need a way to share data deeply down a component tree without manually forwarding it layer by layer. This mechanism is called context. Context allows components to access values owned by parent components without passing them down as props through intermediate layers.

Creating the Context

Let's look at how to set this up using Svelte 5's modern createContext function. First, we create the context in a shared module.

context.ts
1import { createContext } from 'svelte';
2
3interface VIPStatus {
4 isVIP: boolean;
5 level: string;
6}
7
8export const [getVIPContext, setVIPContext] = createContext<VIPStatus>();
CreateContext returns a typed getter and setter pair
RIGHT: create typed context

By defining a [get, set] pair of functions with createContext, you create a strongly-typed bucket. The top-level parent ElectroShopApp.svelte puts data into the bucket using setVIPContext.

ElectroShopApp.svelte
1<script>
2 import { setVIPContext } from '../state/context.ts';
3 import ShopLayout from './ShopLayout.svelte';
4
5 setVIPContext({ isVIP: true, level: 'gold' });
We set the context at the top level of the component tree
RIGHT: set the data for the subtree
6</script>
7
8<ShopLayout />

Any descendant component — like ProductActions.svelte — can pull it out using getVIPContext. The intermediate components (ShopLayout, MainContent, ProductGrid, ProductCard) don't even know the data exists.

Interview Tip

To impress the interviewer: Mention that createContext (added in Svelte 5.40) is the modern, type-safe replacement for the older setContext and getContext functions. Because it generates its own unique getter and setter, you no longer have to manage magic string keys to match them up, and TypeScript infers the exact shape of your data automatically.

You can also put reactive state into context. If you pass a $state object into the context setter, the child component reading the context will update automatically when the parent mutates the state. But you must mutate the object properties (like vip.level = 'platinum'), not reassign the whole variable, or the reactive link will break.

Summary

Context is a way to teleport data deep into a component tree without the pain of prop-drilling. By calling createContext in a shared module, you generate a matched setter and getter. The top-level parent uses the setter to provide data, and any descendant component can use the getter to access it directly, bypassing all intermediate layers.
