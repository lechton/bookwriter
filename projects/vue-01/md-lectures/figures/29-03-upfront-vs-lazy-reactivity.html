Startup Traversal Architecture — Upfront Recursion vs Lazy On-Demand Proxying
UPFRONT RECURSIVE WALK Vue 2 Observer
root: state defineReactive()
↳ state.precincts defineReactive()
↳ precinct[0..5000] Recursive walk()
Startup Time: O(N) synchronous freeze Heap: High
walk(data);
Synchronously wraps every nested branch at boot; blocks the main thread on large payloads.
LAZY ON-DEMAND PROXYING Vue 3 reactive()
root: state Proxy Created O(1)
↳ state.precincts Proxied on get() access
↳ precinct[0..5000] Raw Object (Untouched)
Startup Time: O(1) instantaneous Heap: Minimal
reactive(data);
Wraps nested objects only when accessed by getters; renders initial UI in O(1) time.
