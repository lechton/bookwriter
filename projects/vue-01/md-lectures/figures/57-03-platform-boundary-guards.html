Universal Platform Guards: Three Lines of Defense
1. Lifecycle Deferral Component Hook
onMounted(() => { const w = window.innerWidth; window.addEventListener( 'resize', onResize ); });
Browser-Only Hook: Vue never invokes onMounted on the Node.js server. Window access is completely safe.
✓ Zero ReferenceErrors on Server
2. Runtime Branching Universal Utils
function getAuthToken() { if (typeof window !== 'undefined') { return localStorage.token; } return serverCookieToken; }
Environment Check: Checks global presence before reading local storage or dispatching client analytics.
✓ Universal Function Safe Anywhere
3. Template Boundary ClientOnly Shell
<ClientOnly> <InteractiveChart /> <template #fallback> <div class="skeleton"></div> </template> </ClientOnly>
Markup Isolation: Server renders the skeleton placeholder without running client canvas or map bundles.
✓ Skips Heavy Client Scripts on Server
