Compiler Architecture — Macro Transform
Authoring Code (SFC) <script setup>
<script setup> import { ref } from 'vue' // Top-level variables const count = ref(0) function increment() { count.value++ } </script> <template> <button @click="increment"> {{ count }} </button> </template>
Compiled Output (Browser) setup() function
import { ref } from 'vue' export default { setup(__props, { expose }) { const count = ref(0) function increment() { count.value++ } // Implicitly returned! return { count, increment } } }
The Vue compiler transforms top-level bindings in <script setup> into a returned object inside the standard setup() function.
