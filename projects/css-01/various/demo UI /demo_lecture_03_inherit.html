Design Showcase: Lecture 3 Reference UI

Authentic Component Preview with Strict External Callouts and Ghost Demarcation

Three Golden Design Laws Applied in this Demo:

  • Zero CSS Code in Figures: Code belongs in the code fence above the figure. The figure is purely the browser's rendered UI consequence.
  • Authentic Components: Components look like real website elements (a real dark footer with branding and links) rather than abstract wireframes.
  • The Demarcation Law for Invisible Elements: When an element is visually swallowed by its container, never leave an empty void. Always draw a dashed ghost demarcation box with a subtle contrast wash and a failure value tag (#000000) so the reader clearly sees what was otherwise invisible.
