Less: @ Sigil & Class-Based Mixins
DISCRETE SYNTACTIC ROLES UNAMBIGUOUS
// Distinct variable sigil ($)
$brand-color: #0284c7;

// Dedicated mixin keywords
@mixin elevation { box-shadow: 0 4px 6px #000; }
↓ EXPLICIT INCLUSION DIRECTIVE (@INCLUDE) ↓
.card { @include elevation; }

// Zero collision with CSS native @media, @keyframes, or @layer
✓ Dedicated directives prevent collision with native CSS syntax.
Dedicated language directives
Clear demarcation between variables ($), mixins (@mixin), and inclusions (@include).
AT-RULE SIGIL & CLASS REUSE OVERLOADED ROLES
// @ sigil clashes with native at-rules
@brand-color: #0284c7;

// Standard class acts as mixin
.elevation() { box-shadow: 0 4px 6px #000; }
↓ CLASS SELECTOR INVOCATION (.CLASS()) ↓
.card { .elevation(); }

// Overloads @ symbol; blurs boundary between selectors and mixins
✕ Any CSS class can act as mixin; @ is overloaded with CSS at-rules.
Overloaded @ sigil and class mixins
Variables borrow CSS at-rule symbol; any regular class can be invoked as a mixin.
