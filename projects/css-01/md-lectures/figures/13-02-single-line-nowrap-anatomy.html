Inspecting .byline-truncate container width locked to 320px:

By Elena Rostova, Senior Investigative Reporter and Bureau Chief

1. white-space: nowrap
Forces all glyphs into a single non-breaking line box.
2. overflow: hidden
Prevents horizontal box spilling beyond 320px width.
3. text-overflow: ellipsis
Measures inline edge, drops excess words, stamps U+2026.
Single-Line Mandate: The ellipsis triggers only when inline progression breaches the trailing container edge in a non-wrapping line box
