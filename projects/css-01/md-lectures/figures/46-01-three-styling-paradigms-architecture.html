BEM CSS NO BUILD STEP
<!-- HTML -->
<button class="btn btn--cta">
/* CSS */
.btn--cta { background: #1e3a8a; }
↓ HUMAN DISCIPLINE ↓
Compiled Output:
.btn--cta {
  background: #1e3a8a;
}
Semantic naming conventions prevent collisions across files with zero build tooling required.
TOOLING: Pure CSS runtime;
Relies on team discipline and code reviews to enforce conventions.
MODULES SCOPED HASH
// Component.jsx
<button className={styles.cta}>
/* Component.module.css */
.cta { background: #1e3a8a; }
↓ BUNDLER CODE GEN ↓
Compiled Output:
.Component_cta__a8f9 {
  background: #1e3a8a;
}
Compiler generates unique class hashes per file, mathematically preventing style collisions.
TOOLING: Bundler transform;
Guarantees local component scope, ideal for React/Vue/Svelte stacks.
