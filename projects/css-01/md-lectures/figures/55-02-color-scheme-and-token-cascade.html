DARK DUPLICATION (100+ COPIED RULES) .dark-theme body { background: #0f172a; color: #f8fafc; } .dark-theme .story-card { background: #1e293b; } .dark-theme .btn-primary { background: #38bdf8; }
✕ Stylesheet Bloat & Drift: Duplicating every component selector under .dark-theme doubles CSS bundle size, breaks specificity, and guarantees color bugs whenever new components are added.
Manual selector duplication creates massive maintenance debt and specificity escalation.

TIER 1: PALETTE PRIMITIVES --slate-50: #f8fafc; | --slate-900: #0f172a;
TIER 2: SEMANTIC THEME TOKENS Light: --surface-bg: var(--slate-50); Dark: --surface-bg: var(--slate-900);
TIER 3: SINGLE COMPONENT RULE (ZERO COPIES) .story-card { background: var(--surface-bg); }
✓ Zero Component Duplication: Components only reference semantic tokens. Flipping from light to dark mode redefines only the token values at the root, leaving component code 100% untouched.
Custom properties decouple visual theming from component selectors and DOM geometry.
