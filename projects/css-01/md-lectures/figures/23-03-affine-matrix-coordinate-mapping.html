Direct Post-Layout Coordinate Projection Instead of updating CSS box dimensions in the layout tree, the browser computes a transformation matrix. Each vertex $(x, y)$ in the element's local space is multiplied during display list generation:
matrix(1, 0, 0, 1, 0, -4) × [x, y, 1]™ → [x, y - 4, 1]™
The visualFormattingModel positions elements in normal flow; the transformation matrix projects vertices to the screen without altering surrounding box geometries.
