IMPERATIVE BRANCHING PROGRAMMATIC
@mixin card-theme($mode) {
  @if $mode == 'dark' { background: #0f172a; }
  @else { background: #ffffff; }
}
↓ SASS COMPILER EXECUTES SELECTED BRANCH ↓
.news-card { @include card-theme('dark'); }

Compiled Output: background: #0f172a;

Imperative @if / @else statements

PATTERN MATCHING MEDIA-QUERY STYLE
.card-theme(@mode) when (@mode = dark) {
  background: #0f172a;
}
.card-theme(@mode) when not (@mode = dark) {
  background: #ffffff;
}
↓ LESS COMPILES MATCHING PATTERN GUARDS ↓
.news-card { .card-theme(dark); }

Declarative mixin guards (when)
