NATIVE NESTING SPECIFICITY: DESUGARING TO :IS() IN THE BROWSER
1. Authored Native CSS
.card, #spotlight {
  a {
    color: #d97706;
  }
}
2. Browser Internal Desugaring
:is(.card, #spotlight) a {
  color: #d97706;
}
/* :is() adopts heaviest branch */
Parent Selector List
.card (0,1,0) vs #spotlight (1,0,0)
:is() Resolution
Takes Max: (1, 0, 0)
Total Link Specificity
(1, 0, 1) Everywhere!
:is(.card, #spotlight) a evaluates to (1, 0, 1);
Notice: Nesting adopts the highest specificity in the parent list
