Single Colon (:hover)
Filters whole node on state; zero boxes added
Double Colon (::after)
Appends virtual child box inside element boundary
The Internal Attachment Law: ::before and ::after generate child boxes inside the originating element boundary; they cannot attach to replaced elements like <img> or <input>
