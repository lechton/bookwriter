✕ Context Blindness: The media query only measures screen width. Because the screen is 1200px wide, the sidebar card forces a wide two-column row inside a 280px box, crushing headlines and blowing out layout.
Media queries cannot distinguish between a wide column and a narrow rail on the same screen.
