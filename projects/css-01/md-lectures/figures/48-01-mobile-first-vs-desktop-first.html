Desktop-First: Destructive Overrides
Mobile-First: Progressive Enhancement
DESKTOP-FIRST FLOW MAX-WIDTH OVERRIDES
1. Base Stylesheet (Desktop Foundation)
.article-layout {
  display: flex;
  width: 1200px;
}
↓ MOBILE VIEWPORT OVERRIDES ↓
2. Media Query (@media max-width: 768px)
.article-layout {
  display: block; /* strip flex */
  width: 100% !important; /* undo 1200px */
}
✕ High Reset Debt: Mobile browsers parse heavy desktop rules only to immediately destroy and recalculate them.
Mobile devices waste memory unwinding desktop styles with destructive overrides and high-specificity patches.
MOBILE-FIRST FLOW MIN-WIDTH ENHANCEMENT
1. Base Stylesheet (Natural Document Flow)
.article-layout {
  width: 100%;
  /* natural single-column block flow */
}
↓ DESKTOP VIEWPORT ENHANCEMENT ↓
2. Media Query (@media min-width: 768px)
.article-layout {
  display: flex; /* add columns */
  max-width: 1200px; /* add container */
}
✓ Additive Architecture: Baseline styles are lean and permanent; wider screens purely add new enhancements.
Mobile browsers execute minimal code without overrides, while desktop screens progressively layer on layout tracks.
