## Hard format rules

- One continuous line per paragraph, bullet, and table row. Never hard-wrap. No em-dashes anywhere.
- Section Rhythm & Page Fit: Sections always start with 2–3 sentences of text before code/figure. While aiming to fit Section 1 comfortably on Page 2 is a helpful suggestion, it is NEVER a hard limit that sacrifices clarity. When clarity demands showing parent-child hierarchy, markup context, or child rules, always show them. Strict Synchronization Rule: Every element, class, or selector rendered in a figure canvas MUST appear in the code snippet directly above it (or be clearly labeled by its plain layout role, never as an undeclared CSS selector). Minimal code precedes minimal figure every single time under a section. Always explain before or after the code and figure.
- Figure Visualizations and Discipline: Every time it helps to distinguish or clarify things, fill the lecture with UI visualizations of the CSS provided in the code (no arbitrary '2 to 4' quotas; single scenes or compare scenes where appropriate).
