# Q130: Server Rendering Security: Trust Boundaries and Public RPC Endpoints
* **Topic Tag**: #security | ❱ CORE (Server)
* **Interview Question**: *What security guarantees does server rendering give, and what must you still validate yourself?*
* **Core Truth**: Server Components protect private tokens and database connections from client exposure, but Server Functions are publicly accessible HTTP endpoints that require rigorous authentication, authorization, and input validation on every invocation.
* **The Friction**: A developer at The National Times writes a Server Function deleteArticle(id) assuming that because it runs on the server and is only called from an admin button, it is automatically secure; an attacker inspects the network request, sends a forged POST request with an arbitrary article ID, and deletes the front-page story.
* **The Mechanism**: Security boundary rules: (1) Server Components: secure execution environment, zero client leakage when guarded with server-only; (2) Server Functions: public RPC endpoints; must explicitly verify user session, validate permissions (if (!user.isAdmin) throw new Error()), and sanitize all arguments.
* **Under the Hood**: RPC endpoints are public HTTP APIs: the bundler exposes every Server Function as an HTTP POST endpoint identified by an action ID; anyone with the action ID can invoke it directly via curl without using the React client UI, making client-side disabled buttons useless as security controls.
* **The Code Experiment**:
  * *Naive*: Relying on client-side UI checks ({user.isAdmin && <button onClick={deleteStory}>}) while leaving the Server Function completely unprotected on the server.
  * *React*: Enforcing server-side authorization and schema validation inside the Server Function (const session = await getSession(); if (!session?.isAdmin) throw new UnauthorizedError();).
* **Scope Boundary**: Focus on server rendering security guarantees, the public nature of Server Functions, and mandatory server-side authentication/validation. Concludes the Server CORE tier.
