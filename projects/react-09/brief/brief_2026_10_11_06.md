# Brief 2026-10-11-06: Fewer Fixed Places, More Complete Answers

## Why

Across the owner's comments on Lecture 7 and Gemini's report, the same cause kept returning: the instructions gave the writer fixed places to fill, and when the topic had nothing real for a place, the writer invented something. One map principle had to be one question, so a fix that belonged inside Question 4 became Question 5, and Question 4 ended on a fix the author knew was incomplete (`'card ' + className`, which prints `class="card undefined"`). The bank question names "default values", so defaults, owned by Lecture 6, became a principle. A visible defect was needed, so an empty badge pill appeared. A story world was needed, so newspaper headlines appeared ("Transit Accord Reached"). An example had to come early, so it dropped in cold. The owner's remedy: when a fix has a catch, continue the same answer with the junior and the senior response instead of adding a question; and keep the language warm and plain.

The owner's earlier text (sent with "nnn") also asked for a warm opening and for every example to come with its purpose. Those points had been discussed but never written into the skills; this batch adds them.
