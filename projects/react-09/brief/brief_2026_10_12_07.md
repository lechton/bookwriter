# Brief 2026-10-12-07: The Pertinence Test for the Theme's Options

## Why

Every lecture from 1 to 8 opened with "There are two ways to …", and every blueprint carried the same slot, `{categories: the count} … categorical clarity; the count comes first`, which no skill contains: one blueprint invented it and the next ones copied it. The cause in the skills: `lecture-structure` Section 12 and `map-principles` Section 05B made the theme's options unconditional, and a fallback ("when React offers no rival way, the options are the habit without React and what React does instead") guaranteed a pair for every topic. The fairness check then forced the writer to defend the non-option with an invented use. Lecture 8 shows the result: "a monolithic file (Lecture 5)" set against ES modules, a choice no developer who knows modules makes, credited to a lecture that never taught it as a choice, while the lesson's real pair (default and named exports) sits in its questions.

## Group 1: The pertinence test (#2026_10_12_07_group_1)

- `lecture-structure` Section 12: the opening paragraph makes the list of ways conditional on a real choice; a new check states the pertinence test (would a developer who knows both really pick between them for the same job, and could an interviewer ask when each fits); the options check now starts "When the theme passes the pertinence test"; the fallback check is deleted (pruned, not banned); a new counter-example quotes Lecture 8's box.
- `lecture-structure` Sections 12 and 25: the check that the closing table returns to the introduction's options, and the Section 25 table check, now apply only when the introduction has options; otherwise the existing "What to Remember" matrix applies.
- `map-principles` Section 05B: the paragraph says the map decides whether the theme has options; the fallback check is replaced by the pertinence test, with `- **Options**: none (starting point: …)` when none passes.
- `pre-lecture` Section 13C: option elements and `[ways]` are planned only when the map lists options.
- `produce_prompt.md`: the first-section instruction follows the same condition; its two "never" bans are dropped because the condition does their job.
- `intro-examples.md` Example 1: "Why it works" now names imperative and declarative as a theme that passes the test.
