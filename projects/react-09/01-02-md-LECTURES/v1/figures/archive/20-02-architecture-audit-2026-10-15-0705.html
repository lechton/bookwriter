Architectural Contrast Matrix
Form Control Paradigms in React 19
Contrasting uncontrolled DOM field state with declarative controlled React state architecture across six operational dimensions.
Dimension Form Operation Browser Habit Uncontrolled Field defaultValue & DOM Memory Declarative Model Controlled Field value & React State
Authority & Memory
Source of truth 		DOM Internal
The DOM node retains typed characters internally; defaultValue sets only the initial value once at mount. 		Single Source of Truth
React state variable drives the field via value; the field displays whatever exists in component state after each render.
Programmatic Reset
State clearing 		Desynchronized
Calling setText('') updates state counters but leaves old text visible in the DOM textarea. 		Synchronized Flush
Calling setText('') triggers a re-render where React writes the empty string back into the DOM element.
Event Dispatch
Keystroke timing 		Native Change
Native browser change events fire only after the user leaves the input (blur event). 		Per-Keystroke
React synthetic onChange fires synchronously on every keystroke, keeping state strictly current.
Missing Handler
Read-only trap 		Silent Mutation
Typing modifies the element without warning, but component state remains completely unaware. 		Read-Only Guard
Providing value without onChange locks the input and warns in the development console.
Checkbox Property
Boolean toggles 		Static "on" Value
Reading e.target.value yields "on" on every toggle, permanently locking the checkbox to checked. 		Boolean Checked
Uses checked={isUrgent} and reads e.target.checked to accurately capture true and false transitions.
Select Dropdown
Option selection 		Option Selected
Using HTML <option selected> triggers console errors and breaks programmatic re-selection. 		Select Value Prop
Declares <select value={choice}> on the container; React selects the matching option cleanly.
