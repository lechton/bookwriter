# Prompt glossary

Words to reach for and words to leave alone, when writing prompts.

## Authority and tone

| category | prefer | avoid |
|---|---|---|
| prohibition | "avoid", a condition | "don't", "never", "only", "under no circumstances", "nothing", "not", "forbidden" etc. |
| instruction | "prefer" | "must", "only", "obligatory" etc. |
| actions | setting a standard on the result, using a checklist for actions | "do", "do not, "not" etc. |
