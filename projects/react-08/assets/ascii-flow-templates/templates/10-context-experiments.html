Experiment A: The Central Ambient Broker Hub (Mutator Towards, Subscribers From)
>> Architecture Pattern: Centralized ambient broker; state mutations flow towards, data flows from

                       ┌────────────────────────────────┐
                       │ ThemeToggle (Mutator Child)    │
                       │ onClick: toggleTheme("dawn")   │
                       └───────────────┬────────────────┘
                                       │ (Sends Mutation Towards)
                                       ▼
                 ┌┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┐
                 ┊  AMBIENT CONTEXT ABSTRACTION BROKER  ┊
                 ┊  ThemeContext: { mode: "dawn" }      ┊
                 └┄┄┄┄┄┄┄┄┄┄┄┬┄┄┄┄┄┄┄┄┄┄┄┄┄┬┄┄┄┄┄┄┄┄┄┄┄┄┘
                             │             │
              (Broadcasts    │             │  (Broadcasts
               From)         ▼             ▼   From)
 ┌───────────────────────────────┐     ┌───────────────────────────────┐
 │ ThemeBadge (Consumer #1)      │     │ ArticleView (Consumer #2)     │
 │ useContext(ThemeContext)      │     │ useContext(ThemeContext)      │
 │ Displays: "dawn"              │     │ Repaints reading contrast     │
 └───────────────────────────────┘     └───────────────────────────────┘
Experiment B: The Ambient Atmosphere Enclosure (Enclosing Dashed Perimeter)
>> Architecture Pattern: Atmospheric boundary; children exist within ambient dashed envelope

 ┌────────────────────────────────────────────────────────────────────────┐
 │ App (Root Owner & Provider Setup)                                      │
 │ <ThemeContext.Provider value="midnight">                               │
 └───┬────────────────────────────────────────────────────────────────────┘
     │ (Injects into ambient atmosphere)
     ▼
 ┌┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┐
 ┊  AMBIENT CONTEXT ATMOSPHERE ENVELOPE: <ThemeContext.Provider>          ┊
 ┊  Ambient Value: "midnight"                                             ┊
 ┊                                                                        ┊
 ┊    ┌──────────────────────────────┐                                    ┊
 ┊    │ NewsLayout (Intermediate)    │ (Passive in atmosphere)            ┊
 ┊    │ Props: { } (unaware)         │ (Zero theme prop forwarding)       ┊

 ┊                   │ render: <SidebarNavigation />                      ┊

 ┊    │ SidebarNavigation            │                                    ┊

Experiment C: Multi-Context Layering (Two Independent Ambient Boxes)
>> Architecture Pattern: Parallel ambient abstractions; components selectively tap one or both

 ┌┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┐         ┌┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┐
 ┊  ThemeContext Ambient Box ┊         ┊  AuthContext Ambient Box  ┊
 ┊  value = "midnight"       ┊         ┊  user = { role: "admin" } ┊
 └┄┄┄┄┄┄┄┄┄┄┄┬┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┘         └┄┄┄┄┄┄┄┄┄┄┄┬┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┘
             │                                     │
             │ (Reads From Theme)                  │ (Reads From Auth)
             ▼                                     ▼
 ┌───────────────────────────┐         ┌───────────────────────────┐
 │ ThemeBadge (Child #1)     │         │ UserAvatar (Child #2)     │
 │ useContext(ThemeContext)  │         │ useContext(AuthContext)   │
 │ Displays theme badge      │         │ Displays user initials    │
 └───────────────────────────┘         └───────────────────────────┘
             │                                     │
             └──────────────────┬──────────────────┘
                                │ (Reads From BOTH!)
                                ▼
                  ┌───────────────────────────┐
                  │ AdminDashboard (Child #3) │
                  │ useContext(ThemeContext)  │
                  │ useContext(AuthContext)   │
                  │ Dark mode admin console   │
                  └───────────────────────────┘
