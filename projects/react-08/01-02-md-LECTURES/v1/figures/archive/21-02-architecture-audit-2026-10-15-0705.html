Architectural Contrast Matrix
State Reaction Paradigms in React 19
Contrasting imperative DOM element manipulation with declarative state machine architecture across six operational dimensions.
Dimension Form Operation Imperative Habit Direct DOM Commands querySelector & style.display Declarative Model State-Driven UI status & React State
Authority & Memory
Source of truth 		DOM Internal
DOM nodes hold display state; scripts query and mutate element visibility and properties directly. 		Single Source of Truth
React state variable drives the screen via status; handlers only call setStatus to request re-renders.
Element Visibility
Show and hide logic 		Manual Mutations
Toggles style.display = 'block' or classes; changes persist until explicitly reversed by code. 		Declarative Branches
JSX declares what each status displays using && or early returns; React matches the DOM automatically.
Form Lifecycle
State representation 		Boolean Explosion
Three flags (isSubmitting, isSuccess, isError) create 8 combinations, causing impossible states. 		Single Status String
One state string ('typing' | 'submitting' | 'success' | 'error') mathematically guarantees mutual exclusivity.
Error Recovery
Retry handling 		Conflicting Messages
Retrying after failure leaves error banners visible if the success branch forgets to reset the error element. 		Automated Flushing
Calling setStatus('success') re-renders only the confirmation branch, automatically unmounting the error banner.
Button Interactivity
Double-click guard 		Imperative Property
Assigns button.disabled = true; unhandled errors or missing resets leave buttons permanently locked. 		Derived Disabled Prop
Declares disabled={status === 'submitting'}; restores interactivity automatically when status changes.
Design Workflow
Component construction 		Handler-First
Writes event handlers first, testing visual transitions by manually clicking through every branch in the browser. 		Visual States First
Lists and mocks visual states first with a status prop; catalogues triggers and wires handlers second.
