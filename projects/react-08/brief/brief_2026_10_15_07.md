# Brief 2026-10-15-07: Plain Names in the Syllabus Cards

## Why

Brief 2026-10-15-06 moved the naming of each lesson's example to the map. The maps start from the syllabus cards in `01-01-map/`, and 141 of the 180 cards were set in a newsroom ("The National Times", editorial desks, bylines, breaking news, dispatches, tickers). Every new map had to rename them again. This rewrite renames them once, at the source, so a map starts from plain names.

The rewrite changes names and settings only. Every fact, React API, number, defect, scope boundary, and lesson reference stays as it was. The old cards are kept in `01-01-map/archive/NN-2026-10-15-1213.md` (see `ARCHIVE-LOG.md`).

## Group 1: The Names Table (#2026_10_15_07_group_1)

The setting is a plain website that lists articles, with no site name; where a sentence needs one, it says "the site". A card whose problem lives in another everyday widget uses that widget (a ticket order, a task list, a profile form, a feedback form, a shopping cart, a search box). The names follow the corrected archive of lectures 01 to 21 and `lecture-voice` Section 03.

| Newsroom name | Plain name |
|---|---|
| The National Times, Town News, The Daily Dispatch, any made-up publication | the site (or no name) |
| newsroom, editorial desk, copy desk, editors' tools, CMS | the admin page, `AdminPage`; writing an article: `ArticleEditor` |
| masthead, `NewsHeader` | the site header, `SiteHeader` |
| feed of stories, `EditorialFeed`, `StoryFeed`, `NewsFeed` | the list of articles, `ArticleList` |
| one story or article card | `ArticleCard`; one article's page: `ArticlePage` |
| headline | title, `title` |
| byline, `EditorialByline` | the author's name, `AuthorName`, `author` |
| edition | a plain value that fits the example (`theme`, `language`, `city`, `siteName`) |
| breaking news, urgent badge, exclusive | a "New" label, `isNew` |
| wire, dispatches, live ticker, live blog | a list that updates on its own: latest comments, `LatestComments`; a live score; people online |
| tip form, eyewitness tip | a contact form, `ContactForm` |
| subscriber, paywall, premium reader | a signed-in user, `isSignedIn`; a members-only article |
| Ethics Policy and Masthead pages | the About page and the Contact page |
| correction modal, editorial modal | an edit form, `EditForm` |
| story archive | old articles |
| reporter, journalist, editor (as a person in the story) | the author |
| a developer persona (Clara, Marcus, Elena, Julian, Leo, etc.) | "a developer", or one approved name from `lecture-voice` Section 26B |
| headline-style article titles ("Transit Accord Reached", "Rail Strike Ends") | plain titles ("New Park Opens Today", "Rain Expected This Weekend") |
| news sections (politics, business) | plain topics (Sport, Weather, Food, Travel) |

Words that are React or web terms stay: `dispatch` from `useReducer`, the RSC "wire format", "over the wire", "print" as in `console.log`.

## Applied

All 180 cards were checked: 154 changed, 26 had no newsroom setting and are unchanged. The reports listing every old to new name per card are in `logs/card-rename-2026-10-15/`. A final check against the archived copies found no change to any title line, Topic Tag, Interview Question, or line count, no em-dash in a changed line, and no newsroom word left; the remaining matches of "breaking" and "dispatch" are the verb and the React or browser term. One review fix: card 42 says `EditPanel`, because an `EditForm` inside a `FormContainer` inside a `<form>` reads as three forms.

Old em-dashes remain in lines the rename did not touch (cards 12, 89, 92, 110, 118, 127, 132, 133, 142, 150, 163, 165, 166, 173); they predate this brief. Card 81 keeps `Badge` and `AuthorBadge` because its defect happens inside that badge; its map may swap the badge for a plain part.
