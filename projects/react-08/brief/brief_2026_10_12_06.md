# Brief 2026-10-12-06: The Files Panel in the Introduction

## Why

Lecture 8's introduction showed its folder structure as a plain ` ```ascii ` block titled "Project folders", while its case study shows the same disk layout in the ` ```files ` File Explorer panel. The reader met one layout in two unrelated styles. A first attempt added the rule only as a checkbox in `ui-panels` Section 04, which a writer working on the introduction does not consult, while `lecture-structure` Section 12 still said "plain words" and the Proper example in `intro-examples.md` Example 3 still showed a plain tree, so the example kept teaching the old shape.

## Group 1: The files panel in the introduction (#2026_10_12_06_group_1)
