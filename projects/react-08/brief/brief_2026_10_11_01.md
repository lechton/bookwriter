# Brief 2026-10-11-01: First Sight, and a Runway That Leaves the Questions Open

> Withdrawn by brief 2026-10-11-03: everything below was removed from the skills, the prompt, and the scripts, except groups 3 and 6.

## Why

Lecture 7 was rebuilt under the 2026-10-10 rules and passed its scripts, yet its introduction answered its own questions before they were asked. The first section opened two problems, showed the dropped-children code that Question 1 printed again, and already gave the cause ("the container must explicitly place `{children}`"). The recall list held Lecture 10, a later lesson, and called rest syntax known, though the map marks it New. The runway taught `children` in full, with details no question used (the shape of one child against two, the `children.map` crash, element descriptors), and stated Question 2's rule word for word. Question 1's container already destructured `{ children }`, and its answer named a `Headline` component the scenario never had. One card line read `return <div className="card" />; {/* ... */}`, a JSX comment after a JavaScript statement.

The cause was the 2026-10-10 rule itself: pre-lecture Section 01B sent every `New` row of the map's Terms table to the runway, and Section 13B's Fix line pointed there too. The blueprint for Lecture 7 followed it ("children prop (runway)").

The owner also asked for a concrete teaching rule: show the idea before explaining it. A small HTML list, a small variable, two small components with the line that links them; the result drawn with the tool that fits (rendered-browser figure, ASCII diagram, files tree, the printed line); then the lines that cause it; then the name.

The work below changes skills, scripts, and the production prompt only. No lecture, blueprint, or map was edited.
