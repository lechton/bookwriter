# Path 03: The Flight Simulator (Living Ripple Storytelling)

## Philosophy
Treat the code and the UI panel as an interactive flight instrument panel. Never present static code dumps. Code and UI evolve together beat-by-beat, showing immediate visual causality.

## Pedagogical Invariants
1. **The Hook:** A live interactive dashboard where a single variable change triggers ripples across the system.
2. **Beat-by-Beat Evolution:**
   - Beat 1: Start with 3 lines of plain state.
   - Beat 2: Render it onto the stage. The UI panel lights up in Cyan.
   - Beat 3: Add an event handler. Watch the user interaction trigger an engine pulse.
   - Beat 4: Watch the Fiber reconciler pinpoint the exact DOM node and paint it.
3. **High Visual Causality:** The RCE figure dynamically reflects the exact state of the prose at every step.
4. **Zero Cognitive Friction:** The student feels like a pilot watching gauges respond in real time, making advanced concepts effortless to digest.
