# Table of Contents: Mastering React 19 Architecture

> A unified, dependency-ordered curriculum of **180 technical lectures** covering React 19 Client Foundations & Hooks (Q01–Q100) and React Server, SSR & Full-Stack Systems (Q101–Q180). Designed for engineering mastery and staff-level technical interview preparation.

---

## Curriculum Architecture & Pedagogy

- **Organic Lexical Audit (OLA)**: Concepts are grounded in real-world, high-stakes editorial scenarios from the newsroom of *The National Times* (broken feeds, stale closure captures, layout thrashing, hydration mismatches, unhandled async transitions, cascading re-renders).
- **Harmonious Code + UI Step Rhythm**: Every section opens with 2–3 sentences of conceptual framing, followed immediately by a minimal code snippet directly preceding authentic UI canvases (React Component Explorer) before analytical derivations.
- **React Component Explorer (RCE)**: Visualizations employ strict graphical substrates: macOS window chrome, authentic file tree sidebar (`.jsx` and `.tsx` badges), component boundary tags, props chips, and clean archetypical UI widgets (stepper counters, 3-card news feeds, profile mastheads, controlled search inputs, reducer dispatch tracks).
- **Curriculum Typology Tiers**:
  - `❱ CORE` (React: Q01–Q39, Server: Q101–Q130): Minimum path to build and ship production React applications. Components, JSX, props, state snapshots, basic hooks, effects, keys, and SSR entry points.
  - `❱❱ MORE` (React: Q40–Q70, Server: Q131–Q165): Working developer feature tour. Reducers, context scaling, ref forwarding, custom hooks, transition hooks, streaming SSR, and asset preloading.
  - `❱❱❱ ADVANCED` (React: Q71–Q95, Server: Q166–Q175): Deep engine internals: Fiber reconciliation, render/commit phases, Suspense thrown promises, work loop concurrency, batching internals, React Compiler, and RSC Flight serialization protocol.
  - `LEGACY / MIGRATION` (React: Q96–Q100, Server: Q176–Q180): Class components, lifecycle migrations, and legacy server APIs.
