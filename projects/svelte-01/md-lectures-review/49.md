# Lecture 49 Review: Syncing Local Variables with Incoming Props

A quick-reference guide to the core concepts introduced in lecture 49. Review this table to solidify your understanding of Svelte 5's prop reactivity before moving on.

| You need to do this? | Then do this and not that |
| --- | --- |
| **How to sync a local variable with an incoming prop?**<br>Keep a local variable continuously updated when the parent passes new data. | ✔️ Use the `$derived` rune to maintain a continuous reactive connection.<br><br>`let likes = $derived(post.likes);`<br><br>✖️ Don't use `$state`, which only reads the prop once during creation and then ignores future updates.<br><br>`let likes = $state(post.likes);` |
| **How to temporarily override a derived value?**<br>Update the UI immediately before the server confirms the change (Optimistic UI). | ✔️ Reassign the `$derived` variable directly. The override will be washed away when the parent updates the prop.<br><br>`likes += 1;`<br><br>✖️ Don't declare the derived variable with `const` if you intend to override it. |
| **How to two-way bind a prop?**<br>Allow a child component to push changes back up to the parent component. | ✔️ Declare the prop as `$bindable()`.<br><br>`let { text = $bindable('') } = $props();`<br><br>✖️ Don't mutate standard, one-way props directly. |
| **How to write a multi-statement derivation?**<br>Use an intermediate variable or loop to calculate a derived value. | ✔️ Pass a callback function into `$derived.by()`.<br><br>``let str = $derived.by(() => { return text.trim(); });``<br><br>✖️ Don't mutate other state inside the derivation. It must be side-effect-free. |
| **How to destructure a prop?**<br>Pull properties off the `$props` object without losing reactivity. | ✔️ Read properties directly from the object in the template, or read through an intermediate prop object.<br><br>`let p = $props();`<br>`<p>{p.title}</p>`<br><br>✖️ Don't destructure into primitives, which severs the reactive connection.<br><br>`let { title } = $props();` |
| **How to sync an editable local draft?**<br>A form draft that the user can edit, but also syncs if the parent updates the source. | ✔️ Carefully combine `$state(prop.value)` with an `$effect()` to push upstream changes into the local draft.<br><br>`$effect(() => { draft = user.name; });`<br><br>✖️ Default to `$derived` first; only reach for this when editability and continuous sync are both required. |
