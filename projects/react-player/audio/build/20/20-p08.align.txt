State is the single source of truth.
Our page now shows the message in two places, the box and the count. Both copy the same state. Think of a train station with one main clock. Every platform screen copies that clock. When the clock changes, every screen changes with it. Nobody sets a platform screen by hand.
State is our main clock. The box and the count are the screens. This idea is called a single source of truth. One place holds the text, and everything on the page copies it. So to change what the box shows, we never touch the box. We change the state.

One last note, if you know HTML. In HTML, you write the starting text of a text area between its tags. React doesn't support that. Let's wrap up Principle two. Value. React writes state into the box after every render. When our code must change what the box shows, like emptying it after Send, give the box value from state. A box without value keeps its own text. Default value only sets the starting text, so after Send the count says zero while the old message stays in the box. With value from state, React writes the state into the box after every render. Then saving an empty string empties the box too, and state becomes the single source of truth. So, do this.
