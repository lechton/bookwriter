Summary

When a function finishes, its local variables are normally discarded. But a function defined inside it and then returned keeps a live reference to those variables, so they stay alive — a function bundled with the variables it captured is called a closure. Here claps is private state with no class needed: it survives only because clap() and total() keep its scope alive.

Explanation
When a function returns, the variables it defined would normally be discarded. But the two functions it returns were defined inside that scope and still reference claps, so the scope is kept alive for as long as they exist — and claps can be reached only through them.
