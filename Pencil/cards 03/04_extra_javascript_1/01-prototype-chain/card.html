Summary

In JavaScript, every object keeps a hidden link to a prototype, and a property lookup always checks the object itself first. A value stored directly on the object — an own property — is returned at once. When it is missing, the search walks up the prototype chain and uses the first copy it finds, so that property is inherited rather than duplicated onto every object. The chain ends at null, and a name found nowhere along it simply reads back as undefined.

Explanation
JavaScript looks on the object itself first: a property added to the object — its own property — is found there at once. If it isn't there, the lookup follows the object's link to its prototype and inherits the property from there, continuing up the chain until it is found or the chain ends at null, which gives undefined.
