Passing a Variable From Parent to Child with Props
Parent — passes it down
src/lib/Article.svelte
1<script>
2 import Byline from './Byline.svelte';
3 let author = $state("Ada Lovelace");
4</script>
5<Byline name={author} />
2
Imports the child component, Byline, so the parent can render it.
3
author is the parent's own reactive state — the value we want to hand to the child.
5
Renders the child and passes author down through a prop called name — name={author}.
name={author}read by the child via $props()
Child — receives it
src/lib/Byline.svelte
1<script>
2 let { name } = $props();
3</script>
4<p>By {name}</p>
2
$props() returns everything passed in; destructuring pulls out name — the value the parent sent.
4
The child uses name like any local variable; {name} renders By Ada Lovelace.
Summary

In Svelte, a parent hands data to a child through props: the parent writes an attribute on the child tag — name={author} — and the child reads it by destructuring $props(). The value flows one way, parent to child, and because that value is reactive, changing it in the parent re-renders the child automatically. Props are how components compose — small, self-contained pieces wired together by the data passed between them.
